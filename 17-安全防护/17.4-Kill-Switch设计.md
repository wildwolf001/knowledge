# 17.4 Kill Switch 设计

> **Kill Switch**（紧急停止开关）是 Agent 系统在检测到安全事件时的紧急响应机制。与传统的"一键停服"不同，Agent 的 Kill Switch 面临一个根本挑战：**Agent 可能正在执行有副作用的操作**（正在写文件、正在发邮件、正在处理数据库事务），简单中断可能导致数据损坏、资源泄露或状态不一致。

---

## 一、为什么 Agent 的 Kill Switch 不能只是"停止"

### 1.1 有状态操作的问题

假设一个 Agent 正在执行以下操作序列：

```
时间线：
  T1: Agent 读取数据库（无副作用）
  T2: Agent 创建文件 /tmp/report_part1.txt（有副作用，已完成）
  T3: Agent 调用 API 发送第一封邮件（有副作用，已完成）
  T4: Agent 正在写入文件 /tmp/report_part2.txt（有副作用，进行中）
  T5: Agent 计划删除临时文件（无此操作会导致资源泄露）
        ↑
  此时检测到注入攻击！
  
如果简单 Kill：
    1. /tmp/report_part1.txt 残留 → 可能包含敏感信息
    2. 第一封邮件已发送 → 无法撤回
    3. /tmp/report_part2.txt 可能损坏（写入过程中断）
    4. 下一次 Agent 启动时，残留文件可能导致状态混乱
```

### 1.2 Kill Switch 的三个设计目标

1. **止损（Containment）**：立即阻止 Agent 执行新的操作，阻断攻击继续扩大
2. **补偿（Compensation）**：对已完成的有副作用操作执行补偿动作（回滚、清理、撤销）
3. **恢复（Recovery）**：在确认安全后，恢复到可用状态（或降级模式）

## 二、Kill Switch 状态机设计

### 2.1 核心状态

```
                    ┌─────────────────────────────────────┐
                    │                                        │
                    ▼                                        │
    ┌──────────┐      ┌──────────┐      ┌──────────────┐      │
    │ 正常执行    │      │ 触发暂停   │      │  安全模式     │      │
    │ (Normal)  │ ──→  │ (Halted) │ ──→  │ (Safe Mode) │ ─────┘
    └──────────┘      └──────────┘      └──────────────┘
         │                                    │
         │                                    │
         ▼                                    ▼
    ┌──────────┐                         ┌──────────┐
    │ 手动恢复   │                         │ 自动恢复   │
    │ (Manual)  │                         │ (Auto)    │
    └──────────┘                         └──────────┘
```

### 2.2 状态定义

| 状态 | 定义 | 可执行操作 | 存活时间 |
|------|------|-----------|---------|
| **Normal** | Agent 正常运行 | 所有工具调用 | 无限制 |
| **Halted** | 检测到安全事件，暂停新操作 | 只允许查询状态、执行补偿动作 | 有限（通常 < 60 秒） |
| **Safe Mode** | Agent 以降级模式运行 | 只读操作、状态查询 | 直到管理员介入或自动恢复 |
| **Manual Recovery** | 等待管理员介入恢复 | 无（管理员操作） | 无限制 |
| **Auto Recovery** | 自动恢复流程 | 执行恢复脚本 | 有限（< 30 秒） |

### 2.3 状态机实现

```python
from enum import Enum
import time
import threading
import logging

class AgentState(Enum):
    NORMAL = "normal"           # 正常
    HALTED = "halted"           # 暂停（过渡态）
    SAFE_MODE = "safe_mode"     # 安全模式
    MANUAL_RECOVERY = "manual"  # 需管理员介入
    AUTO_RECOVERY = "auto"      # 自动恢复中
    
    TERMINATED = "terminated"   # 已终止（不可恢复）

class KillSwitchStateMachine:
    """
    Kill Switch 状态机：管理 Agent 的安全生命周期
    """
    
    # 状态转换规则
    TRANSITIONS = {
        AgentState.NORMAL: [AgentState.HALTED],
        AgentState.HALTED: [AgentState.SAFE_MODE, AgentState.AUTO_RECOVERY, AgentState.MANUAL_RECOVERY],
        AgentState.SAFE_MODE: [AgentState.NORMAL, AgentState.MANUAL_RECOVERY, AgentState.TERMINATED],
        AgentState.AUTO_RECOVERY: [AgentState.NORMAL, AgentState.SAFE_MODE, AgentState.TERMINATED],
        AgentState.MANUAL_RECOVERY: [AgentState.NORMAL, AgentState.TERMINATED],
        AgentState.TERMINATED: [],
    }
    
    def __init__(self, agent_id: str, session_id: str):
        self.agent_id = agent_id
        self.session_id = session_id
        self.state = AgentState.NORMAL
        
        # 补偿动作队列
        self.compensation_queue: list[dict] = []
        
        # 安全事件记录
        self.trigger_event: dict | None = None
        
        # 锁
        self._lock = threading.Lock()
        
        # 日志
        self.logger = logging.getLogger(f'killswitch.{agent_id}')
        
        # 回调注册
        self._on_state_change: list[callable] = []
    
    def trigger_halt(self, event: dict) -> bool:
        """
        触发暂停：从 NORMAL → HALTED
        
        event: 触发暂停的安全事件详情
        """
        with self._lock:
            if self.state != AgentState.NORMAL:
                return False
            
            self.state = AgentState.HALTED
            self.trigger_event = event
            
            self.logger.warning(
                f"Kill Switch triggered | agent={self.agent_id} "
                f"event={event.get('type', 'unknown')} "
                f"reason={event.get('reason', 'unknown')}"
            )
            
            self._notify_state_change()
            return True
    
    def enter_safe_mode(self, compensation_actions: list[dict]) -> bool:
        """
        进入安全模式：HALTED → SAFE_MODE
        执行补偿动作后进入安全模式
        """
        with self._lock:
            if self.state != AgentState.HALTED:
                return False
            
            # 记录补偿动作队列
            self.compensation_queue = compensation_actions
            
            self.state = AgentState.SAFE_MODE
            self.logger.info(
                f"Entered safe mode | agent={self.agent_id} "
                f"pending_compensations={len(compensation_actions)}"
            )
            
            self._notify_state_change()
            return True
    
    def attempt_auto_recovery(self) -> bool:
        """
        尝试自动恢复：HALTED → AUTO_RECOVERY
        """
        with self._lock:
            if self.state not in (AgentState.HALTED, AgentState.SAFE_MODE):
                return False
            
            self.state = AgentState.AUTO_RECOVERY
            self._notify_state_change()
            return True
    
    def recover_to_normal(self) -> bool:
        """
        恢复到正常状态：AUTO_RECOVERY/MANUAL_RECOVERY/SAFE_MODE → NORMAL
        """
        with self._lock:
            if self.state not in (AgentState.AUTO_RECOVERY, AgentState.MANUAL_RECOVERY, AgentState.SAFE_MODE):
                return False
            
            self.state = AgentState.NORMAL
            self.trigger_event = None
            self.compensation_queue = []
            
            self.logger.info(f"Recovered to normal | agent={self.agent_id}")
            self._notify_state_change()
            return True
    
    def require_manual_recovery(self) -> bool:
        """
        需要管理员介入：SAFE_MODE/HALTED → MANUAL_RECOVERY
        """
        with self._lock:
            if self.state not in (AgentState.HALTED, AgentState.SAFE_MODE):
                return False
            
            self.state = AgentState.MANUAL_RECOVERY
            self._notify_state_change()
            return True
    
    def terminate(self) -> bool:
        """
        终止 Agent（不可恢复）：任何状态 → TERMINATED
        """
        with self._lock:
            if self.state == AgentState.TERMINATED:
                return False
            
            self.state = AgentState.TERMINATED
            self.logger.critical(f"Agent terminated | agent={self.agent_id}")
            self._notify_state_change()
            return True
    
    def on_state_change(self, callback: callable):
        """注册状态变更回调"""
        self._on_state_change.append(callback)
    
    def _notify_state_change(self):
        """通知所有状态变更监听器"""
        for callback in self._on_state_change:
            try:
                callback(self.state, self.trigger_event)
            except Exception as e:
                self.logger.error(f"State change callback failed: {e}")
    
    def can_execute_tool(self, tool_name: str, risk_level: str) -> bool:
        """根据当前状态判断是否可以执行工具"""
        if self.state == AgentState.NORMAL:
            return True
        
        if self.state == AgentState.HALTED:
            # HALTED 状态只允许补偿操作和只读状态查询
            safe_tools = ['get_status', 'query_state', 'rollback', 'cleanup']
            return tool_name in safe_tools
        
        if self.state == AgentState.SAFE_MODE:
            # SAFE_MODE 只允许只读操作
            safe_tools = ['read_file', 'search_web', 'get_status', 'query_state']
            return risk_level == 'read' and tool_name in safe_tools
        
        if self.state in (AgentState.MANUAL_RECOVERY, AgentState.AUTO_RECOVERY):
            # 恢复过程中不接受新工具调用
            return False
        
        if self.state == AgentState.TERMINATED:
            return False
        
        return False
```

## 三、补偿动作（Compensation Actions）

### 3.1 补偿模式

当 Kill Switch 被触发时，系统需要针对每个已经产生副作用的操作执行补偿动作：

```
检测到攻击，进入 HALTED 状态
    │
    ├── 读取操作：无副作用 → 不需要补偿
    │
    ├── 写操作：
    │   ├── 文件写入 → 删除已写入的临时文件
    │   ├── 数据库更新 → 执行回滚（如果事务支持）或补偿更新
    │   └── 创建资源 → 删除已创建的资源
    │
    ├── 网络操作：
    │   ├── 已发送的邮件 → 无法撤回，标记为"可疑"并通知安全团队
    │   ├── 已发出的 API 请求 → 记录请求 ID，后续取消
    │   └── 已建立的长连接 → 关闭连接
    │
    └── 状态修改：
        ├── 修改的配置 → 恢复到前一版本
        └── 修改的权限 → 恢复到前一权限状态
```

### 3.2 补偿动作执行器

```python
class CompensationExecutor:
    """
    补偿动作执行器：对已完成的有副作用操作执行回滚/清理
    """
    
    def __init__(self, session_state: dict):
        self.session_state = session_state  # Agent 会话状态快照
        self.executed_compensations: list[dict] = []
        self.failed_compensations: list[dict] = []
    
    def build_compensation_plan(self, 
                                executed_actions: list[dict]) -> list[dict]:
        """
        根据已执行的操作列表构建补偿计划
        
        executed_actions: Agent 已执行的操作历史
        [
            {'tool': 'write_file', 'params': {'path': '/tmp/report.md', 'content': '...'}, 'status': 'completed'},
            {'tool': 'send_email', 'params': {'to': 'user@example.com', 'subject': '...'}, 'status': 'completed'},
            {'tool': 'query_database', 'params': {'sql': 'SELECT * FROM users'}, 'status': 'completed'},
        ]
        """
        compensation_plan = []
        
        for action in reversed(executed_actions):  # 逆序补偿（LIFO）
            tool = action['tool']
            params = action['params']
            
            compensation = self._build_compensation(tool, params, action)
            if compensation:
                compensation_plan.append(compensation)
        
        return compensation_plan
    
    def _build_compensation(self, 
                            tool: str, 
                            params: dict, 
                            action: dict) -> dict | None:
        """为单个操作构建补偿动作"""
        
        if tool == 'write_file':
            path = params.get('path', '')
            return {
                'action': 'delete_file',
                'params': {'path': path},
                'reason': f'Clean up file created during compromised session',
                'criticality': 'high',
                'rollback_of': action
            }
        
        elif tool == 'update_database':
            table = params.get('table', '')
            record_id = params.get('record_id', '')
            old_values = action.get('before_snapshot', {})
            return {
                'action': 'restore_database_record',
                'params': {
                    'table': table,
                    'record_id': record_id,
                    'restore_values': old_values
                },
                'reason': f'Restore database record {table}.{record_id}',
                'criticality': 'critical',
                'rollback_of': action
            }
        
        elif tool == 'send_email':
            # 已发送的邮件无法撤回，但可以标记并通知
            return {
                'action': 'mark_email_as_suspicious',
                'params': {
                    'email_id': action.get('result', {}).get('email_id', 'unknown'),
                    'original_params': params
                },
                'reason': 'Sent email cannot be recalled, marking as suspicious',
                'criticality': 'info',
                'requires_manual_review': True,
                'rollback_of': action
            }
        
        elif tool == 'execute_shell':
            command = params.get('command', '')
            return {
                'action': 'revert_shell_changes',
                'params': {
                    'command': command,
                    'original_state': self.session_state.get('filesystem_snapshot', {})
                },
                'reason': f'Revert changes from shell command: {command[:100]}',
                'criticality': 'critical',
                'rollback_of': action
            }
        
        elif tool == 'create_sub_agent':
            sub_agent_id = action.get('result', {}).get('agent_id', '')
            return {
                'action': 'terminate_sub_agent',
                'params': {'agent_id': sub_agent_id},
                'reason': f'Terminate sub-agent created during compromised session',
                'criticality': 'critical',
                'rollback_of': action
            }
        
        return None  # 不需要补偿的操作（如只读操作）
    
    def execute_compensation(self, 
                             compensation: dict, 
                             executor_fn: callable) -> dict:
        """
        执行单个补偿动作
        executor_fn: 实际的执行函数（由上层注入）
        """
        try:
            result = executor_fn(
                compensation['action'],
                compensation['params']
            )
            
            entry = {
                'compensation': compensation,
                'success': True,
                'result': result,
                'timestamp': __import__('time').time()
            }
            self.executed_compensations.append(entry)
            return entry
            
        except Exception as e:
            entry = {
                'compensation': compensation,
                'success': False,
                'error': str(e),
                'timestamp': __import__('time').time()
            }
            self.failed_compensations.append(entry)
            
            # 如果关键补偿失败，可能需要提升告警级别
            if compensation.get('criticality') == 'critical':
                self._escalate_failure(compensation, e)
            
            return entry
    
    def _escalate_failure(self, compensation: dict, error: Exception):
        """关键补偿失败时升级告警"""
        import logging
        logger = logging.getLogger('security.compensation')
        logger.critical(
            f"Critical compensation failed! "
            f"action={compensation['action']} "
            f"error={error} "
            f"requires immediate manual intervention"
        )
```

### 3.3 Halted 状态的自毁计时器

Agent 在 Halted 状态不能无限期停留——必须有一个明确的超时策略：

```python
class HaltTimeoutManager:
    """
    Halted 状态超时管理器：决定 Halted 状态后的下一步动作
    """
    
    def __init__(self, state_machine: KillSwitchStateMachine,
                 safe_mode_timeout: int = 300,       # 5 分钟后进入 manual
                 compensation_timeout: int = 60,     # 1 分钟内完成补偿
                 auto_recovery_enabled: bool = True):
        
        self.state_machine = state_machine
        self.safe_mode_timeout = safe_mode_timeout
        self.compensation_timeout = compensation_timeout
        self.auto_recovery_enabled = auto_recovery_enabled
        
        self._timer: threading.Timer | None = None
    
    def on_halt_triggered(self):
        """当 Halted 状态被触发时的超时策略"""
        
        # 启动补偿超时计时器
        self._start_timer(
            timeout=self.compensation_timeout,
            callback=self._on_compensation_timeout
        )
    
    def on_compensation_completed(self, has_failures: bool):
        """补偿动作完成后的下一步"""
        self._cancel_timer()
        
        if has_failures:
            # 有补偿失败 → 需要管理员介入
            self.state_machine.require_manual_recovery()
        elif self.auto_recovery_enabled:
            # 补偿全部成功 → 尝试自动恢复
            self.state_machine.attempt_auto_recovery()
        else:
            # 手动模式 → 进入安全模式等待
            self.state_machine.enter_safe_mode([])
    
    def _on_compensation_timeout(self):
        """补偿超时 → 强制进入 Manual Recovery"""
        self.state_machine.require_manual_recovery()
        import logging
        logging.getLogger('killswitch').warning(
            "Compensation timeout reached, requiring manual recovery"
        )
    
    def _start_timer(self, timeout: int, callback: callable):
        self._cancel_timer()
        self._timer = threading.Timer(timeout, callback)
        self._timer.daemon = True
        self._timer.start()
    
    def _cancel_timer(self):
        if self._timer:
            self._timer.cancel()
            self._timer = None
```

## 四、安全模式（Safe Mode）的功能边界

### 4.1 安全模式下允许的操作

进入安全模式后，Agent 仍然可以运行，但功能大幅受限：

```
安全模式功能矩阵：

核心功能（仍然可用）：
  ✅ 读文件（限制路径范围）
  ✅ 只读数据库查询
  ✅ 状态报告
  ✅ 与管理员通信
  ✅ 帮助用户导出已有结果
  ✅ 查看执行历史
  ✅ 与安全系统通信（上报日志）

受限功能（需要特殊审批）：
  ⚠️ 写文件（仅限安全日志目录）
  ⚠️ 发送通知（仅限"系统告警"通道）

禁止功能（完全不可用）：
  ❌ 任何写数据库操作
  ❌ Shell 命令执行
  ❌ 网络请求（除安全端点外）
  ❌ 创建子 Agent
  ❌ 修改权限配置
  ❌ 删除文件
  ❌ 发送邮件
```

### 4.2 安全模式下的用户通知

当 Agent 进入安全模式时，需要向用户清晰地传达信息：

```

  - 待人工审查的邮件操作：1 封
  - 需要管理员介入

  ✅ 查看当前对话历史
```

## 五、从安全模式恢复到正常

### 5.1 自动恢复流程

当触发事件是一次误报（False Positive）或低严重性事件时，自动恢复是首选：

```python
class AutoRecoveryProcedure:
    """
    自动恢复程序：从安全模式无风险地恢复到正常模式
    """
    
    def __init__(self, state_machine: KillSwitchStateMachine):
        self.state_machine = state_machine
    
    def execute_recovery(self, 
                         trigger_event: dict,
                         compensation_results: list[dict]) -> bool:
        """
        执行自动恢复
        """
        steps = [
            ('验证补偿结果', self._verify_compensation, compensation_results),
            ('检查环境一致性', self._check_environment_integrity, None),
            ('重置权限状态', self._reset_permissions, None),
            ('清理残留状态', self._cleanup_residual_state, None),
            ('恢复服务', self._restore_services, None),
        ]
        
        for step_name, step_fn, step_arg in steps:
            success, error = step_fn(step_arg) if step_arg else step_fn()
            if not success:
                # 自动恢复失败 → 转为手动恢复
                self.state_machine.require_manual_recovery()
                return False
        
        # 所有步骤成功 → 恢复到正常
        return self.state_machine.recover_to_normal()
    
    def _verify_compensation(self, results: list[dict]) -> tuple[bool, str | None]:
        """验证所有补偿动作是否成功"""
        failures = [r for r in results if not r.get('success')]
        if failures:
            return False, f"{len(failures)} compensations failed"
        return True, None
    
    def _check_environment_integrity(self) -> tuple[bool, str | None]:
        """检查 Agent 运行环境是否完好"""
        # 检查文件系统完整性
        # 检查敏感文件是否被篡改
        # 检查权限配置
        return True, None
    
    def _reset_permissions(self) -> tuple[bool, str | None]:
        """重置权限到最低级别（保守策略）"""
        return True, None
    
    def _cleanup_residual_state(self) -> tuple[bool, str | None]:
        """清理 Agent 状态中的残留"""
        return True, None
    
    def _restore_services(self) -> tuple[bool, str | None]:
        """恢复被暂停的服务"""
        return True, None
```

### 5.2 恢复后的降级运行

即使恢复到正常状态，也建议在一段时间内"降级运行"——保持提升的安全监控级别：

```python
class GradualRecovery:
    """
    分级恢复：恢复到正常后逐步放宽安全限制
    """
    
    def __init__(self):
        self.recovery_stage = 0  # 0 = 刚恢复，监控最严
        self.stage_timers: dict[int, int] = {
            0: 300,    # 5 分钟
            1: 1800,   # 30 分钟
            2: 7200,   # 2 小时
            3: 0,      # 完全恢复
        }
    
    def get_current_restrictions(self) -> dict:
        """获取当前恢复阶段的额外限制"""
        if self.recovery_stage == 0:
            return {
                'all_writes_require_confirmation': True,
                'network_access_level': 1,  # 仅白名单
                'shell_execution': False,
                'max_tools_per_minute': 5,
                'extra_logging': True,
            }
        elif self.recovery_stage == 1:
            return {
                'all_writes_require_confirmation': True,
                'network_access_level': 2,
                'shell_execution': False,
                'max_tools_per_minute': 20,
                'extra_logging': True,
            }
        elif self.recovery_stage == 2:
            return {
                'network_access_level': 3,
                'shell_execution': True,
                'max_tools_per_minute': 60,
                'extra_logging': True,
            }
        else:
            return {}  # 无额外限制
```

### 6.2 防止 Kill Switch 被攻击者利用

Kill Switch 本身也是一个攻击目标——攻击者可能试图反复触发 Kill Switch 导致拒绝服务（DoS）：

```python
class AntiAbuseGuard:
    """
    Kill Switch 反滥用保护：防止攻击者通过反复触发 Kill Switch 实施 DoS
    """
    
    def __init__(self):
        self.trigger_history: list[float] = []
        self.cooldown_period = 60  # 60 秒冷却期
        self.max_triggers_per_period = 3  # 冷却期内最多触发次数
    
    def can_trigger(self) -> dict:
        """检查是否可以触发 Kill Switch"""
        now = __import__('time').time()
        
        # 清理过期的历史记录
        self.trigger_history = [
            t for t in self.trigger_history 
            if now - t < self.cooldown_period
        ]
        
        if len(self.trigger_history) >= self.max_triggers_per_period:
            return {
                'allowed': False,
                'reason': f'Throttled: {len(self.trigger_history)} triggers in {self.cooldown_period}s',
                'retry_after': int(self.cooldown_period - (now - self.trigger_history[0]))
            }
        
        self.trigger_history.append(now)
        return {'allowed': True, 'reason': 'ok'}
```

## 关键概念速查

| 术语 | 解释 |
|------|------|
| Kill Switch | Agent 系统的紧急停止/安全响应机制 |
| Halted（暂停状态） | 检测到安全事件后的过渡状态，暂停新操作 |
| Safe Mode（安全模式） | 降级运行模式，只允许只读操作 |
| 补偿动作（Compensation） | 对已执行的副作用操作进行回滚/清理 |
| 状态机 | 管理 Agent 不同安全状态的转换逻辑 |
| 自动恢复 | 安全事件解除后自动恢复到正常模式 |
| Manual Recovery | 需要管理员手动介入的恢复流程 |
| 分级恢复 | 恢复后逐步放宽安全限制的策略 |
| 反滥用保护 | 防止 Kill Switch 被用作 DoS 攻击工具 |
| LIFO 补偿 | 后进先出（Last In First Out）的补偿顺序 |
