# 9.2 工具注册中心

> 工具注册中心（Tool Registry）是 Agent 系统中所有可用工具的"目录"。它负责工具的发现、版本管理、权限标注和 Schema 兼容性检测。一个设计良好的注册中心，是 Agent 能够动态发现和调用数千个工具的基础。

---

## 一、什么是工具注册中心？

### 1.1 从硬编码到动态注册

在早期的 Agent 实现中，工具定义通常是硬编码在代码中的：

```python
# 硬编码方式 —— 不可扩展
tools = [
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "获取天气信息",
            "parameters": {...}
        }
    }
]
```

当工具数量从 5 个增长到 50 个、500 个时，硬编码方式完全不可维护。工具注册中心应运而生——它是 Agent 运行时的"服务发现"层，负责管理工具的全生命周期。

```
┌─────────────────────────────────────────────────────┐
│                    工具注册中心                          │
│                                                         │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐             │
│  │ 工具 A    │  │ 工具 B    │  │ 工具 C    │  ← 工具实例  │
│  │ v1.2     │  │ v2.0     │  │ v1.0     │  ← 版本信息  │
│  │ read     │  │ write    │  │ read     │  ← 权限标注  │
│  └──────────┘  └──────────┘  └──────────┘             │
│         │              │              │                │
│         └──────────────┴──────────────┘                │
│                        │                                │
│                Agent 运行时    ← 统一查询接口           │
└─────────────────────────────────────────────────────┘
```

### 1.2 注册中心的核心职责

| 职责 | 说明 | 优先级 |
|------|------|--------|
| **工具发现（Discovery）** | 运行时动态获取可用工具列表 | P0 |
| **版本管理（Versioning）** | 跟踪工具定义的变化，支持版本回退 | P1 |
| **权限标注（Permissions）** | 标注每个工具的访问级别和授权要求 | P1 |
| **Schema 兼容性检测** | 验证工具 Schema 是否符合模型的 Function Call 协议 | P0 |
| **工具分组（Grouping）** | 对海量工具进行逻辑分类 | P1 |
| **健康检查（Health Check）** | 检测工具后端服务是否可用 | P2 |

### 2.2 Python 工具注册中心实现

以下是一个生产级别的工具注册中心实现：

```python
from __future__ import annotations
import json
import time
import hashlib
from dataclasses import dataclass, field
from enum import Enum
from typing import Any, Callable, Optional


class ToolPermission(Enum):
    """工具权限级别"""
    PUBLIC = "public"           # 任何对话可用
    AUTHENTICATED = "auth"      # 需要用户认证
    ADMIN = "admin"             # 仅管理员可用
    SANDBOXED = "sandboxed"     # 需要在沙箱中执行


class ToolSafety(Enum):
    """工具安全性分类"""
    READ = "read"               # 只读，无副作用
    WRITE = "write"             # 写操作，有副作用
    DESTRUCTIVE = "destructive" # 删除/销毁操作
    EXEC = "exec"               # 代码执行（高风险）


@dataclass
class ToolMetadata:
    """工具元数据"""
    name: str
    description: str
    parameters: dict
    permission: ToolPermission
    safety: ToolSafety
    version: str
    handler: Optional[Callable] = None
    tags: list[str] = field(default_factory=list)
    deprecated: bool = False
    deprecation_message: str = ""
    concurrency_safe: bool = True
    timeout_ms: int = 30000
    rate_limit: int = 100  # 每分钟最大调用次数


class ToolRegistry:
    """工具注册中心"""

    def __init__(self):
        self._tools: dict[str, ToolMetadata] = {}
        self._versions: dict[str, list[ToolMetadata]] = {}
        self._schema_cache: dict[str, str] = {}
        self._call_counts: dict[str, list[float]] = {}

    def register(self, metadata: ToolMetadata) -> None:
        """注册一个工具"""
        # Schema 兼容性检测
        errors = self._validate_schema(metadata.parameters)
        if errors:
            raise ValueError(
                f"工具 '{metadata.name}' Schema 验证失败: {errors}"
            )

        # 名称冲突检测
        if metadata.name in self._tools:
            existing = self._tools[metadata.name]
            if existing.version == metadata.version:
                raise ValueError(
                    f"工具 '{metadata.name}' v{metadata.version} 已存在"
                )

        # 存储元数据
        self._tools[metadata.name] = metadata

        # 版本历史
        if metadata.name not in self._versions:
            self._versions[metadata.name] = []
        self._versions[metadata.name].append(metadata)

        # Schema 指纹缓存
        schema_str = json.dumps(metadata.parameters, sort_keys=True)
        self._schema_cache[metadata.name] = hashlib.md5(
            schema_str.encode()
        ).hexdigest()

    def unregister(self, name: str) -> None:
        """注销工具"""
        if name in self._tools:
            del self._tools[name]

    def discover(
        self,
        permission: Optional[ToolPermission] = None,
        safety: Optional[ToolSafety] = None,
        tags: Optional[list[str]] = None,
        include_deprecated: bool = False,
    ) -> list[ToolMetadata]:
        """发现可用工具，支持多维度筛选"""
        results = []
        for tool in self._tools.values():
            if not include_deprecated and tool.deprecated:
                continue
            if permission and tool.permission.value != permission.value:
                continue
            if safety and tool.safety != safety:
                continue
            if tags and not all(t in tool.tags for t in tags):
                continue
            results.append(tool)
        return results

    def get(self, name: str, version: Optional[str] = None) -> Optional[ToolMetadata]:
        """获取指定工具的定义"""
        if version:
            versions = self._versions.get(name, [])
            for v in versions:
                if v.version == version:
                    return v
            return None
        return self._tools.get(name)

    def _validate_schema(self, schema: dict) -> list[str]:
        """Schema 兼容性检测"""
        errors = []

        # 1. 必须是 object 类型
        if schema.get("type") != "object":
            errors.append("parameters 必须为 object 类型")

        # 2. properties 必须存在
        if "properties" not in schema:
            errors.append("parameters 必须包含 properties 字段")

        # 3. 每个属性必须有 type
        for prop_name, prop_def in schema.get("properties", {}).items():
            if "type" not in prop_def:
                errors.append(f"属性 '{prop_name}' 缺少 type 字段")

            # 4. 嵌套对象的 properties 检查
            if prop_def.get("type") == "object" and "properties" in prop_def:
                if "additionalProperties" not in prop_def:
                    errors.append(
                        f"嵌套对象 '{prop_name}' 建议设置 additionalProperties"
                    )

        # 5. 不支持 anyOf/oneOf
        if "anyOf" in schema or "oneOf" in schema:
            errors.append("anyOf/oneOf 不被 Function Call 协议支持")

        # 6. required 必须是 properties 的子集
        for req in schema.get("required", []):
            if req not in schema.get("properties", {}):
                errors.append(f"required 字段 '{req}' 不在 properties 中")

        return errors

    def check_rate_limit(self, name: str) -> bool:
        """检查工具是否触发限流"""
        now = time.time()
        window_start = now - 60  # 1 分钟窗口

        if name not in self._call_counts:
            self._call_counts[name] = []

        # 清理过期记录
        self._call_counts[name] = [
            t for t in self._call_counts[name] if t > window_start
        ]

        tool = self._tools.get(name)
        if not tool:
            return False

        return len(self._call_counts[name]) < tool.rate_limit

    def record_call(self, name: str) -> None:
        """记录工具调用"""
        self._call_counts.setdefault(name, []).append(time.time())

    def get_schema_digest(self, name: str) -> Optional[str]:
        """获取 Schema 指纹（用于缓存判断）"""
        return self._schema_cache.get(name)

    def diff_schema(
        self, name: str, new_schema: dict
    ) -> list[dict]:
        """Schema 差异检测"""
        old_tool = self._tools.get(name)
        if not old_tool:
            return [{"type": "added", "field": "entire_tool"}]

        old_schema = old_tool.parameters
        diffs = []

        old_props = set(old_schema.get("properties", {}).keys())
        new_props = set(new_schema.get("properties", {}).keys())

        # 新增参数
        for prop in new_props - old_props:
            diffs.append({
                "type": "added",
                "field": f"properties.{prop}"
            })

        # 删除参数
        for prop in old_props - new_props:
            diffs.append({
                "type": "removed",
                "field": f"properties.{prop}"
            })

        # 参数类型变更
        for prop in old_props & new_props:
            old_type = old_schema["properties"][prop].get("type")
            new_type = new_schema["properties"][prop].get("type")
            if old_type != new_type:
                diffs.append({
                    "type": "type_changed",
                    "field": f"properties.{prop}",
                    "old": old_type,
                    "new": new_type
                })

        return diffs
```

## 三、版本管理

### 3.1 版本策略

工具版本的变更分为三个等级，参考语义化版本控制（SemVer）：

| 等级 | 示例 | 对 Agent 的影响 | Schema 兼容性 |
|------|------|----------------|--------------|
| **Major** | v1→v2 | 参数不兼容，需要更新调用方 | 不兼容 |
| **Minor** | v1.1→v1.2 | 新增可选参数，行为不变 | 向前兼容 |
| **Patch** | v1.1.1→v1.1.2 | 修复内部实现，接口不变 | 完全兼容 |

**版本管理的关键规则**：
1. **向后兼容性**：Minor/Patch 版本必须保证向后兼容。新的可选参数不能改变工具的预期行为。
2. **版本标注**：每个工具定义包含明确的版本号，Agent 在调用时可以指定版本偏好。
3. **弃用策略**：标记为 deprecated 的工具会在响应中包含 `deprecation_message`，Agent 应逐步迁移。

```python
# 版本仓库实现
class VersionRepository:
    def __init__(self):
        self._history: dict[str, list[dict]] = {}

    def snapshot(self, tool_metadata: ToolMetadata) -> str:
        """创建工具定义的快照"""
        snapshot_id = hashlib.sha256(
            json.dumps({
                "name": tool_metadata.name,
                "version": tool_metadata.version,
                "parameters": tool_metadata.parameters,
                "timestamp": time.time()
            }, sort_keys=True).encode()
        ).hexdigest()[:12]

        entry = {
            "snapshot_id": snapshot_id,
            "name": tool_metadata.name,
            "version": tool_metadata.version,
            "schema": tool_metadata.parameters,
            "timestamp": time.time()
        }

        self._history.setdefault(tool_metadata.name, []).append(entry)
        return snapshot_id

    def rollback(self, name: str, target_version: str) -> Optional[dict]:
        """回滚到指定版本"""
        versions = self._history.get(name, [])
        for entry in reversed(versions):
            if entry["version"] == target_version:
                return entry["schema"]
        return None
```

### 3.2 Schema 兼容性检测规则

兼容性检测不仅要在注册时做，还要在**运行时**做——因为 Agent 可能缓存了旧版本的工具定义：

```python
def check_backward_compatibility(old_schema: dict, new_schema: dict) -> list[str]:
    """检查新 Schema 是否向后兼容旧 Schema"""
    warnings = []

    old_props = old_schema.get("properties", {})
    new_props = new_schema.get("properties", {})

    for prop_name, prop_def in old_props.items():
        if prop_name not in new_props:
            warnings.append(f"参数 '{prop_name}' 被移除——破坏性变更")
            continue

        new_def = new_props[prop_name]

        # 必填 → 可选：OK
        # 可选 → 必填：破坏性
        old_required = prop_name in old_schema.get("required", [])
        new_required = prop_name in new_schema.get("required", [])
        if not old_required and new_required:
            warnings.append(f"参数 '{prop_name}' 从可选变为必填——破坏性变更")

        # 类型变化：破坏性
        if prop_def.get("type") != new_def.get("type"):
            warnings.append(
                f"参数 '{prop_name}' 类型从 {prop_def.get('type')} "
                f"变为 {new_def.get('type')}——破坏性变更"
            )

        # 枚举值移除：破坏性
        old_enum = set(prop_def.get("enum", []))
        new_enum = set(new_def.get("enum", []))
        removed_enums = old_enum - new_enum
        if removed_enums:
            warnings.append(
                f"参数 '{prop_name}' 移除了枚举值 {removed_enums}——破坏性变更"
            )

    return warnings
```

## 四、权限标注体系

### 4.1 权限标签设计

每个工具注册时标注其权限级别。Agent 运行时根据**用户的身份**和**当前对话的安全上下文**决定哪些工具可见：

```python
@dataclass
class ToolPermissionPolicy:
    """工具权限策略"""
    default_permission: ToolPermission
    override_rules: dict[str, ToolPermission] = field(default_factory=dict)
    # key: "user:admin", value: ToolPermission.PUBLIC（管理员能看到所有工具）

    def get_effective_permission(
        self, tool: ToolMetadata, user_role: str
    ) -> ToolPermission:
        """获取用户对工具的实际可用权限"""
        rule_key = f"user:{user_role}"
        if rule_key in self.override_rules:
            return self.override_rules[rule_key]
        return tool.permission


# 使用示例
registry = ToolRegistry()
registry.register(ToolMetadata(
    name="delete_user",
    description="永久删除用户账号",
    parameters=delete_user_schema,
    permission=ToolPermission.ADMIN,
    safety=ToolSafety.DESTRUCTIVE,
    version="1.0.0"
))
```

### 4.2 运行时的安全隔离

结合安全性分类，Agent 可以实施不同级别的安全策略（详细安全分析见第 17 章）：

```
┌─────────────────────────────────────────────┐

│                                               │

│     │                                          │
│     ▼                                          │
│  ① 用户认证 → 角色识别                         │
│     │                                          │
```

## 五、MCP 集成与工具发现

### 5.1 MCP 工具注册与 Function Call 的桥接

MCP（Model Context Protocol，详见第 10 章）定义了标准化的工具描述格式。工具注册中心需要桥接 MCP 和 Function Call 两种协议：

```python
def mcp_tool_to_function_call(mcp_tool: dict) -> dict:
    """将 MCP 工具定义转换为 OpenAI Function Call 格式"""
    return {
        "type": "function",
        "function": {
            "name": mcp_tool["name"],
            "description": mcp_tool.get("description", ""),
            "strict": True,
            "parameters": mcp_tool.get("inputSchema", {
                "type": "object",
                "properties": {}
            })
        }
    }

def register_mcp_tools(registry: ToolRegistry, mcp_server_url: str):
    """从 MCP 服务发现并注册所有工具"""
    import requests

    # 调用 MCP 的 tools/list 端点
    response = requests.post(
        f"{mcp_server_url}/tools/list",
        json={"method": "tools/list"}
    )
    mcp_tools = response.json().get("tools", [])

    for mcp_tool in mcp_tools:
        func_call_schema = mcp_tool_to_function_call(mcp_tool)

        registry.register(ToolMetadata(
            name=func_call_schema["function"]["name"],
            description=func_call_schema["function"]["description"],
            parameters=func_call_schema["function"]["parameters"],
            permission=ToolPermission.PUBLIC,
            safety=ToolSafety.READ,
            version="1.0.0",
            tags=["mcp", mcp_server_url]
        ))
```

### 5.2 动态发现与缓存

为了减少每次请求都查询完整工具列表的开销，注册中心实现分层缓存策略：

```python
class CachedToolDiscovery:
    """带缓存的服务发现"""

    def __init__(self, registry: ToolRegistry, ttl_seconds: int = 60):
        self._registry = registry
        self._cache: dict[str, tuple[list[ToolMetadata], float]] = {}
        self._ttl = ttl_seconds

    def discover_cached(
        self,
        cache_key: str,
        **filters
    ) -> list[ToolMetadata]:
        now = time.time()

        # 检查缓存
        if cache_key in self._cache:
            tools, timestamp = self._cache[cache_key]
            if now - timestamp < self._ttl:
                return tools

        # 缓存未命中，查询注册中心
        tools = self._registry.discover(**filters)
        self._cache[cache_key] = (tools, now)
        return tools

    def invalidate(self, cache_key: str):
        """主动使缓存失效"""
        self._cache.pop(cache_key, None)
```

## 六、注册中心的监控与运维

### 6.1 关键监控指标

| 指标 | 说明 | 告警阈值 |
|------|------|---------|
| **工具总数** | 注册的工具数量 | > 1000 时关注性能 |
| **活跃工具数** | 近 1 小时内被调用的工具数 | < 总工具数 30% 时检查 |
| **注册失败率** | Schema 验证失败的比例 | > 5% |
| **调用延迟** | 工具执行到返回的延迟 | P99 > 5s 告警 |
| **Schema 兼容率** | 兼容性检查通过的比例 | < 95% 告警 |

### 6.2 注册中心与安全

工具注册中心是安全的关键控制点（详见第 17 章）。重要策略包括：

1. **注册审核**：新工具注册需要审批流程
2. **定期审计**：每 24 小时扫描所有注册工具的权限和安全性级别
3. **异常检测**：检测不寻常的工具调用模式（如短时间内大量调用 DESTRUCTIVE 工具）
4. **Schema 注入检测**：防止通过工具描述进行 Prompt Injection
