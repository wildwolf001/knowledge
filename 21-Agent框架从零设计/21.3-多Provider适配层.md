# 21.3 多 Provider 适配层 —— 统一接口抽象、Provider 间差异屏蔽、运行时热切换

> 现实中的 Agent 系统几乎不可能只依赖一个 LLM Provider：OpenAI 可能有网络故障、Anthropic 可能推出更好的模型、本地 LLM 可能是成本最优解。多 Provider 适配层的目标是以最小的代码代价实现 Provider 间的无缝切换和优雅降级。

---

## 一、为什么需要 Provider 适配层？

### 1.1 Provider 之间的差异

不同的 LLM Provider 在 API 设计上存在大量**微小但致命的差异**，直接切换 Provider 会导致以下问题：

| 差异维度 | OpenAI | Anthropic | Google Gemini | 本地 Ollama |
|---------|--------|-----------|--------------|------------|
| 消息格式 | `role: system/user/assistant/tool` | `role: user/assistant`，system 在参数中 | `role: user/model`，无 tool | `role: system/user/assistant` |
| Tool Call | `tools` 参数 + `tool_choice` | `tools` 参数，无 `tool_choice` | `tools` 参数，格式不同 | `tools` 参数或 function_call |
| 流式格式 | Server-Sent Events | SSE + `content_block` | Server-Sent Events | SSE |
| 上下文窗口 | 128K (GPT-4) | 200K (Claude 3) | 1M (Gemini 1.5) | 视模型而定 |
| Token 计数 | 返回 `usage` | 返回 `usage` | 返回 `usageMetadata` | 不返回 |
| 错误格式 | JSON 错误码 | 不同错误结构 | 不同错误结构 | HTTP 状态码 |
| 认证方式 | API Key (Header) | API Key (Header) | API Key (Query) | 无 |
| 价格模型 | Pay-per-token | Pay-per-token | Pay-per-token | 免费 (本地) |

如果不做适配层，Agent 框架将与特定的 Provider 紧耦合（Hard-coupled），更换 Provider 意味着重写主循环。

### 1.2 适配层要解决的核心问题

1. **接口统一**：所有 Provider 暴露相同的高层 API
2. **差异屏蔽**：将 Provider 特有的格式、参数、行为转换为内部统一格式
3. **错误标准化**：将 Provider 特有的错误映射为框架统一的异常体系
4. **运行时切换**：支持在运行时动态切换 Provider（如降级到备用 Provider）
5. **功能最小公倍数**：适配层只暴露所有 Provider 都支持的最小公共功能子集

### 2.1 抽象基类

```python
# framework/provider/base.py
"""LLM Provider 统一接口抽象"""

from __future__ import annotations
from abc import ABC, abstractmethod
from dataclasses import dataclass, field
from typing import Any, AsyncIterator, Optional


@dataclass
class ProviderMessage:
    """内部统一的消息格式"""
    role: str  # "system" | "user" | "assistant" | "tool"
    content: str
    tool_call_id: Optional[str] = None
    tool_name: Optional[str] = None
    tool_arguments: Optional[dict] = None

@dataclass
class ToolDefinition:
    """统一的工具定义格式"""
    name: str
    description: str
    input_schema: dict  # JSON Schema

@dataclass
class ProviderResponse:
    """Provider 调用结果的统一封装"""
    content: str
    tool_calls: list[ToolCall] = field(default_factory=list)
    model: str = ""
    input_tokens: int = 0
    output_tokens: int = 0
    finish_reason: str = ""

@dataclass
class ToolCall:
    """统一的工具调用格式"""
    id: str
    type: str = "function"
    function: FunctionCall = None

@dataclass
class FunctionCall:
    name: str
    arguments: str  # JSON string


class LLMProvider(ABC):
    """LLM Provider 抽象基类
    
    所有 Provider 适配器必须实现此接口。
    """
    
    @abstractmethod
    async def chat(
        self,
        messages: list[dict],
        tools: Optional[list[dict]] = None,
        temperature: float = 0.7,
        max_tokens: int = 4096,
        **kwargs,
    ) -> ProviderResponse:
        """非流式对话
        
        Args:
            messages: OpenAI 格式的消息列表
            tools: OpenAI 格式的工具定义
            temperature: 采样温度
            max_tokens: 最大输出 token 数
            **kwargs: Provider 特有的参数
            
        Returns:
            ProviderResponse: 统一的响应封装
        """
        ...
    
    @abstractmethod
    async def chat_stream(
        self,
        messages: list[dict],
        tools: Optional[list[dict]] = None,
        temperature: float = 0.7,
        max_tokens: int = 4096,
        **kwargs,
    ) -> AsyncIterator[str]:
        """流式对话
        
        返回 token 序列的异步迭代器。
        """
        ...
    
    @abstractmethod
    def count_tokens(self, text: str) -> int:
        """估算文本的 token 数量"""
        ...
    
    @property
    @abstractmethod
    def model_name(self) -> str:
        """当前使用的模型名称"""
        ...
    
    @property
    @abstractmethod
    def provider_name(self) -> str:
        """Provider 名称（如 'openai', 'anthropic', 'google'）"""
        ...
```

### 2.2 统一异常体系

```python
# framework/provider/exceptions.py
"""Provider 统一异常体系"""


class ProviderError(Exception):
    """Provider 错误的基类"""
    def __init__(self, message: str, provider: str = "", status_code: int = 0):
        self.provider = provider
        self.status_code = status_code
        super().__init__(f"[{provider}] {message}")


class RateLimitError(ProviderError):
    """速率限制（429）"""
    retry_after: float = 0.0


class AuthenticationError(ProviderError):
    """认证失败（401）"""


class ContextLengthError(ProviderError):
    """上下文超长"""
    current_tokens: int = 0
    max_tokens: int = 0


class ServiceUnavailableError(ProviderError):
    """服务不可用（503）"""


class ProviderTimeoutError(ProviderError):
    """请求超时"""


class BadRequestError(ProviderError):
    """请求参数错误（400）"""
```

### 3.1 OpenAI Provider

```python
# framework/provider/openai_provider.py
"""OpenAI Provider 适配器"""

from __future__ import annotations
import json
from typing import Any, AsyncIterator, Optional

from openai import AsyncOpenAI

from .base import (
    LLMProvider,
    ProviderResponse,
    ToolCall,
    FunctionCall,
)
from .exceptions import (
    AuthenticationError,
    ContextLengthError,
    ProviderError,
    ProviderTimeoutError,
    RateLimitError,
    ServiceUnavailableError,
)


class OpenAIProvider(LLMProvider):
    """OpenAI Provider 适配器"""
    
    def __init__(
        self,
        api_key: str,
        model: str = "gpt-4o",
        base_url: Optional[str] = None,
        organization: Optional[str] = None,
        timeout: float = 60.0,
        max_retries: int = 3,
    ):
        self._model = model
        self._client = AsyncOpenAI(
            api_key=api_key,
            base_url=base_url,
            organization=organization,
            timeout=timeout,
            max_retries=max_retries,
        )
    
    @property
    def model_name(self) -> str:
        return self._model
    
    @property
    def provider_name(self) -> str:
        return "openai"
    
    async def chat(
        self,
        messages: list[dict],
        tools: Optional[list[dict]] = None,
        temperature: float = 0.7,
        max_tokens: int = 4096,
        **kwargs,
    ) -> ProviderResponse:
        try:
            params = dict(
                model=self._model,
                messages=messages,
                temperature=temperature,
                max_tokens=max_tokens,
            )
            if tools:
                params["tools"] = tools
                params["tool_choice"] = kwargs.get("tool_choice", "auto")
            
            # 传递 provider 特有的参数
            for key in ("response_format", "stop", "presence_penalty", "frequency_penalty"):
                if key in kwargs:
                    params[key] = kwargs[key]
            
            response = await self._client.chat.completions.create(**params)
            
            choice = response.choices[0]
            message = choice.message
            
            # 处理工具调用
            tool_calls = []
            if message.tool_calls:
                for tc in message.tool_calls:
                    tool_calls.append(ToolCall(
                        id=tc.id,
                        type="function",
                        function=FunctionCall(
                            name=tc.function.name,
                            arguments=tc.function.arguments,
                        ),
                    ))
            
            return ProviderResponse(
                content=message.content or "",
                tool_calls=tool_calls,
                model=response.model,
                input_tokens=response.usage.prompt_tokens if response.usage else 0,
                output_tokens=response.usage.completion_tokens if response.usage else 0,
                finish_reason=choice.finish_reason or "",
            )
            
        except Exception as e:
            raise self._translate_error(e)
    
    async def chat_stream(
        self,
        messages: list[dict],
        tools: Optional[list[dict]] = None,
        temperature: float = 0.7,
        max_tokens: int = 4096,
        **kwargs,
    ) -> AsyncIterator[str]:
        try:
            params = dict(
                model=self._model,
                messages=messages,
                temperature=temperature,
                max_tokens=max_tokens,
                stream=True,
                stream_options={"include_usage": True},
            )
            if tools:
                params["tools"] = tools
                params["tool_choice"] = kwargs.get("tool_choice", "auto")
            
            stream = await self._client.chat.completions.create(**params)
            
            async for chunk in stream:
                delta = chunk.choices[0].delta if chunk.choices else None
                if delta and delta.content:
                    yield delta.content
                    
        except Exception as e:
            raise self._translate_error(e)
    
    def count_tokens(self, text: str) -> int:
        # 使用 tiktoken 进行精确计数
        try:
            import tiktoken
            encoding = tiktoken.encoding_for_model(self._model)
            return len(encoding.encode(text))
        except ImportError:
            # 回退：粗略估计（约 4 字符/token）
            return len(text) // 4
    
    def _translate_error(self, error: Exception) -> ProviderError:
        """将 OpenAI SDK 异常转换为统一异常"""
        error_msg = str(error)
        status_code = getattr(error, 'status_code', 0)
        
        if hasattr(error, 'status_code'):
            if error.status_code == 401:
                return AuthenticationError(error_msg, "openai", 401)
            elif error.status_code == 429:
                return RateLimitError(error_msg, "openai", 429)
            elif error.status_code == 503:
                return ServiceUnavailableError(error_msg, "openai", 503)
            elif "context_length" in error_msg.lower() or "maximum context" in error_msg.lower():
                return ContextLengthError(error_msg, "openai", error.status_code)
        
        if isinstance(error, TimeoutError):
            return ProviderTimeoutError(error_msg, "openai", 0)
        
        return ProviderError(error_msg, "openai", status_code)
```

### 3.2 Anthropic Provider

```python
# framework/provider/anthropic_provider.py
"""Anthropic Claude Provider 适配器"""

from __future__ import annotations
import json
from typing import Any, AsyncIterator, Optional

from anthropic import AsyncAnthropic

from .base import (
    LLMProvider,
    ProviderResponse,
    ToolCall,
    FunctionCall,
)
from .exceptions import (
    AuthenticationError,
    ContextLengthError,
    ProviderError,
    RateLimitError,
)


class AnthropicProvider(LLMProvider):
    """Anthropic Claude Provider 适配器
    
    Anthropic 的 API 设计与 OpenAI 有显著差异：
    1. 没有 message.role="system"，system 是独立参数
    2. 消息交替 role="user" 和 role="assistant"
    3. 工具调用格式不同（tool_use content block）
    4. 流式使用 content_block_start/delta 事件
    """
    
    def __init__(
        self,
        api_key: str,
        model: str = "claude-sonnet-4-20250514",
        base_url: Optional[str] = None,
        timeout: float = 60.0,
        max_retries: int = 3,
    ):
        self._model = model
        self._client = AsyncAnthropic(
            api_key=api_key,
            base_url=base_url,
            timeout=timeout,
            max_retries=max_retries,
        )
    
    @property
    def model_name(self) -> str:
        return self._model
    
    @property
    def provider_name(self) -> str:
        return "anthropic"
    
    async def chat(
        self,
        messages: list[dict],
        tools: Optional[list[dict]] = None,
        temperature: float = 0.7,
        max_tokens: int = 4096,
        **kwargs,
    ) -> ProviderResponse:
        try:
            # 从 messages 中分离 system prompt
            system = None
            filtered_messages = []
            for msg in messages:
                if msg["role"] == "system":
                    system = msg["content"]
                else:
                    # 转换 tool 消息格式
                    if msg["role"] == "tool":
                        filtered_messages.append({
                            "role": "user",
                            "content": [
                                {
                                    "type": "tool_result",
                                    "tool_use_id": msg.get("tool_call_id", ""),
                                    "content": msg["content"],
                                }
                            ],
                        })
                    else:
                        filtered_messages.append({
                            "role": msg["role"],
                            "content": msg["content"],
                        })
            
            params = dict(
                model=self._model,
                messages=filtered_messages,
                max_tokens=max_tokens,
                temperature=temperature,
            )
            
            if system:
                params["system"] = system
            
            # 转换工具格式
            if tools:
                anthropic_tools = []
                for tool in tools:
                    if "function" in tool:
                        # OpenAI 格式转 Anthropic 格式
                        func = tool["function"]
                        anthropic_tools.append({
                            "name": func["name"],
                            "description": func.get("description", ""),
                            "input_schema": func["parameters"],
                        })
                    else:
                        anthropic_tools.append(tool)
                params["tools"] = anthropic_tools
            
            response = await self._client.messages.create(**params)
            
            # 解析 Anthropic 的响应
            content = ""
            tool_calls = []
            
            for block in response.content:
                if block.type == "text":
                    content += block.text
                elif block.type == "tool_use":
                    tool_calls.append(ToolCall(
                        id=block.id,
                        type="function",
                        function=FunctionCall(
                            name=block.name,
                            arguments=json.dumps(block.input),
                        ),
                    ))
            
            return ProviderResponse(
                content=content,
                tool_calls=tool_calls,
                model=response.model,
                input_tokens=response.usage.input_tokens if response.usage else 0,
                output_tokens=response.usage.output_tokens if response.usage else 0,
                finish_reason=response.stop_reason or "",
            )
            
        except Exception as e:
            raise self._translate_error(e)
    
    async def chat_stream(
        self,
        messages: list[dict],
        tools: Optional[list[dict]] = None,
        temperature: float = 0.7,
        max_tokens: int = 4096,
        **kwargs,
    ) -> AsyncIterator[str]:
        # 流式实现略 —— 需要处理 Anthropic 的 content_block_start/delta 事件
        # 核心思路：监听 message_delta 事件中的 delta.text
        raise NotImplementedError("Streaming not yet implemented for Anthropic")
    
    def count_tokens(self, text: str) -> int:
        # Anthropic 使用自己的 tokenizer
        try:
            return self._client.count_tokens(text)
        except Exception:
            return len(text) // 4
    
    def _translate_error(self, error: Exception) -> ProviderError:
        error_msg = str(error)
        status_code = getattr(error, 'status_code', 0)
        
        if status_code == 401:
            return AuthenticationError(error_msg, "anthropic", 401)
        elif status_code == 429:
            return RateLimitError(error_msg, "anthropic", 429)
        elif "too many tokens" in error_msg.lower() or "context_length" in error_msg.lower():
            return ContextLengthError(error_msg, "anthropic", status_code)
        
        return ProviderError(error_msg, "anthropic", status_code)
```

```python
# framework/provider/ollama_provider.py
"""Ollama 本地 Provider 适配器"""

from __future__ import annotations
import json
from typing import Any, AsyncIterator, Optional

import httpx

from .base import (
    LLMProvider,
    ProviderResponse,
    ToolCall,
    FunctionCall,
)
from .exceptions import ProviderError


class OllamaProvider(LLMProvider):
    """Ollama Provider 适配器 —— 本地部署"""
    
    def __init__(
        self,
        model: str = "llama3.1",
        base_url: str = "http://localhost:11434",
        timeout: float = 120.0,
    ):
        self._model = model
        self._base_url = base_url.rstrip("/")
        self._timeout = timeout
        self._client = httpx.AsyncClient(timeout=timeout)
    
    @property
    def model_name(self) -> str:
        return self._model
    
    @property
    def provider_name(self) -> str:
        return "ollama"
    
    async def chat(
        self,
        messages: list[dict],
        tools: Optional[list[dict]] = None,
        temperature: float = 0.7,
        max_tokens: int = 4096,
        **kwargs,
    ) -> ProviderResponse:
        # Ollama 的 /api/chat 接口接近 OpenAI 格式
        payload = {
            "model": self._model,
            "messages": messages,
            "options": {
                "temperature": temperature,
                "num_predict": max_tokens,
            },
            "stream": False,
        }
        
        if tools:
            # Ollama 支持 OpenAI 兼容的 tools 格式
            payload["tools"] = tools
        
        try:
            response = await self._client.post(
                f"{self._base_url}/api/chat",
                json=payload,
            )
            response.raise_for_status()
            data = response.json()
            
            message = data.get("message", {})
            content = message.get("content", "")
            
            # 处理工具调用
            tool_calls = []
            raw_tool_calls = message.get("tool_calls", [])
            for tc in raw_tool_calls:
                func = tc.get("function", tc)
                tool_calls.append(ToolCall(
                    id=f"ollama_{hash(str(func))}",
                    type="function",
                    function=FunctionCall(
                        name=func.get("name", ""),
                        arguments=json.dumps(func.get("arguments", {})),
                    ),
                ))
            
            return ProviderResponse(
                content=content,
                tool_calls=tool_calls,
                model=data.get("model", self._model),
                input_tokens=data.get("prompt_eval_count", 0),
                output_tokens=data.get("eval_count", 0),
                finish_reason=data.get("done_reason", ""),
            )
            
        except httpx.HTTPStatusError as e:
            raise ProviderError(
                f"Ollama request failed: {e.response.text}",
                "ollama",
                e.response.status_code,
            )
        except httpx.RequestError as e:
            raise ProviderError(
                f"Ollama connection failed: {e}",
                "ollama",
                0,
            )
    
    async def chat_stream(
        self,
        messages: list[dict],
        tools: Optional[list[dict]] = None,
        temperature: float = 0.7,
        max_tokens: int = 4096,
        **kwargs,
    ) -> AsyncIterator[str]:
        payload = {
            "model": self._model,
            "messages": messages,
            "options": {
                "temperature": temperature,
                "num_predict": max_tokens,
            },
            "stream": True,
        }
        
        async with httpx.AsyncClient(timeout=self._timeout) as client:
            async with client.stream("POST", f"{self._base_url}/api/chat", json=payload) as response:
                async for line in response.aiter_lines():
                    if line.strip():
                        try:
                            chunk = json.loads(line)
                            if "message" in chunk and "content" in chunk["message"]:
                                yield chunk["message"]["content"]
                        except json.JSONDecodeError:
                            continue
    
    def count_tokens(self, text: str) -> int:
        return len(text) // 4  # Ollama 不提供 token 计数
    
    async def close(self):
        await self._client.aclose()
```

## 四、运行时热切换与降级

### 4.1 Router Provider

Router Provider 是适配层的核心组件，负责在多个 Provider 之间动态路由请求：

```python
# framework/provider/router.py
"""Provider 路由器 —— 热切换与降级"""

from __future__ import annotations
import asyncio
import logging
import time
from dataclasses import dataclass, field
from enum import Enum
from typing import Any, AsyncIterator, Optional

from .base import LLMProvider, ProviderResponse
from .exceptions import (
    ProviderError,
    RateLimitError,
    ServiceUnavailableError,
)

logger = logging.getLogger(__name__)


class ProviderStatus(Enum):
    ACTIVE = "active"
    DEGRADED = "degraded"  # 可用但延迟高
    BACKOFF = "backoff"    # 临时退避
    DOWN = "down"           # 不可用


@dataclass
class ProviderState:
    """Provider 运行时状态"""
    name: str
    provider: LLMProvider
    status: ProviderStatus = ProviderStatus.ACTIVE
    priority: int = 0        # 值越小优先级越高
    error_count: int = 0
    last_error_at: float = 0.0
    backoff_until: float = 0.0
    avg_latency_ms: float = 0.0
    total_requests: int = 0
    failed_requests: int = 0


class RouterProvider(LLMProvider):
    """Provider 路由器 —— 支持优先级路由和故障转移
    
    路由策略：
    1. 按优先级排序，选最高优先级的 ACTIVE Provider
    2. 如果连续错误超过阈值，标记为 BACKOFF 并降级
    3. 如果所有 Provider 都不可用，抛出 NoAvailableProviderError
    """
    
    def __init__(
        self,
        providers: list[tuple[LLMProvider, int]],  # (provider, priority)
        max_errors_before_backoff: int = 3,
        backoff_seconds: float = 30.0,
        fallback_on_error: bool = True,
    ):
        self._states = [
            ProviderState(
                name=p.provider_name,
                provider=p,
                priority=pri,
            )
            for p, pri in providers
        ]
        self._states.sort(key=lambda s: s.priority)
        self.max_errors = max_errors_before_backoff
        self.backoff_seconds = backoff_seconds
        self.fallback_on_error = fallback_on_error
    
    @property
    def model_name(self) -> str:
        active = self._get_active()
        return active.provider.model_name if active else "no_provider"
    
    @property
    def provider_name(self) -> str:
        return "router"
    
    async def chat(
        self,
        messages: list[dict],
        tools: Optional[list[dict]] = None,
        temperature: float = 0.7,
        max_tokens: int = 4096,
        **kwargs,
    ) -> ProviderResponse:
        last_error = None
        
        # 按照优先级尝试 Provider
        for state in self._states:
            if not self._is_available(state):
                continue
            
            try:
                start = time.monotonic()
                response = await state.provider.chat(
                    messages, tools, temperature, max_tokens, **kwargs
                )
                latency = (time.monotonic() - start) * 1000
                
                # 更新状态
                state.total_requests += 1
                state.avg_latency_ms = (
                    state.avg_latency_ms * 0.9 + latency * 0.1
                )
                state.error_count = 0
                
                return response
                
            except RateLimitError as e:
                logger.warning(f"[Router] {state.name} rate limited: {e}")
                state.error_count += 1
                state.last_error_at = time.time()
                last_error = e
                
                if state.error_count >= self.max_errors:
                    self._backoff(state)
                
            except ServiceUnavailableError as e:
                logger.warning(f"[Router] {state.name} unavailable: {e}")
                state.error_count += 1
                state.last_error_at = time.time()
                last_error = e
                
                if state.error_count >= self.max_errors:
                    state.status = ProviderStatus.DOWN
                
            except ProviderError as e:
                logger.error(f"[Router] {state.name} error: {e}")
                state.error_count += 1
                state.last_error_at = time.time()
                last_error = e
            
            # 如果不允许降级，抛出异常
            if not self.fallback_on_error:
                raise last_error
        
        # 所有 Provider 都不可用
        raise NoAvailableProviderError(
            f"No available providers (tried: "
            f"{[s.name for s in self._states if s.status != ProviderStatus.DOWN]})"
        )
    
    async def chat_stream(
        self,
        messages: list[dict],
        tools: Optional[list[dict]] = None,
        temperature: float = 0.7,
        max_tokens: int = 4096,
        **kwargs,
    ) -> AsyncIterator[str]:
        active = self._get_active()
        if active is None:
            raise NoAvailableProviderError("No available providers")
        
        async for token in active.provider.chat_stream(
            messages, tools, temperature, max_tokens, **kwargs
        ):
            yield token
    
    def count_tokens(self, text: str) -> int:
        active = self._get_active()
        if active:
            return active.provider.count_tokens(text)
        return len(text) // 4
    
    def _is_available(self, state: ProviderState) -> bool:
        """检查 Provider 是否可用"""
        if state.status == ProviderStatus.DOWN:
            return False
        if state.status == ProviderStatus.BACKOFF:
            if time.time() >= state.backoff_until:
                state.status = ProviderStatus.ACTIVE
                return True
            return False
        return True
    
    def _backoff(self, state: ProviderState):
        """将 Provider 设为退避状态"""
        state.status = ProviderStatus.BACKOFF
        state.backoff_until = time.time() + self.backoff_seconds
        logger.info(
            f"[Router] Backing off {state.name} "
            f"for {self.backoff_seconds}s (errors: {state.error_count})"
        )
    
    def _get_active(self) -> Optional[ProviderState]:
        """获取当前最高优先级的可用 Provider"""
        for state in self._states:
            if self._is_available(state):
                return state
        return None


class NoAvailableProviderError(ProviderError):
    """没有可用的 Provider"""
    pass
```

### 5.3 延迟和成本的平衡

不同 Provider 的延迟和成本差异巨大，Router 可以根据实时数据做智能路由：

| 场景 | 推荐策略 |
|------|---------|
| 高可用要求 | 配置 3+ Provider，故障自动切换 |
| 成本敏感 | 优先使用本地/低价 Provider，复杂任务路由到高价模型 |
| 延迟敏感 | 优先使用响应最快的 Provider，记录滚动平均延迟 |
| 合规要求 | 数据不出境的场景强制使用本地 Provider |

## 关键概念速查

| 术语 | 解释 |
|------|------|
| Provider Adapter | Provider 适配层，将不同 LLM API 的差异封装在统一接口之后 |
| LLMProvider | 统一接口抽象基类，所有 Provider 适配器实现的共同契约 |
| RouterProvider | Provider 路由器，支持优先级路由、故障转移、热切换 |
| ProviderState | Provider 运行时状态，跟踪健康度、延迟、错误计数 |
| Backoff | 退避策略，连续错误后将 Provider 临时降级以避免雪崩 |
| 功能最小公倍数 | 适配层只暴露所有 Provider 都支持的功能子集 |
| 错误标准化 | 将不同 Provider 的错误类型映射为框架统一的异常体系 |
| 功能协商 | 运行时确认 Provider 支持的特性（流式、工具调用等） |
| NoAvailableProviderError | 所有 Provider 都不可用时抛出的异常 |
