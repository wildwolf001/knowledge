# 21.2 主循环设计 —— Async Generator 模式、Turn 管理、Stop Hooks

> 主循环（Main Loop）是 Agent 框架的心脏。它决定了 Agent 如何思考、行动、观察，以及何时停止。本节的实现采用 Async Generator 模式，让主循环的每一步都可以被消费方（前端、日志、调试器）实时追踪。

---

## 一、主循环的核心架构

### 1.1 什么是主循环？

主循环是 Agent 运行时的核心控制逻辑，它实现了一个 **ReAct（Reasoning + Acting）循环**：

```
Loop {
  1. Think   : 将当前上下文 + 记忆 → LLM，获取下一步行动决策
  2. Action  : 执行决策（调用工具、输出最终回答等）
  3. Observe : 获取执行结果
  4. Repeat  : 直到满足停止条件
}
```

在经典的 ReAct 论文（Yao et al., 2023）中，这个循环通过"思考-行动-观察"的交错进行逐步推理。本框架的实现将这个过程抽象为一个 Async Generator，每个 `Turn` 作为一次迭代的产出物。

### 1.2 为什么选择 Async Generator？

Python 的 Async Generator（`async def ... yield`）是实现 Agent 主循环的理想模式，原因如下：

| 特性 | 解决的问题 |
|------|-----------|
| **惰性求值（Lazy Evaluation）** | 调用方可以按需消费 Turn，不需要等所有 Turn 完成 |
| **背压支持（Backpressure）** | 消费方速度慢时，生成方自然等待 |
| **中断友好** | 可以在任意 `yield` 点安全停止，不需要清理复杂的状态机 |
| **流式兼容** | 天然适配 SSE、WebSocket 等流式传输协议 |
| **调试友好** | 可以在每个 Turn 之间插入断点、日志、检查 |

对比另两种方案：

- **方案 A：返回完整列表** —— 等待所有 Turn 完成才返回，前端需要等待全过程，无法做流式渲染。对于长任务（如 20 轮迭代），用户体验极差。
- **方案 B：回调函数** —— 每完成一个 Turn 调用回调。控制流反转（Inversion of Control），异常处理复杂，多个回调之间的状态管理容易出错。
- **方案 C：Async Generator（本框架选择）** —— 保留自然的顺序控制流，同时支持逐步产出。调用方做 `async for turn in agent.run(...)` 既可实时展示，也可只取最终结果。

## 二、完整的主循环实现

### 2.1 Turn 管理

Turn 是主循环的基本迭代单元。每个 Turn 记录 Agent 一轮完整的思考-行动-观察过程。

```python
# framework/turn.py
"""Turn 管理 —— 主循环的一次迭代单元"""

from __future__ import annotations
import time
import uuid
from dataclasses import dataclass, field
from enum import Enum
from typing import Any, Optional


class FinishReason(str, Enum):
    """停止原因枚举"""
    GOAL_ACHIEVED = "goal_achieved"       # 目标完成
    MAX_TURNS = "max_turns"               # 达到最大轮次
    LOOP_DETECTED = "loop_detected"       # 检测到循环
    STOP_HOOK = "stop_hook"               # 用户自定义 Stop Hook 触发
    SECURITY_REJECTION = "security_rejection"  # 安全拦截
    ERROR = "error"                       # 运行时错误
    CANCELLED = "cancelled"               # 用户取消
    TOOL_FAILURE = "tool_failure"         # 工具调用失败


@dataclass
class Turn:
    """Agent 的一轮迭代
    
    每个 Turn 代表 Think → Act → Observe 完整的一轮。
    """
    turn_id: int
    session_id: str = ""
    
    # 思考阶段
    thought: Optional[str] = None
    model: str = ""
    input_tokens: int = 0
    output_tokens: int = 0
    
    # 行动阶段
    action_type: str = ""   # "tool_call" | "final_answer" | "thinking"
    tool_name: Optional[str] = None
    tool_args: Optional[dict] = None
    tool_call_id: Optional[str] = None
    
    # 观察阶段
    observation: Optional[str] = None
    observation_error: Optional[str] = None
    
    # 控制信息
    finish_reason: Optional[FinishReason] = None
    latency_ms: float = 0.0
    turn_start_at: float = 0.0
    turn_end_at: float = 0.0
    metadata: dict = field(default_factory=dict)
    
    def mark_start(self):
        self.turn_start_at = time.monotonic()
    
    def mark_end(self):
        self.turn_end_at = time.monotonic()
        self.latency_ms = (self.turn_end_at - self.turn_start_at) * 1000
```

### 2.2 Stop Hooks 系统

Stop Hooks 是主循环的刹车系统。每个 Hook 是一个独立检查器，一旦判定"应该停止"，就发出停止信号。

```python
# framework/stop_hooks.py
"""Stop Hooks —— 主循环的停止策略"""

from __future__ import annotations
from abc import ABC, abstractmethod
from dataclasses import dataclass, field
from typing import Any, Optional

from .turn import FinishReason, Turn


@dataclass
class StopSignal:
    """停止信号"""
    should_stop: bool
    reason: Optional[FinishReason] = None
    message: str = ""


class StopHook(ABC):
    """停止钩子 —— 每次 Turn 完成后检查是否应该停止"""
    
    @abstractmethod
    async def check(self, history: list[Turn], context: Any = None) -> StopSignal:
        ...


class MaxTurnsHook(StopHook):
    """最大轮次检测 —— 防止 Agent 无限循环"""
    
    def __init__(self, max_turns: int = 20):
        self.max_turns = max_turns
    
    async def check(self, history: list[Turn], context: Any = None) -> StopSignal:
        if len(history) >= self.max_turns:
            return StopSignal(
                should_stop=True,
                reason=FinishReason.MAX_TURNS,
                message=f"Reached maximum turns ({self.max_turns})"
            )
        return StopSignal(should_stop=False)


class LoopDetectionHook(StopHook):
    """循环检测 —— 检测 Agent 是否在原地打转
    
    策略：如果最近 N 轮的 Action + Observation 与之前某段高度相似，判定为循环。
    """
    
    def __init__(self, window_size: int = 3, threshold: float = 0.85):
        self.window_size = window_size
        self.threshold = threshold
    
    def _turn_signature(self, turn: Turn) -> str:
        """生成 Turn 的签名用于相似度比较"""
        # 使用工具名称和参数的关键部分
        sig = f"{turn.action_type}:{turn.tool_name}"
        if turn.observation:
            # 取观察结果的前 100 个字符作为签名的一部分
            sig += f"|{turn.observation[:100]}"
        return sig
    
    def _similarity(self, sig1: str, sig2: str) -> float:
        """简单的字符串相似度（基于公共子序列）"""
        # 实际生产环境中可以使用 TF-IDF + Cosine 相似度
        # 这里使用简洁的 Jaccard 相似度
        set1 = set(sig1.split())
        set2 = set(sig2.split())
        if not set1 or not set2:
            return 0.0
        return len(set1 & set2) / len(set1 | set2)
    
    async def check(self, history: list[Turn], context: Any = None) -> StopSignal:
        if len(history) < self.window_size * 2:
            return StopSignal(should_stop=False)
        
        # 取最近 N 轮的签名
        recent = history[-self.window_size:]
        recent_sigs = [self._turn_signature(t) for t in recent]
        
        # 与之前的窗口对比
        for i in range(len(history) - self.window_size * 2):
            window = history[i:i + self.window_size]
            window_sigs = [self._turn_signature(t) for t in window]
            
            # 计算两个窗口的平均相似度
            similarities = [
                self._similarity(rs, ws)
                for rs, ws in zip(recent_sigs, window_sigs)
            ]
            avg_sim = sum(similarities) / len(similarities)
            
            if avg_sim > self.threshold:
                return StopSignal(
                    should_stop=True,
                    reason=FinishReason.LOOP_DETECTED,
                    message=f"Loop detected: window starting at turn {i} "
                            f"matches recent turns (similarity={avg_sim:.2f})"
                )
        
        return StopSignal(should_stop=False)


class GoalAchievedHook(StopHook):
    """目标达成检测 —— 检测 Agent 是否已经给出最终答案"""
    
    async def check(self, history: list[Turn], context: Any = None) -> StopSignal:
        if not history:
            return StopSignal(should_stop=False)
        
        last_turn = history[-1]
        # 当 LLM 的 response 中没有 tool_call，而是直接输出 final answer 时
        if last_turn.action_type == "final_answer":
            return StopSignal(
                should_stop=True,
                reason=FinishReason.GOAL_ACHIEVED,
                message="Agent produced final answer"
            )
        
        return StopSignal(should_stop=False)


class CompositeStopHook(StopHook):
    """组合 Stop Hook —— 多个 Hook 的 OR 逻辑"""
    
    def __init__(self, hooks: list[StopHook]):
        self.hooks = hooks
    
    async def check(self, history: list[Turn], context: Any = None) -> StopSignal:
        for hook in self.hooks:
            signal = await hook.check(history, context)
            if signal.should_stop:
                return signal
        return StopSignal(should_stop=False)
```

### 2.3 主循环的完整实现

下面给出主循环的完整代码。这是框架最核心的部分，实现了 Async Generator 模式下的 Think → Act → Observe 循环。

```python
# framework/main_loop.py
"""主循环 —— Async Generator 模式下的 Think → Act → Observe"""

from __future__ import annotations
import asyncio
import json
import logging
import time
from typing import Any, AsyncIterator, Callable, Optional

from .turn import FinishReason, Turn
from .stop_hooks import (
    CompositeStopHook,
    GoalAchievedHook,
    LoopDetectionHook,
    MaxTurnsHook,
    StopHook,
    StopSignal,
)

logger = logging.getLogger(__name__)


class AgentLoop:
    """Agent 主循环 —— 异步生成器模式"""
    
    def __init__(
        self,
        llm_provider,               # LLMProvider 实例（21.3 节定义）
        tool_registry,              # ToolRegistry 实例（工具的注册和调用）
        memory,                     # Memory 实例（21.4 节定义）
        system_prompt: str = "You are a helpful AI assistant.",
        max_turns: int = 20,
        loop_detection_window: int = 3,
        loop_detection_threshold: float = 0.85,
        before_turn_hook: Optional[Callable] = None,   # 每轮开始前的回调
        after_turn_hook: Optional[Callable] = None,    # 每轮结束后的回调
    ):
        self.provider = llm_provider
        self.tools = tool_registry
        self.memory = memory
        self.system_prompt = system_prompt
        self.before_turn_hook = before_turn_hook
        self.after_turn_hook = after_turn_hook
        
        # 默认 Stop Hooks
        self._stop_hooks: list[StopHook] = [
            MaxTurnsHook(max_turns=max_turns),
            LoopDetectionHook(
                window_size=loop_detection_window,
                threshold=loop_detection_threshold,
            ),
            GoalAchievedHook(),
        ]
    
    def register_stop_hook(self, hook: StopHook) -> None:
        """注册自定义 Stop Hook"""
        self._stop_hooks.append(hook)
    
    async def run(self, task: str, session_id: str = "") -> AsyncIterator[Turn]:
        """运行 Agent 主循环，异步生成 Turn 序列
        
        使用方式：
            async for turn in agent_loop.run("查询北京的天气"):
                print(f"Turn {turn.turn_id}: {turn.thought}")
        """
        # 初始化上下文
        await self.memory.add("user", task, {"session_id": session_id})
        messages = await self.memory.get_context()
        
        # 组装 system message
        system_msg = {"role": "system", "content": self.system_prompt}
        full_messages = [system_msg] + [
            {"role": m.role, "content": m.content}
            for m in messages
        ]
        
        # 获取工具 schema（LLM Function Calling 所需）
        tool_schemas = self.tools.get_schemas() if hasattr(self.tools, 'get_schemas') else []
        
        history: list[Turn] = []
        
        for turn_num in range(1, self.max_turns + 1):
            # 创建 Turn 对象
            turn = Turn(
                turn_id=turn_num,
                session_id=session_id,
            )
            turn.mark_start()
            
            try:
                # ── 前置 Hook ──
                if self.before_turn_hook:
                    await self.before_turn_hook(turn)
                
                # Step 1: Think —— 调用 LLM 获取决策
                logger.debug(f"[Turn {turn_num}] Calling LLM...")
                
                response = await self.provider.chat(
                    messages=full_messages,
                    tools=tool_schemas if tool_schemas else None,
                )
                
                # 记录 token 用量
                turn.input_tokens = getattr(response, 'input_tokens', 0)
                turn.output_tokens = getattr(response, 'output_tokens', 0)
                turn.model = getattr(response, 'model', 'unknown')
                
                # Step 2: 解析 LLM 响应 —— 判断是工具调用还是最终回答
                if self._has_tool_calls(response):
                    # → 工具调用
                    tool_call = response.tool_calls[0]
                    turn.action_type = "tool_call"
                    turn.tool_name = tool_call.function.name
                    turn.tool_args = json.loads(tool_call.function.arguments)
                    turn.tool_call_id = tool_call.id
                    turn.thought = response.content if response.content else ""
                    
                    # 将 LLM 响应记录到对话历史
                    full_messages.append({
                        "role": "assistant",
                        "content": response.content or "",
                        "tool_calls": [
                            {
                                "id": tool_call.id,
                                "type": "function",
                                "function": {
                                    "name": tool_call.function.name,
                                    "arguments": tool_call.function.arguments,
                                }
                            }
                        ],
                    })
                    
                    # Step 3: Act —— 执行工具调用
                    yield turn  # yield before execution (for streaming UX)
                    
                    logger.debug(
                        f"[Turn {turn_num}] Executing tool: "
                        f"{turn.tool_name}({turn.tool_args})"
                    )
                    
                    try:
                        result = await self.tools.execute(
                            turn.tool_name, turn.tool_args
                        )
                        turn.observation = str(result.data) if result.success else str(result.error)
                        turn.observation_error = None if result.success else result.error
                    except Exception as e:
                        turn.observation = f"Error: {str(e)}"
                        turn.observation_error = str(e)
                        logger.warning(f"[Turn {turn_num}] Tool execution failed: {e}")
                    
                    # 将工具执行结果记录到对话历史
                    full_messages.append({
                        "role": "tool",
                        "content": turn.observation,
                        "tool_call_id": turn.tool_call_id,
                    })
                    
                    # 记录到记忆系统
                    await self.memory.add("assistant", turn.thought, {
                        "session_id": session_id,
                        "turn_id": turn_num,
                        "tool_call": turn.tool_name,
                    })
                    await self.memory.add("tool", turn.observation, {
                        "session_id": session_id,
                        "turn_id": turn_num,
                        "tool_name": turn.tool_name,
                    })
                    
                else:
                    # → 最终回答
                    turn.action_type = "final_answer"
                    turn.thought = response.content
                    turn.observation = response.content
                    
                    # 记录到对话历史
                    full_messages.append({
                        "role": "assistant",
                        "content": response.content or "",
                    })
                    
                    await self.memory.add("assistant", response.content, {
                        "session_id": session_id,
                        "turn_id": turn_num,
                    })
                
                # Step 4: 检查 Stop Hooks
                composite_hook = CompositeStopHook(self._stop_hooks)
                stop_signal = await composite_hook.check(history + [turn])
                
                if stop_signal.should_stop:
                    turn.finish_reason = stop_signal.reason
                    turn.mark_end()
                    
                    # 如果是最终回答，也 yield 这个 turn
                    if turn.action_type == "final_answer":
                        yield turn
                    
                    logger.info(
                        f"[Session {session_id}] Agent stopped: "
                        f"{stop_signal.reason.value} — {stop_signal.message}"
                    )
                    return
                
                turn.mark_end()
                history.append(turn)
                
                # ── 后置 Hook ──
                if self.after_turn_hook:
                    await self.after_turn_hook(turn)
                
                # yield completed turn to consumer
                yield turn
                
            except asyncio.CancelledError:
                # 处理用户取消
                turn.finish_reason = FinishReason.CANCELLED
                turn.mark_end()
                yield turn
                logger.info(f"[Session {session_id}] Agent cancelled at turn {turn_num}")
                return
                
            except Exception as e:
                turn.finish_reason = FinishReason.ERROR
                turn.observation_error = str(e)
                turn.mark_end()
                yield turn
                logger.error(f"[Session {session_id}] Error at turn {turn_num}: {e}")
                return
        
        # 达到最大轮次但未触发 MaxTurnsHook（兜底）
        if history:
            last_turn = history[-1]
            last_turn.finish_reason = FinishReason.MAX_TURNS
            last_turn.mark_end()
    
    @staticmethod
    def _has_tool_calls(response) -> bool:
        """判断 LLM 响应是否包含工具调用"""
        return (
            hasattr(response, 'tool_calls')
            and response.tool_calls
            and len(response.tool_calls) > 0
        )
```

### 2.4 使用主循环

下面展示如何实例化主循环并消费其输出：

```python
# examples/run_agent.py
"""使用主循环的示例"""

import asyncio
from framework.main_loop import AgentLoop
from framework.stop_hooks import StopHook, StopSignal, FinishReason
from framework.turn import Turn

# 假设已经创建了 provider, tools, memory
# provider = OpenAIProvider(api_key="...")
# tools = ToolRegistry()
# memory = InMemoryMemory()


class CustomStopHook(StopHook):
    """自定义 Stop Hook：检测特定关键词"""
    
    def __init__(self, keyword: str):
        self.keyword = keyword
    
    async def check(self, history: list[Turn], context=None) -> StopSignal:
        for turn in history:
            if turn.observation and self.keyword in turn.observation:
                return StopSignal(
                    should_stop=True,
                    reason=FinishReason.STOP_HOOK,
                    message=f"Keyword '{self.keyword}' detected"
                )
        return StopSignal(should_stop=False)


async def main():
    loop = AgentLoop(
        llm_provider=provider,
        tool_registry=tools,
        memory=memory,
        system_prompt="You are a helpful assistant with tools.",
        max_turns=15,
    )
    
    # 注册自定义 Stop Hook
    loop.register_stop_hook(CustomStopHook("emergency_stop"))
    
    # 消费 Async Generator
    async for turn in loop.run("计算 25 * 13 + 7 的结果"):
        status = "RUNNING" if not turn.finish_reason else turn.finish_reason.value
        print(f"[{status}] Turn {turn.turn_id}: "
              f"thought={turn.thought[:50] if turn.thought else '...'} "
              f"latency={turn.latency_ms:.0f}ms")
        
        if turn.finish_reason == FinishReason.GOAL_ACHIEVED:
            print(f"\n=== Final Answer: {turn.observation} ===")
        
        if turn.finish_reason == FinishReason.LOOP_DETECTED:
            print(f"\n!!! Loop detected, stopping")


if __name__ == "__main__":
    asyncio.run(main())
```

## 三、Stop Hooks 的详细设计

### 3.1 Hook 执行时机

Stop Hooks 的检查发生在每个 Turn 完成**之后**、下一个 Turn 开始**之前**：

```
Turn N Start → Think → Act → Observe → Turn N End
                                           │
                                    CompositeStopHook.check(history)
                                           │
                              ┌────────────┼────────────┐
                              ▼            ▼            ▼
                        MaxTurnsHook  LoopDetector  GoalAchieved
                              │            │            │
                              └────────────┼────────────┘
                                           ▼
                                    Should stop?
                                   /            \
                                 Yes             No
                                  │              │
                              Finish           Turn N+1
                              Session           Start
```

### 3.2 循环检测的局限性

循环检测是一个启发式算法，存在以下权衡：

- **窗口大小**：窗口太小（1-2轮）容易误判；窗口太大（>10轮）会漏掉短循环
- **相似度阈值**：0.85 是一个经验值。对于工具调用丰富的场景（参数每次都不同），误判率低；对于简单场景（同样是 get_weather），容易误判
- **签名的粒度**：只使用工具名称和观察结果作为签名，可能遗漏"语义相同但表达不同"的循环。更复杂的实现可以使用 embedding 相似度

### 3.3 生产级建议

1. **Stop Hooks 的优先级**：MaxTurnsHook 永远放在第一位（安全兜底）
2. **Hook 的超时**：Stop Hook 本身不应该阻塞太久，建议设置 1 秒超时
3. **异步安全**：Stop Hooks 之间没有依赖关系，可以并行检查

## 四、主循环的状态机视角

主循环本质上是一个状态机，状态转移如下：

```
                    ┌─────────────────────────────────────┐
                    │           Agent Running              │
                    │                                      │
    ┌─────────┐     │  ┌─────────┐    ┌─────────┐         │
    │  START  │────▶│  │ THINK   │───▶│  ACT    │───▶...  │
    └─────────┘     │  └─────────┘    └─────────┘         │
                    │       ▲              │               │
                    │       │   ┌──────────▼───────┐      │
                    │       │   │   OBSERVE        │      │
                    │       └───│  (Tool Result)   │      │
                    │           └──────────────────┘      │
                    │                                      │
                    │           Stop Hook Check            │
                    └──────────────────┬──────────────────┘
                                       │
                                       ▼
                              ┌─────────────────┐
                              │  END (Finished)  │
                              │ - goal_achieved  │
                              │ - max_turns      │
                              │ - loop_detected  │
                              │ - error          │
                              │ - cancelled      │
                              └─────────────────┘
```

## 五、主循环的性能考量

### 5.1 Token 消耗计算

主循环每轮的 Token 消耗呈现**递增**特性：

```
Turn 1: system(500) + user(50)              ≈ 550 tokens input
Turn 2: system(500) + user(50) + turn1(300) ≈ 850 tokens input
Turn 3: system(500) + user(50) + turn1+2    ≈ 1150 tokens input
...
Turn 10:                                    ≈ 4000+ tokens input
```

这意味着：
- 每轮 LLM 调用的输入长度线性增长
- 如果 Agent 运行超过 10-15 轮，仅 Prompt 就可能超过 8K tokens
- 解决方案：滑动窗口（只保留最近 N 轮）+ 中间轮次摘要

详细的内存管理策略见 21.4 节「会话管理」和第 7 章。

### 5.2 并发与 Cancellation

主循环使用 `asyncio` 实现，天然支持并发和取消：

```python
# 超时控制
async def run_with_timeout(loop: AgentLoop, task: str, timeout: float = 30.0):
    try:
        async with asyncio.timeout(timeout):
            async for turn in loop.run(task):
                process_turn(turn)
    except asyncio.TimeoutError:
        print(f"Agent task timed out after {timeout}s")
```

## 关键概念速查

| 术语 | 解释 |
|------|------|
| Main Loop | Agent 框架主循环，实现 Think → Act → Observe 迭代 |

| Turn | 主循环的一次完整迭代，包含思考/行动/观察三个阶段 |

| MaxTurnsHook | 最大轮次限制，防止无限循环的安全兜底 |
| GoalAchievedHook | 目标达成检测，当 LLM 输出最终回答时停止 |
| FinishReason | 停止原因枚举，记录 Agent 为什么停止 |
| composite pattern | 组合模式，将多个 Stop Hook 组合为 OR 逻辑 |
| ReAct | Reasoning + Acting，Agent 通过交替思考和行动完成任务 |
