# 19.5 错误回放与根因分析 —— 完整上下文快照、可复现的调试环境

> Agent 的错误往往不是简单的"返回了一个错误码"——它是 50 步推理、工具调用和观察结果交织后的"偏差累积"。当错误出现时，你需要的不是日志片段，而是**完整的上下文快照**和**可复现的调试环境**。错误回放（Error Replay）技术让开发者可以像调试单线程程序一样调试 Agent 的每一步。

---

## 一、为什么 Agent 的调试如此困难？

### 1.1 传统调试 vs Agent 调试

```
传统程序调试：
错误 → 查看堆栈 → 定位代码行 → 修复 → 复现验证
确定性：同一输入始终产生同一输出

Agent 调试：
错误 → Agent 给出了错误答案
    → 是 LLM 推理错了？Tool 返回错了？Prompt 设计问题？
    → 重跑一次可能得到不同的结果（非确定性）
    → 50 步的中间状态需要全部检查
    → 工具返回数据可能已经过期或改变
```

Agent 调试的三个核心困难：

1. **非确定性（Non-determinism）**：LLM 的采样机制导致相同输入可能产生不同输出（详见第 18.1 节关于概率爆炸的讨论）。这意味着"复现"一个 Agent 错误本身就很困难。

2. **状态爆炸**：Agent 的每一步都会更新内部状态（思考、记忆、工具结果），50 步后的状态空间大到无法手动追踪。

3. **外部依赖**：Agent 调用外部工具和 API，这些工具的返回数据随时间变化。一周后的搜索结果已完全不同——错误无法复现。

### 1.2 错误回放的价值

错误回放（Record & Replay）的核心思想是：**在执行时完整记录 Agent 的每一步状态，在调试时精确还原每一个中间结果**，让开发者可以在"时间冻结"的环境中分析错误。

---

## 二、Record & Replay 机制

### 2.1 完整上下文快照（Record Phase）

在执行阶段，Record 组件捕获 Agent 每一步的所有相关状态，形成一个可独立加载的快照：

```python
from dataclasses import dataclass, field, asdict
from typing import Optional, Any
from datetime import datetime
import json
import pickle
import hashlib

@dataclass
class Snapshot:
    """Agent 单步快照——完整记录一步的全部状态"""

    # 时间标识
    timestamp: datetime = field(default_factory=datetime.now)
    step_index: int = 0

    # 1. 外部可见状态
    user_input: str = ""                    # 用户当前的输入
    system_prompt: str = ""                 # 当前的系统指令
    conversation_history: list = field(default_factory=list)  # 完整对话历史

    # 2. Agent 内部状态
    current_thought: Optional[str] = None   # 当前的推理内容
    current_action: Optional[dict] = None   # 当前的动作（工具名+参数）
    current_observation: Optional[str] = None # 动作返回结果
    agent_memory: dict = field(default_factory=dict)  # Agent 内部记忆

    # 3. LLM 调用详情
    llm_request: Optional[dict] = None      # 发送给 LLM 的完整请求
    llm_response: Optional[dict] = None     # LLM 返回的完整响应
    llm_tokens: dict = field(default_factory=dict)  # Token 明细

    # 4. Token 级信息
    token_usage: int = 0                    # 当前步骤 Token 消耗
    cumulative_tokens: int = 0              # 累积 Token 消耗
    context_usage_pct: float = 0.0          # 上下文使用百分比

    # 5. 元数据
    model: str = ""                         # 当前使用的模型
    temperature: float = 0.0                # 采样温度
    duration_ms: float = 0.0                # 执行耗时

    # 6. 校验
    checksum: str = ""                      # 快照内容校验和

    def __post_init__(self):
        self.checksum = self._compute_checksum()

    def _compute_checksum(self) -> str:
        """计算快照的校验和，用于完整性验证"""
        content = json.dumps(asdict(self), default=str, ensure_ascii=False)
        return hashlib.sha256(content.encode()).hexdigest()[:16]


class Recorder:
    """Agent 执行记录器——捕获每一步的完整快照"""

    def __init__(self, storage_path: str = "./replays"):
        self.storage_path = storage_path
        self.snapshots: list[Snapshot] = []
        self.session_id: str = datetime.now().strftime("%Y%m%d_%H%M%S")
        self._ensure_storage()

    def _ensure_storage(self):
        import os
        os.makedirs(f"{self.storage_path}/{self.session_id}", exist_ok=True)

    def record_snapshot(self, snapshot: Snapshot):
        """记录一步快照"""
        self.snapshots.append(snapshot)

        # 保存到磁盘（支持 JSON 和 Pickle 两种格式）
        self._save_snapshot(snapshot)

    def _save_snapshot(self, snapshot: Snapshot):
        """将快照保存到磁盘"""
        step_file = f"{self.storage_path}/{self.session_id}/step_{snapshot.step_index:04d}"

        # JSON 格式（人类可读）
        with open(f"{step_file}.json", "w", encoding="utf-8") as f:
            json.dump(asdict(snapshot), f, default=str, ensure_ascii=False, indent=2)

        # Pickle 格式（精确还原 Python 对象）
        with open(f"{step_file}.pkl", "wb") as f:
            pickle.dump(snapshot, f)

    def get_session_manifest(self) -> dict:
        """生成会话的完整清单"""
        return {
            "session_id": self.session_id,
            "total_steps": len(self.snapshots),
            "start_time": self.snapshots[0].timestamp.isoformat() if self.snapshots else None,
            "end_time": self.snapshots[-1].timestamp.isoformat() if self.snapshots else None,
            "total_duration_ms": sum(s.duration_ms for s in self.snapshots),
            "total_tokens": sum(s.token_usage for s in self.snapshots),
            "models_used": list(set(s.model for s in self.snapshots if s.model)),
            "snapshots": [
                {
                    "step": s.step_index,
                    "file": f"step_{s.step_index:04d}.json",
                    "checksum": s.checksum
                }
                for s in self.snapshots
            ]
        }
```

### 2.2 错误回放引擎（Replay Phase）

在调试阶段，Replay 引擎读取快照，按步骤还原 Agent 的完整执行过程：

```python
class ReplayEngine:
    """错误回放引擎——读取快照并逐步还原执行过程"""

    def __init__(self, session_dir: str):
        self.session_dir = session_dir
        self.snapshots: list[Snapshot] = []
        self.current_step: int = 0
        self.load_session()

    def load_session(self):
        """加载整个会话的快照"""
        import os, glob, re

        # 按步骤编号排序加载
        pkl_files = sorted(
            glob.glob(f"{self.session_dir}/step_*.pkl"),
            key=lambda x: int(re.search(r"step_(\d+)", x).group(1))
        )

        for f in pkl_files:
            with open(f, "rb") as fp:
                self.snapshots.append(pickle.load(fp))

    def step_forward(self) -> Optional[Snapshot]:
        """前进到下一步"""
        if self.current_step >= len(self.snapshots):
            return None

        snapshot = self.snapshots[self.current_step]
        self.current_step += 1
        return snapshot

    def step_backward(self) -> Optional[Snapshot]:
        """后退一步"""
        if self.current_step <= 0:
            return None
        self.current_step -= 1
        return self.snapshots[self.current_step]

    def jump_to(self, step: int) -> Optional[Snapshot]:
        """跳到指定步骤"""
        if 0 <= step < len(self.snapshots):
            self.current_step = step
            return self.snapshots[step]
        return None

    def get_state_at_step(self, step: int) -> dict:
        """获取指定步骤完成后 Agent 的完整状态"""
        snapshot = self.snapshots[step]
        return {
            "conversation": snapshot.conversation_history,
            "memory": snapshot.agent_memory,
            "cumulative_tokens": snapshot.cumulative_tokens,
            "context_usage": snapshot.context_usage_pct,
            "last_thought": snapshot.current_thought,
            "last_action": snapshot.current_action,
            "last_observation": snapshot.current_observation
        }

    def compare_steps(self, step_a: int, step_b: int) -> dict:
        """对比两步之间的差异，用于分析问题出现在哪一步"""
        sa = self.snapshots[step_a]
        sb = self.snapshots[step_b]

        diffs = {}

        # Token 消耗差异
        diffs["token_diff"] = sb.cumulative_tokens - sa.cumulative_tokens
        diffs["duration_diff"] = sb.duration_ms - sa.duration_ms

        # 内容变化
        if sa.current_thought != sb.current_thought:
            diffs["thought_changed"] = True
        if sa.current_observation != sb.current_observation:
            diffs["observation_changed"] = True

        # 上下文增长
        diffs["context_growth"] = sb.context_usage_pct - sa.context_usage_pct

        return diffs

    def export_trace_timeline(self) -> list:
        """导出时间线视图，用于可视化"""
        return [
            {
                "step": s.step_index,
                "type": "thought" if s.current_thought else ("action" if s.current_action else "observation"),
                "duration_ms": s.duration_ms,
                "tokens": s.token_usage,
                "model": s.model,
                "has_error": s.llm_response is None if s.llm_request else False
            }
            for s in self.snapshots
        ]
```

## 三、根因分析（Root Cause Analysis）

### 3.1 常见 Agent 错误分类

Agent 错误不是单一类型——不同根因需要不同的分析方法：

| 错误类别 | 定义 | 典型表现 | 检测方式 |
|---------|------|---------|---------|
| **推理错误** | LLM 推理逻辑错误 | 步骤跳跃、因果关系混淆 | 检查 Thought 内容 |
| **工具选择错误** | 选择了错误的工具 | 用计算工具做搜索 | 检查 Action 匹配度 |
| **工具参数错误** | 工具调用参数错误 | 传错了查询语句 | 检查 Action 输入 |
| **Observation 误读** | 错误理解了工具返回 | 把 "not found" 当成成功 | 对比 Obs 与原始返回 |
| **上下文污染** | 上下文中的错误被继承 | 后续步骤在一开始就偏了 | 追溯信息源 |
| **Token 耗尽** | 上下文窗口溢出 | 回答截断或模型行为异常 | 检查 Token 指标 |
| **循环陷阱** | Agent 陷入死循环 | 同样的 Thought 重复出现 | 检测 Semantic 重复 |

### 3.2 自动化根因分析引擎

```python
class RootCauseAnalyzer:
    """自动化根因分析引擎"""

    def __init__(self, replay: ReplayEngine):
        self.replay = replay
        self.findings = []

    async def analyze(self) -> dict:
        """对当前会话进行全面分析"""
        self.findings = []

        # 1. 检查每一对相邻步骤的 Thought 差异
        self._analyze_thought_consistency()

        # 2. 检查工具调用是否合理
        self._analyze_tool_usage()

        # 3. 检查 Observation 是否被正确传递
        self._analyze_observation_flow()

        # 4. 检查上下文污染
        self._analyze_context_contamination()

        # 5. 检查是否陷入循环
        self._analyze_loop_detection()

        return {
            "has_root_cause": len(self.findings) > 0,
            "primary_cause": self.findings[0] if self.findings else None,
            "all_findings": self.findings,
            "error_step": self._find_error_step(),
            "recommended_action": self._generate_recommendation()
        }

    def _analyze_thought_consistency(self):
        """分析推理的一致性——寻找逻辑跳跃"""
        for i in range(1, len(self.replay.snapshots)):
            prev = self.replay.snapshots[i-1]
            curr = self.replay.snapshots[i]

            # 如果前一步的 Observation 包含错误信息，但下一步的 Thought 采纳了它
            if prev.current_observation and curr.current_thought:
                if "error" in prev.current_observation.lower():
                    # 检查 Agent 是否忽略了错误
                    if "忽略" not in curr.current_thought and "重试" not in curr.current_thought:
                        self.findings.append({
                            "type": "ignored_error",
                            "severity": "high",
                            "step": i,
                            "description": f"Agent 在第 {i} 步忽略了前一步的错误",
                            "evidence": {
                                "observation": prev.current_observation[:200],
                                "thought": curr.current_thought[:200]
                            }
                        })

    def _analyze_loop_detection(self):
        """检测 Agent 是否陷入循环"""
        thoughts = [
            s.current_thought for s in self.replay.snapshots
            if s.current_thought
        ]

        if len(thoughts) < 4:
            return

        # 使用 N-gram 检测语义重复
        from collections import Counter

        # 将 Thought 按关键词简化
        simplified = [
            " ".join(sorted(set(t.split()[:10])))  # 取前10个词的去重集合
            for t in thoughts
        ]

        # 检查是否有重复的模式
        patterns = Counter(simplified)
        for pattern, count in patterns.items():
            if count >= 3:  # 相同模式出现 3 次以上
                self.findings.append({
                    "type": "infinite_loop",
                    "severity": "critical",
                    "step": thoughts.index(pattern),
                    "description": f"检测到推理循环：相同模式重复 {count} 次",
                    "evidence": {"repeated_thought": pattern[:200]}
                })

    def _analyze_observation_flow(self):
        """分析 Observation 是否被正确传递到下一步"""
        for i in range(len(self.replay.snapshots) - 1):
            curr = self.replay.snapshots[i]
            next_step = self.replay.snapshots[i + 1]

            # 如果 Action 返回了结果，但下一步没有引用它
            if (curr.current_action and curr.current_observation
                    and next_step.current_thought):

                # 检查下一步的 Thought 是否包含上一步的 Observation 关键词
                obs_keywords = set(curr.current_observation.split()[:20])
                thought_words = set(next_step.current_thought.split())

                overlap = obs_keywords & thought_words
                if len(overlap) < 3 and len(obs_keywords) > 10:
                    self.findings.append({
                        "type": "observation_disconnect",
                        "severity": "medium",
                        "step": i + 1,
                        "description": f"第 {i+1} 步的 Thought 似乎未使用第 {i} 步的 Observation 结果",
                        "evidence": {
                            "observation_preview": curr.current_observation[:150],
                            "thought_preview": next_step.current_thought[:150],
                            "keyword_overlap": list(overlap)[:5]
                        }
                    })

    def _find_error_step(self) -> int:
        """定位最可能的错误引入步骤"""
        if not self.findings:
            return -1

        # 找到严重度最高、步骤最早的 finding
        severity_order = {"critical": 3, "high": 2, "medium": 1, "low": 0}
        sorted_findings = sorted(
            self.findings,
            key=lambda f: (-severity_order.get(f["severity"], 0), f["step"])
        )

        return sorted_findings[0]["step"]

    def _generate_recommendation(self) -> str:
        """根据分析结果生成修复建议"""
        if not self.findings:
            return "未检测到明确的根因，建议人工审查"

        primary = self.findings[0]

        recommendations = {
            "ignored_error": "在 Agent Prompt 中添加显式的错误检查指令："
                           "\"当工具返回错误时，必须记录错误并重试或报告用户\"",
            "infinite_loop": "设置最大步骤限制，并在 Prompt 中加入："
                           "\"如果发现自己在重复相同的推理模式，立即停止并总结已获得的信息\"",
            "observation_disconnect": "在 Agent 的语境窗口中加强 Observation 和 Thought 之间的"
                                    "引用关系，要求 Thought 中明确引用 Observation 的关键信息",
            "context_contamination": "加强对上下文中关键信息的引用验证，"
                                   "添加事实一致性检查步骤",
        }

        return recommendations.get(
            primary["type"],
            f"请检查第 {primary['step']} 步的详细快照以确定根因"
        )
```

### 3.3 交互式 Debugger 示例

基于 Replay 引擎，可以构建一个交互式的 Agent Debugger：

```python
class InteractiveAgentDebugger:
    """交互式 Agent 调试器"""

    def __init__(self, replay: ReplayEngine):
        self.replay = replay
        self.breakpoints = set()

    def set_breakpoint(self, step: int):
        """在指定步骤设置断点"""
        self.breakpoints.add(step)

    def run_to_breakpoint(self) -> Optional[Snapshot]:
        """运行到下一个断点"""
        while True:
            snapshot = self.replay.step_forward()
            if snapshot is None:
                return None
            if snapshot.step_index in self.breakpoints:
                return snapshot

    def inspect(self, step: int) -> dict:
        """检查指定步骤的完整状态"""
        snapshot = self.replay.jump_to(step)
        if not snapshot:
            return {"error": "步骤不存在"}

        return {
            "step": step,
            "user_input": snapshot.user_input,
            "agent_thought": snapshot.current_thought,
            "agent_action": snapshot.current_action,
            "tool_result": snapshot.current_observation,
            "llm_request": snapshot.llm_request["messages"][-1]
                           if snapshot.llm_request else None,
            "llm_response": snapshot.llm_response["choices"][0]["message"]
                           if snapshot.llm_response else None,
            "token_usage": snapshot.llm_tokens,
            "context_usage": f"{snapshot.context_usage_pct:.1f}%",
            "memory": snapshot.agent_memory
        }

    def diff(self, step_a: int, step_b: int) -> dict:
        """对比两步之间的所有变化"""
        return self.replay.compare_steps(step_a, step_b)
```

## 四、生产环境中的错误回放实践

### 4.1 存储策略

快照存储需要考虑成本和查询效率的平衡：

| 策略 | 存储成本 | 查询速度 | 适用场景 |
|------|---------|---------|---------|
| **JSON 文件**（仅错误会话） | 低 | 慢 | 生产中仅保存失败 Trace |
| **Pickle 文件**（全量） | 中 | 快 | 开发和预发环境 |
| **对象存储**（S3/OSS） | 按量计费 | 中 | 长期存档，合规要求 |
| **数据库**（PostgreSQL JSONB） | 中 | 快 | 需要按字段查询 |

建议的存储策略：
- 生产中：**仅对失败的 Trace** 保存完整快照，成功的 Trace 只保存摘要（Trace ID、耗时、总 Token）
- 开发/测试：全量保存，可用更大的存储空间

### 4.2 快照生命周期

```
快照生命周期管理

创建 → 第 N 步执行完成时创建快照
  │
  ├─ 会话正常结束 → 保留 7 天 → 删除（或摘要化）
  │
  └─ 会话异常结束 → 永久保留（或 30 天）
       │
       ├─ 已确认的 Bug → 关联 Issue，标记为复现用例
       │
       └─ 未知错误 → 触发告警，通知开发者审查
```

### 4.3 回放的安全性考虑

Agent 快照可能包含敏感数据（用户查询内容、工具返回的私有数据）：

```python
class SafeReplayEngine(ReplayEngine):
    """带脱敏功能的回放引擎"""

    SENSITIVE_PATTERNS = [
        r"\b\d{18}\b",            # 身份证号
        r"\b\d{11}\b",            # 手机号
        r"\b[\w\.-]+@[\w\.-]+\.\w+\b",  # 邮箱
        r"(?:access_key|secret_key|api_key|password)\s*[:=]\s*\S+",  # 密钥
    ]

    def get_sanitized_snapshot(self, step: int) -> dict:
        """获取脱敏后的快照"""
        snapshot = self.snapshots[step]
        data = asdict(snapshot)

        # 递归脱敏
        return self._sanitize(data)

    def _sanitize(self, obj):
        """递归地脱敏敏感数据"""
        import re

        if isinstance(obj, str):
            for pattern in self.SENSITIVE_PATTERNS:
                obj = re.sub(pattern, "[REDACTED]", obj)
            return obj
        elif isinstance(obj, dict):
            return {k: self._sanitize(v) for k, v in obj.items()}
        elif isinstance(obj, list):
            return [self._sanitize(item) for item in obj]
        return obj
```

## 五、根因分析 CheckList

在实践中，面对一个 Agent 错误时，按以下顺序排查：

```
1. 确认错误表现
   □ Agent 输出了错误答案？
   □ 工具调用失败？
   □ Agent 陷入循环/超时？
   □ Token 消耗异常？

2. 加载错误会话的快照
   □ 检查会话 Manifest（步数、耗时、模型）
   □ 定位首次出现异常的步骤

3. 逐步骤分析
   □ 第 N 步 Thought 是否合理？
   □ 第 N 步 Action 是否选择了正确的工具？
   □ 第 N 步 Observation 是否包含预期数据？
   □ 第 N+1 步是否正确使用了前一步的结果？

4. 定位根因
   □ 推理错误 → 检查 Prompt 设计
   □ 工具错误 → 检查工具实现和返回
   □ 上下文污染 → 限制上下文大小或改进压缩
   □ 循环 → 添加退出条件
   □ 模型退化 → 降低上下文使用率

5. 修复验证
   □ 用回放引擎在修复后复现
   □ 验证修复后的行为符合预期
   □ 添加到回归测试数据集
```

## 关键概念速查

| 术语 | 解释 |
|------|------|
| Record & Replay | 在生产环境记录 Agent 状态，在调试环境回放复现的错误诊断技术 |
| 上下文快照（Snapshot） | Agent 在某一时刻的完整状态记录，包括输入/输出/记忆/Token 等所有信息 |
| 会话清单（Manifest） | 记录一次 Agent 执行会话的元数据（步数、耗时、模型、步骤索引等） |
| 回放引擎（Replay Engine） | 读取快照并逐步还原 Agent 执行过程的引擎，支持前进/后退/跳转 |
| 根因分析（Root Cause Analysis） | 系统性地定位错误引入的最初步骤的技术 |
| 断点调试（Breakpoint Debugging） | 在指定步骤暂停回放，检查 Agent 状态的调试方式 |
| 非确定性（Non-determinism） | 相同输入产生不同输出的特性，Agent 调试的核心挑战 |
| 脱敏（Sanitization） | 在回放展示时替换或隐藏敏感信息的处理过程 |
