# 8.6 RAG 评估

> RAG 系统的评估远不止"回答是否正确"——它需要从**检索质量**（是否找到相关信息）、**生成质量**（是否忠实于检索内容）、**引用质量**（是否准确标注来源）等多个维度进行衡量。本章深入讲解 Hit Rate、MRR、NDCG、Faithfulness、引用溯源准确率等核心评估指标及其计算方法和工程实现。

---

## 一、RAG 评估的层次结构

RAG 评估分为三个层次：

```
层次 1: 检索评估（Retrieval Evaluation）
  衡量"是否找到了正确的信息"
  指标: Hit Rate, MRR, NDCG, Recall, Precision

层次 2: 生成评估（Generation Evaluation）
  衡量"生成的内容是否准确和忠实"
  指标: Faithfulness, Answer Relevancy, Context Precision

层次 3: 综合评估（End-to-End Evaluation）
  衡量"整个系统的最终效果"
  指标: 引用溯源准确率, 用户满意度, 任务完成率
```

### 1.1 为什么需要分层评估？

```ascii
一个典型的 RAG 失败案例：

用户: "2024年诺贝尔化学奖得主是谁？"

← 检索阶段 →
✓ 检索到正确的文档："2024年诺贝尔化学奖授予David Baker..."
  → 检索评估通过（Hit Rate = 1.0）

← 生成阶段 →
✗ LLM 忽略检索内容，凭记忆输出："2024年诺贝尔化学奖得主是..."
  → 生成评估失败（Faithfulness = 0.0）

→ 分层评估能精确定位问题所在：不是检索出错了，而是 LLM 没有忠实于检索内容
```

## 二、检索评估指标

### 2.1 Hit Rate（命中率）

**定义**：前 K 个检索结果中是否至少包含一个相关文档。

**公式**：

$$HitRate@K = \frac{1}{|Q|} \sum_{q \in Q} \mathbb{I}(relevant\_docs \cap retrieved\_docs_K \neq \emptyset)$$

其中 $\mathbb{I}(\cdot)$ 是指示函数，条件为真时返回 1，否则返回 0。

**特点**：
- 最简单的评估指标，只关心"有没有"命中
- 不够精细——不区分命中的位置和数量
- 通常用于初步筛选

```python
def hit_rate_at_k(retrieved: list[list[int]], relevant: list[list[int]], k: int = 10) -> float:
    """
    计算 HitRate@K
    
    Args:
        retrieved: 每个查询的检索结果文档 ID 列表
        relevant: 每个查询的相关文档 ID 列表
        k: 考虑前 K 个结果
    
    Returns:
        HitRate@K 分数 (0~1)
    """
    hits = 0
    for retrieved_docs, relevant_docs in zip(retrieved, relevant):
        retrieved_set = set(retrieved_docs[:k])
        relevant_set = set(relevant_docs)
        if retrieved_set & relevant_set:
            hits += 1
    return hits / len(retrieved) if retrieved else 0.0


# 示例
retrieved = [[3, 7, 1, 9, 5], [2, 4, 6, 8, 0]]
relevant  = [[1, 5],          [6, 9]]

print(f"HitRate@1 = {hit_rate_at_k(retrieved, relevant, k=1):.2f}")  # 0.50（第一个查询命中3，第二个查询命中2）
print(f"HitRate@3 = {hit_rate_at_k(retrieved, relevant, k=3):.2f}")  # 1.00（第一个查询在[3,7,1]中命中1，第二个查询未命中
print(f"HitRate@5 = {hit_rate_at_k(retrieved, relevant, k=5):.2f}")  # 1.00
```

### 2.2 MRR（Mean Reciprocal Rank，平均倒数排名）

**定义**：第一个相关文档在检索结果中位置的倒数，对所有查询取平均。

**公式**：

$$MRR@K = \frac{1}{|Q|} \sum_{q \in Q} \frac{1}{rank_{q,first\_relevant}}$$

其中 $rank_{q,first\_relevant}$ 是查询 $q$ 的第一个相关文档在结果中的排名（若前 K 个结果中没有相关文档，则倒数分数为 0）。

**特点**：
- 关心第一个正确答案**出现的位置**
- 对排名敏感：相关文档在第 1 位 vs 第 5 位，MRR 差异很大
- 适合"用户只关注第一个正确答案"的场景

```python
def mrr_at_k(retrieved: list[list[int]], relevant: list[list[int]], k: int = 10) -> float:
    """
    计算 MRR@K
    """
    reciprocal_ranks = []
    
    for retrieved_docs, relevant_docs in zip(retrieved, relevant):
        relevant_set = set(relevant_docs)
        found = False
        for rank, doc_id in enumerate(retrieved_docs[:k], start=1):
            if doc_id in relevant_set:
                reciprocal_ranks.append(1.0 / rank)
                found = True
                break
        if not found:
            reciprocal_ranks.append(0.0)
    
    return sum(reciprocal_ranks) / len(reciprocal_ranks) if reciprocal_ranks else 0.0


# 示例
retrieved = [[3, 1, 7, 9, 5], [2, 4, 6, 8, 0]]
relevant  = [[1, 5],          [6, 9]]

# 查询1: 第一个相关文档(1) 在位置2 → 1/2 = 0.5
# 查询2: 第一个相关文档(6) 在位置3 → 1/3 = 0.333
print(f"MRR@3 = {mrr_at_k(retrieved, relevant, k=3):.4f}")  # (0.5 + 0.333) / 2 = 0.4167
```

### 2.3 NDCG（Normalized Discounted Cumulative Gain，标准化折扣累计增益）

**定义**：NDCG 考虑排序的**质量**——不仅看相关文档是否被检索到，还看它们是否排在更靠前的位置，并且可以处理**多级相关性**（如：非常相关=2分，部分相关=1分，不相关=0分）。

**计算步骤**：

**第一步**：计算 DCG（Discounted Cumulative Gain）

$$DCG@K = \sum_{i=1}^{K} \frac{2^{rel_i} - 1}{\log_2(i + 1)}$$

其中 $rel_i$ 是第 $i$ 个文档的相关性评分。

**第二步**：计算 IDCG（Ideal DCG，理想排序下的 DCG）

$$IDCG@K = \sum_{i=1}^{K} \frac{2^{rel_i^*} - 1}{\log_2(i + 1)}$$

其中 $rel_i^*$ 是按相关性降序排列时的理想评分。

**第三步**：计算 NDCG

$$NDCG@K = \frac{DCG@K}{IDCG@K}$$

```python
import math

def ndcg_at_k(retrieved_scores: list[list[float]], k: int = 10) -> float:
    """
    计算 NDCG@K
    
    Args:
        retrieved_scores: 每个查询前 K 个文档的相关性评分列表 (0~1 或 0/1)
        k: 考虑前 K 个结果
    
    Returns:
        NDCG@K 分数 (0~1)
    """
    def dcg(scores):
        """计算 DCG"""
        return sum((2**s - 1) / math.log2(i + 2) for i, s in enumerate(scores[:k]))
    
    ndcg_values = []
    for scores in retrieved_scores:
        # 实际 DCG
        actual_dcg = dcg(scores)
        
        # 理想 DCG（按相关性降序排列）
        ideal_scores = sorted(scores, reverse=True)
        ideal_dcg = dcg(ideal_scores)
        
        if ideal_dcg == 0:
            ndcg_values.append(0.0)
        else:
            ndcg_values.append(actual_dcg / ideal_dcg)
    
    return sum(ndcg_values) / len(ndcg_values) if ndcg_values else 0.0


# 示例：三个查询的 Top-5 相关性评分
scores = [
    [3, 2, 1, 0, 0],  # 查询1: 第1位非常相关，第2位中等相关
    [0, 0, 3, 0, 0],  # 查询2: 相关文档在第3位
    [1, 1, 1, 0, 0],  # 查询3: 部分相关
]

print(f"NDCG@3 = {ndcg_at_k(scores, k=3):.4f}")
print(f"NDCG@5 = {ndcg_at_k(scores, k=5):.4f}")
```

### 2.4 三种指标的对比

```
检索结果排名: [相关] [相关] [不相关] [相关] [不相关]

HitRate@5 = 1.0
  (只要有相关文档就算通过)

MRR@5 = 1/1 = 1.0
  (第一个相关文档在位置1)

NDCG@5 = ?
  DCG = (2^1-1)/log2(2) + (2^1-1)/log2(3) + (2^0-1)/log2(4) + (2^1-1)/log2(5) + 0
       = 1/1 + 1/1.585 + 0 + 1/2.322 = 1.848
  IDCG = 1/1 + 1/1.585 + 1/2.0 + 1/2.322 = 2.548
  NDCG = 1.848 / 2.548 = 0.725
  (更精细地反映排序质量)
```

**什么时候用哪个？**

| 指标 | 用在哪 | 原因 |
|------|--------|------|
| **HitRate** | 快速筛选，A/B 测试 | 计算简单，直观理解 |
| **MRR** | 问答系统、知识库搜索 | 用户只看第一个结果 |
| **NDCG** | 推荐、学术评测 | 多级相关性，排序精细度要求高 |

## 三、生成评估指标

### 3.1 Faithfulness（忠实性）

**定义**：生成的内容是否**严格基于**检索到的文档，没有编造事实。

**评估方法**：将生成的回答分解为独立的事实断言（Claims），逐条验证每个断言是否被检索文档支持。

$$Faithfulness = \frac{|\text{被支持的断言}|}{|\text{总断言}|}$$

```python
from openai import OpenAI

class FaithfulnessEvaluator:
    """忠实性评估器"""
    
    def __init__(self, model: str = "gpt-4o-mini"):
        self.client = OpenAI()
        self.model = model
    
    def evaluate(self, answer: str, context: list[str]) -> dict:
        """评估忠实性"""
        
        # Step 1: 将回答拆解为原子断言
        claims = self._extract_claims(answer)
        print(f"  [Claims] 提取 {len(claims)} 个断言")
        
        # Step 2: 验证每个断言
        results = []
        supported_count = 0
        
        for claim in claims:
            verdict = self._verify_claim(claim, context)
            results.append({
                "claim": claim,
                "supported": verdict["supported"],
                "evidence": verdict.get("evidence", ""),
                "confidence": verdict.get("confidence", 0.0)
            })
            if verdict["supported"]:
                supported_count += 1
        
        faithfulness = supported_count / len(claims) if claims else 1.0
        
        return {
            "faithfulness_score": faithfulness,
            "supported_count": supported_count,
            "total_claims": len(claims),
            "unsupported_claims": [r for r in results if not r["supported"]],
            "details": results
        }
    
    def _extract_claims(self, answer: str) -> list[str]:
        """将回答拆解为原子断言"""
        prompt = f"""将以下回答拆解为独立的、不可再分的事实断言。
每个断言应该是一个可以被验证真假的陈述句。

回答: {answer}

输出 JSON:
{{
  "claims": [
    "断言1: ...",
    "断言2: ..."
  ]
}}"""
        
        response = self.client.chat.completions.create(
            model=self.model,
            messages=[{"role": "user", "content": prompt}],
            response_format={"type": "json_object"},
            temperature=0.0
        )
        
        result = json.loads(response.choices[0].message.content)
        return result["claims"]
    
    def _verify_claim(self, claim: str, context: list[str]) -> dict:
        """验证单个断言是否被上下文支持"""
        context_text = "\n\n".join([f"[文档 {i+1}] {doc[:500]}" for i, doc in enumerate(context)])
        
        prompt = f"""判断以下断言是否被给定的参考文档支持。

断言: {claim}

参考文档:
{context_text}

要求：
- "supported": 该断言被参考文档明确支持吗？
- "evidence": 从参考文档中引用具体的支持证据（如果不支持则为空）
- "confidence": 你的信心分数 (0~1)

输出 JSON:"""
        
        response = self.client.chat.completions.create(
            model=self.model,
            messages=[{"role": "user", "content": prompt}],
            response_format={"type": "json_object"},
            temperature=0.0
        )
        
        return json.loads(response.choices[0].message.content)


# 使用示例
evaluator = FaithfulnessEvaluator()

answer = "NVIDIA在2024年Q3的营收为350亿美元，同比增长50%。主要是由AI芯片需求驱动的。"
context = [
    "NVIDIA在2024年第三季度实现营收350.7亿美元...",
    "AI芯片需求的持续增长是NVIDIA业绩的主要驱动力..."
]

result = evaluator.evaluate(answer, context)
print(f"Faithfulness: {result['faithfulness_score']:.2f}")
print(f"支持的/总共: {result['supported_count']}/{result['total_claims']}")
```

### 3.2 Answer Relevancy（回答相关性）

**定义**：生成的回答是否回答了用户的问题，而不是答非所问。

**评估方法**：让评估模型判断回答与问题的相关程度（1-5 分制），或者计算回答和问题的语义相似度。

### 3.3 Context Precision（上下文精确率）

**定义**：检索到的文档中，有多少是实际被用于生成回答的（没有信息浪费）。

$$ContextPrecision = \frac{|\text{实际用于回答的文档}|}{|\text{检索到的总文档数}|}$$

## 四、引用溯源准确率（Citation Accuracy）

### 4.1 定义

引用溯源准确率从 14.4 节所述的引用溯源机制出发，衡量以下两个维度：

**精确率（Citation Precision）**：Agent 标注的引用中，有多少是**真实和内容匹配的**。

$$CitationPrecision = \frac{|\text{正确引用的次数}|}{|\text{总引用次数}|}$$

**召回率（Citation Recall）**：回答中的事实断言中，有多少有对应的引用标注。

$$CitationRecall = \frac{|\text{有引用标注的断言}|}{|\text{总断言数}|}$$

**F1 分数**：综合精确率和召回率的调和平均：

$$CitationF1 = 2 \cdot \frac{CitationPrecision \cdot CitationRecall}{CitationPrecision + CitationRecall}$$

### 4.2 实现

```python
class CitationAccuracyEvaluator:
    """引用溯源准确率评估器"""
    
    def evaluate(self, answer_with_citations: str, source_documents: list[dict]) -> dict:
        """
        评估引用准确率
        
        Args:
            answer_with_citations: 带引用标记的回答
            source_documents: 参考文档列表 [{"id": "1", "text": "..."}, ...]
        """
        # Step 1: 提取所有引用
        citations = self._extract_citations(answer_with_citations)
        
        # Step 2: 提取所有事实断言
        claims = self._extract_claims(answer_with_citations)
        
        # Step 3: 验证每个引用
        correct_citations = 0
        citation_results = []
        for citation in citations:
            is_correct = self._verify_citation(
                citation["text"],
                citation["source_id"],
                source_documents
            )
            if is_correct:
                correct_citations += 1
            citation_results.append({
                "cited_text": citation["text"],
                "source_id": citation["source_id"],
                "correct": is_correct
            })
        
        # Step 4: 计算指标
        total_citations = len(citations)
        total_claims = len(claims)
        claims_with_citations = sum(
            1 for claim in claims if claim["has_citation"]
        )
        
        citation_precision = correct_citations / total_citations if total_citations > 0 else 0
        citation_recall = claims_with_citations / total_claims if total_claims > 0 else 0
        citation_f1 = 2 * (citation_precision * citation_recall) / (citation_precision + citation_recall + 1e-10)
        
        return {
            "citation_precision": citation_precision,
            "citation_recall": citation_recall,
            "citation_f1": citation_f1,
            "total_citations": total_citations,
            "correct_citations": correct_citations,
            "total_claims": total_claims,
            "claims_with_citations": claims_with_citations,
            "detail": {
                "citations": citation_results,
                "claims": claims
            }
        }
    
    def _verify_citation(self, cited_text: str, source_id: str, sources: list[dict]) -> bool:
        """验证某个引用是否真实来自于指定文档"""
        source = next((s for s in sources if s["id"] == source_id), None)
        if not source:
            return False
        
        prompt = f"""判断以下标注来源的内容是否真实地出现在源文档中。

标注来源的内容: "{cited_text[:200]}"
源文档 ID: {source_id}
源文档内容: "{source['text'][:500]}"

该标注来源的内容是否被源文档明确支持？只需回答 true 或 false:"""
        
        response = self.client.chat.completions.create(
            model="gpt-4o-mini",
            messages=[{"role": "user", "content": prompt}],
            temperature=0.0,
            max_tokens=10
        )
        
        return response.choices[0].message.content.strip().lower() == "true"
```

## 六、RAGAS 评估框架

RAGAS（RAG Assessment）是目前应用最广的 RAG 评估框架，它定义了一套标准化的评估指标：

```python
from ragas import evaluate
from ragas.metrics import (
    faithfulness,
    answer_relevancy,
    context_precision,
    context_recall,
)
from datasets import Dataset

def evaluate_with_ragas(questions, answers, contexts, ground_truths):
    """
    使用 RAGAS 框架进行多维度评估
    """
    data = {
        "question": questions,
        "answer": answers,
        "contexts": [[c] for c in contexts],
        "ground_truth": ground_truths,
    }
    
    dataset = Dataset.from_dict(data)
    
    result = evaluate(
        dataset,
        metrics=[
            faithfulness,
            answer_relevancy,
            context_precision,
            context_recall,
        ]
    )
    
    return result.to_pandas()
```

**RAGAS 各维度的含义**：

| 指标 | 测量内容 | 范围 | 理想值 |
|------|----------|------|--------|
| **Faithfulness** | 回答是否忠实于检索上下文 | 0~1 | > 0.8 |
| **Answer Relevancy** | 回答是否与问题相关 | 0~1 | > 0.8 |
| **Context Precision** | 检索结果中相关信息占比 | 0~1 | > 0.7 |
| **Context Recall** | 检索结果是否覆盖所需信息 | 0~1 | > 0.8 |

## 七、评估的最佳实践

### 7.1 评估流水线的分层设计

```ascii

│  在线评估（持续）                     │
│  ┌───────────────────────────────┐   │
│  │ • 用户反馈收集（点赞/点踩）      │   │
│  │ • 人工抽检（每周抽样 100 条）   │   │
│  │ • 引用准确率监控                │   │
│  └───────────────────────────────┘   │
└─────────────────────────────────────┘
```

## 关键概念速查表

| 术语 | 英文 | 定义 |
|------|------|------|
| **Hit Rate** | Hit Rate | 前 K 个结果中至少包含一个相关文档的比例 |
| **MRR** | Mean Reciprocal Rank | 第一个相关文档位置倒数的均值 |
| **NDCG** | Normalized Discounted Cumulative Gain | 考虑多级相关性和排序位置的标准化指标 |
| **DCG** | Discounted Cumulative Gain | 折扣累计增益，NDCG 的未标准化版本 |
| **IDCG** | Ideal DCG | 理想排序下的 DCG，用于归一化 |
| **Faithfulness** | Faithfulness | 生成内容是否忠实于检索文档 |
| **引用精确率** | Citation Precision | 引用标注中真实匹配的比例 |
| **引用召回率** | Citation Recall | 事实断言中有引用标注的比例 |
| **RAGAS** | RAG Assessment | 标准化的 RAG 评估框架 |
| **Context Precision** | Context Precision | 检索结果中相关信息占比 |
| **Context Recall** | Context Recall | 检索结果覆盖所需信息的程度 |

## 本章小结

RAG 评估需要覆盖三个层次，每个层次关注不同的问题：

1. **检索评估**（Hit Rate / MRR / NDCG）衡量"检索系统是否找到了正确的信息"
   - Hit Rate 适合快速筛选
   - MRR 适合用户只看第一个结果的场景
   - NDCG 适合需要精细排序质量的场景

2. **生成评估**（Faithfulness / Answer Relevancy / Context Precision）衡量"LLM 是否正确使用了检索到的信息"
   - Faithfulness 是最关键的生成指标——不忠实的回答会误导用户

3. **引用评估**（Citation Precision / Recall / F1）衡量"引用标注的准确性"
   - 这是连接 8.1 节（引用标注）和 14.4 节（引用溯源）的桥梁

建议的生产评估体系：
- **离线阶段**：用 RAGAS 框架全量评估，设定门限值自动阻断回归
- **在线阶段**：采集用户反馈（点赞/点踩）+ 人工抽检
- **持续监控**：对 Citation F1 和 Faithfulness 设警报，低于门限立即告警
