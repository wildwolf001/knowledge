# 18.6 降级策略

> "有时候，最好的回答是'我不知道'，最好的行动是'不行动'。"——当 Agent 的置信度低于阈值时，如何优雅地降级而不是硬着头皮犯错？本章讨论从高到低的系统性降级方案。

---

## 一、降级策略的核心理念

### 1.1 什么是降级策略？

**降级策略**（Degradation Strategy）是指当系统无法以完整质量完成任务时，主动降低服务质量期望，以换取可靠性和安全性的保障。

在 Agent 系统中，降级不是"失败"，而是**有管理的失败**——在知道无法完美完成时，选择一种更安全的失败模式。

### 1.2 降级的层次

降级可以在多个层次上发生，从最轻微到最严重：

```
Level 0: 正常执行（Full Service）
  → Agent 以完整能力完成任务

Level 1: 输出降级（Output Degradation）
  → Agent 完成推理，但输出标注不确定性、提供置信度
  → 用户被告知"这个结果可能需要人工核实"

Level 2: 步骤降级（Step Degradation）
  → Agent 跳过某些高风险步骤
  → 如：只读操作不执行写操作

Level 3: 人工介入（Human-in-the-loop）
  → Agent 暂停执行，将决策权交给人
  → 人确认或修正后 Agent 继续

Level 4: 规则引擎回退（Rule Engine Fallback）
  → 完全放弃 LLM 方案，使用确定性规则
  → 安全性最高，但灵活性最低

Level 5: 安全终止（Safe Abort）
  → Agent 告知无法完成任务并安全退出
  → 不产生任何副作用
```

### 1.3 降级决策的输入

降级决策基于三个核心输入：

1. **置信度分数**（参见 14.5 节）：Agent 对当前步骤输出正确性的信心
2. **任务关键度**：当前操作的影响范围（读取 vs 写入、可逆 vs 不可逆）
3. **静默失败评分**（参见 18.4 节）：系统检测到的异常信号强度

## 二、置信度驱动的降级框架

### 2.1 阈值设计

```python
class ConfidenceThresholds:
    """
    置信度阈值定义
    
    基于 14.5 节「置信度评分」的校准机制，
    这里的阈值需要根据实际生产数据进行调优。
    """
    
    # 通用阈值
    FULL_AUTOMATION = 0.85   # ≥ 0.85: 全自动执行
    HUMAN_NOTIFY = 0.70      # ≥ 0.70: 自动执行，但通知人类复核
    HUMAN_CONFIRM = 0.50     # ≥ 0.50: 需要人类确认后才能执行
    HUMAN_DECIDE = 0.30      # ≥ 0.30: 人类完全接管决策
    SAFE_ABORT = 0.0         # < 0.30: 安全终止
    
    # 操作类型加权系数
    # 对于不可逆操作，实际阈值 = 基础阈值 × 加权系数
    OPERATION_WEIGHTS = {
        "read_only": 1.0,          # 只读操作：标准阈值
        "write_reversible": 1.2,    # 可逆写入：提高阈值 20%
        "write_irreversible": 1.5,  # 不可逆写入：提高阈值 50%
        "external_api": 1.3,       # 外部 API 调用：提高阈值 30%
        "delete_operation": 1.8,   # 删除操作：大幅提高阈值
    }
    
    @classmethod
    def get_effective_threshold(
        cls,
        base_threshold: float,
        operation_type: str,
    ) -> float:
        """
        计算考虑操作类型的有效阈值
        
        Args:
            base_threshold: 基础阈值（如 FULL_AUTOMATION = 0.85）
            operation_type: 操作类型
        
        Returns:
            调整后的有效阈值
        """
        weight = cls.OPERATION_WEIGHTS.get(operation_type, 1.0)
        return min(base_threshold * weight, 1.0)
```

### 2.2 降级决策引擎

```python
from enum import Enum, auto

class DegradationLevel(Enum):
    """降级级别"""
    FULL_SERVICE = auto()          # Level 0: 正常服务
    OUTPUT_DEGRADATION = auto()    # Level 1: 输出降级
    STEP_DEGRADATION = auto()      # Level 2: 步骤降级
    HUMAN_IN_LOOP = auto()         # Level 3: 人工介入
    RULE_ENGINE = auto()           # Level 4: 规则引擎
    SAFE_ABORT = auto()            # Level 5: 安全终止


class DegradationDecisionEngine:
    """
    降级决策引擎
    
    根据置信度、任务关键度和静默失败信号，
    决定使用哪个降级级别。
    """
    
    def __init__(self, thresholds: ConfidenceThresholds = None):
        self.thresholds = thresholds or ConfidenceThresholds()
    
    def decide(
        self,
        confidence: float,
        operation_type: str,
        silent_failure_score: float = 0.0,
        is_critical_task: bool = False,
    ) -> DegradationLevel:
        """
        做出降级决策
        
        Args:
            confidence: 置信度分数 (0-1)
            operation_type: 操作类型
            silent_failure_score: 静默失败评分 (0-1)
            is_critical_task: 是否关键任务
        
        Returns:
            建议的降级级别
        """
        
        # 高静默失败信号 → 直接升高级别
        if silent_failure_score >= 0.8:
            return DegradationLevel.SAFE_ABORT
        if silent_failure_score >= 0.6:
            return DegradationLevel.HUMAN_IN_LOOP
        
        # 获取有效的操作加权阈值
        effective_full = self.thresholds.get_effective_threshold(
            self.thresholds.FULL_AUTOMATION, operation_type
        )
        effective_notify = self.thresholds.get_effective_threshold(
            self.thresholds.HUMAN_NOTIFY, operation_type
        )
        effective_confirm = self.thresholds.get_effective_threshold(
            self.thresholds.HUMAN_CONFIRM, operation_type
        )
        
        # 基于置信度的降级决策
        if confidence >= effective_full:
            if is_critical_task:
                return DegradationLevel.OUTPUT_DEGRADATION
            return DegradationLevel.FULL_SERVICE
        
        elif confidence >= effective_notify:
            return DegradationLevel.OUTPUT_DEGRADATION
        
        elif confidence >= effective_confirm:
            return DegradationLevel.HUMAN_IN_LOOP
        
        elif confidence >= self.thresholds.HUMAN_DECIDE:
            return DegradationLevel.RULE_ENGINE
        
        else:
            return DegradationLevel.SAFE_ABORT
    
    def get_decision_explanation(
        self,
        level: DegradationLevel,
        confidence: float,
        operation_type: str,
    ) -> str:
        """生成降级决策的解释"""
        explanations = {
            DegradationLevel.FULL_SERVICE: (
                f"置信度 {confidence:.2f} 超过自动化阈值 "
                f"({self.thresholds.FULL_AUTOMATION})，全自动执行"
            ),
            DegradationLevel.OUTPUT_DEGRADATION: (
                f"置信度 {confidence:.2f} 在通知阈值 "
                f"({self.thresholds.HUMAN_NOTIFY}) 以下，"
                f"输出将标注不确定性供人工复核"
            ),
            DegradationLevel.HUMAN_IN_LOOP: (
                f"置信度 {confidence:.2f} 低于确认阈值 "
                f"({self.thresholds.HUMAN_CONFIRM})，"
                f"需要人工确认后才能执行"
            ),
            DegradationLevel.RULE_ENGINE: (
                f"置信度 {confidence:.2f} 低于安全阈值，"
                f"回退到确定性规则引擎"
            ),
            DegradationLevel.SAFE_ABORT: (
                f"置信度 {confidence:.2f} 极低，"
                f"安全终止任务以避免副作用"
            ),
        }
        return explanations.get(level, "未知决策")
```

## 三、Human-in-the-loop（人工介入）

### 3.1 什么是 Human-in-the-loop？

**Human-in-the-loop（HITL）** 是在 Agent 决策链中引入人类判断的机制。当 Agent 不确定时，不是自己做决定，而是把决定权交给人类。

HITL 的三种切入模式：

| 模式 | 触发条件 | 行为 | 用户体验 |
|------|---------|------|---------|
| **通知模式** | 置信度 0.70-0.85 | Agent 执行，但事后通知人复核 | 非侵入式 |
| **确认模式** | 置信度 0.50-0.70 | Agent 暂停，请求人确认后继续 | 中等侵入 |
| **接管模式** | 置信度 0.30-0.50 | Agent 交出控制权，人完全决策 | 高侵入 |

### 3.2 HITL 的实现

```python
from typing import Optional, Protocol

class HumanApprovalCallback(Protocol):
    """人类审批回调的协议"""
    async def request_approval(
        self,
        task_description: str,
        proposed_action: Dict,
        context: Dict,
        confidence: float,
    ) -> Dict:
        """
        请求人类审批
        
        Returns:
            {"decision": "approve" | "reject" | "modify",
             "modified_action": Dict | None,
             "comment": str}
        """
        ...


class HumanInTheLoopHandler:
    """
    Human-in-the-loop 处理器
    
    管理 Agent 和人类之间的交互流程。
    """
    
    def __init__(self, approval_callback: HumanApprovalCallback):
        self.approval_callback = approval_callback
        self.approval_history: List[Dict] = []
    
    async def intervene(
        self,
        agent_step: str,
        proposed_action: Dict,
        confidence: float,
        context: Dict,
    ) -> Dict:
        """
        请求人类介入
        
        Args:
            agent_step: 当前 Agent 步骤的描述
            proposed_action: Agent 建议执行的操作
            confidence: Agent 对该操作的置信度
            context: 当前上下文
        
        Returns:
            {
                "action": Dict,          # 最终执行的操作
                "human_intervened": bool, # 是否有人类干预
                "approval_record": Dict,   # 审批记录
            }
        """
        
        # 生成给人类审查者的提示
        approval_request = {
            "task": agent_step,
            "proposed_action": proposed_action,
            "confidence": confidence,
            "context_summary": self._summarize_context(context),
            "risk_level": self._assess_risk(proposed_action),
        }
        
        # 请求人类审批
        response = await self.approval_callback.request_approval(
            task_description=agent_step,
            proposed_action=proposed_action,
            context=context,
            confidence=confidence,
        )
        
        # 记录审批历史
        record = {
            "timestamp": time.time(),
            "step": agent_step,
            "proposed_action": proposed_action,
            "human_decision": response.get("decision"),
            "human_comment": response.get("comment", ""),
            "confidence_at_intervention": confidence,
        }
        self.approval_history.append(record)
        
        # 根据人类决策处理
        decision = response.get("decision", "reject")
        
        if decision == "approve":
            return {
                "action": proposed_action,
                "human_intervened": False,
                "approval_record": record,
            }
        elif decision == "modify":
            modified = response.get("modified_action")
            if modified:
                return {
                    "action": modified,
                    "human_intervened": True,
                    "approval_record": record,
                }
            else:
                # 没有提供修改方案→拒绝
                return {
                    "action": None,
                    "human_intervened": True,
                    "approval_record": record,
                }
        else:  # reject
            return {
                "action": None,
                "human_intervened": True,
                "approval_record": record,
            }
    
    def _summarize_context(self, context: Dict) -> str:
        """为人类审查者总结上下文"""
        # 提取关键信息，避免信息过载
        key_fields = ["task_goal", "current_step", "previous_results"]
        summary = {k: context.get(k) for k in key_fields if k in context}
        return json.dumps(summary, indent=2, ensure_ascii=False)
    
    def _assess_risk(self, action: Dict) -> str:
        """评估操作风险"""
        action_type = action.get("type", "")
        if action_type in ("delete", "write", "update", "transfer"):
            return "high"
        if action_type in ("read", "query", "search"):
            return "low"
        return "medium"
```

### 3.3 人类审批超时处理

人类介人的一个实际问题是——如果人不响应怎么办？

```python
class ApprovalTimeoutHandler:
    """审批超时处理"""
    
    def __init__(
        self,
        timeout_seconds: float = 300.0,  # 5 分钟
        on_timeout: str = "reject",      # reject / auto_approve / escalate
    ):
        self.timeout_seconds = timeout_seconds
        self.on_timeout = on_timeout
    
    async def wait_for_approval(
        self,
        approval_func,
        escalate_func=None,
    ) -> Dict:
        """等待审批，处理超时"""
        try:
            result = await asyncio.wait_for(
                approval_func(),
                timeout=self.timeout_seconds,
            )
            return result
        except asyncio.TimeoutError:
            if self.on_timeout == "reject":
                return {"decision": "reject", "comment": "审批超时，自动拒绝"}
            elif self.on_timeout == "escalate":
                if escalate_func:
                    return await escalate_func()
                return {"decision": "reject", "comment": "升级审批失败"}
            else:  # auto_approve
                return {"decision": "approve", "comment": "审批超时，自动通过"}
```

## 四、规则引擎回退（Rule Engine Fallback）

### 4.1 什么是规则引擎回退？

**规则引擎回退**（Rule Engine Fallback）是指当 LLM 置信度过低时，放弃 AI 方案，转而使用基于确定性规则的方案。规则引擎可能不如 LLM 灵活，但它是**确定性的、可预测的、永远不会产生幻觉**。

### 4.2 规则引擎的设计原则

```python
class RuleEngine:
    """
    确定性规则引擎
    
    作为 LLM Agent 的最终 Fallback。
    规则引擎不会产生幻觉，但只能处理预定义的场景。
    """
    
    def __init__(self, rules: List[Dict]):
        self.rules = rules
    
    def execute(self, task: str, context: Dict) -> Dict:
        """
        尝试用规则匹配并执行
        
        Returns:
            {"matched": bool, "result": Any, "rule_id": str}
        """
        for rule in self.rules:
            if self._match(rule["condition"], task, context):
                result = self._apply(rule["action"], context)
                return {
                    "matched": True,
                    "result": result,
                    "rule_id": rule.get("id", "unknown"),
                }
        
        return {
            "matched": False,
            "result": None,
            "rule_id": None,
        }
    
    def _match(self, condition: Dict, task: str, context: Dict) -> bool:
        """判断规则是否匹配"""
        # 关键词匹配
        if "keywords" in condition:
            task_lower = task.lower()
            if not all(kw.lower() in task_lower for kw in condition["keywords"]):
                return False
        
        # 任务类型匹配
        if "task_type" in condition:
            if context.get("task_type") != condition["task_type"]:
                return False
        
        return True
    
    def _apply(self, action: Dict, context: Dict) -> Any:
        """执行规则的动作"""
        action_type = action.get("type")
        if action_type == "template":
            return self._apply_template(action["template"], context)
        elif action_type == "function":
            return action["function"](context)
        else:
            raise ValueError(f"未知规则动作类型: {action_type}")
    
    def _apply_template(self, template: str, context: Dict) -> str:
        """用模板引擎生成输出"""
        return template.format(**context)
```

### 4.4 非 LLM 备选方案的完整策略

规则引擎之外，还有其他非 LLM 的备选方案：

| 备选方案 | 适用场景 | 复杂度 | 维护成本 | 可靠性 |
|---------|---------|--------|---------|-------|
| **模板引擎** | 固定格式的输出（邮件、报告模板） | 低 | 低 | 极高 |
| **决策树** | 有明确分支逻辑的分类/路由 | 中 | 中 | 高 |
| **状态机** | 多步骤、多状态的流程控制 | 中 | 中 | 高 |
| **查询语言** | 数据库/知识库的结构化查询 | 中 | 低 | 高 |
| **相似度搜索** | FAQ 匹配、案例检索 | 中 | 低 | 中 |
| **正则表达式** | 特定格式的提取/验证 | 低 | 低 | 极高 |

## 五、完整降级流程

### 5.1 从高到低的系统性降级

```python
class AgentDegradationManager:
    """
    Agent 降级管理器
    
    管理从全自动到安全终止的完整降级流程。
    """
    
    def __init__(
        self,
        confidence_engine: DegradationDecisionEngine,
        hitl_handler: HumanInTheLoopHandler,
        rule_engine: RuleEngine,
    ):
        self.confidence_engine = confidence_engine
        self.hitl_handler = hitl_handler
        self.rule_engine = rule_engine
        self.current_level = DegradationLevel.FULL_SERVICE
    
    async def execute_with_degradation(
        self,
        task: str,
        agent_fn,
        context: Dict,
        operation_type: str = "read_only",
    ) -> Dict:
        """
        带降级策略的任务执行
        
        Args:
            task: 任务描述
            agent_fn: Agent 执行函数（返回结果和置信度）
            context: 上下文
            operation_type: 操作类型
        
        Returns:
            执行结果（可能包含降级信息）
        """
        
        # Step 1: 尝试 LLM Agent
        result = await agent_fn(task, context)
        confidence = result.get("confidence", 1.0)
        silent_failure_score = result.get("silent_failure_score", 0.0)
        
        # Step 2: 做出降级决策
        degradation_level = self.confidence_engine.decide(
            confidence=confidence,
            operation_type=operation_type,
            silent_failure_score=silent_failure_score,
            is_critical_task=context.get("is_critical", False),
        )
        
        self.current_level = degradation_level
        
        # Step 3: 根据降级级别处理
        if degradation_level == DegradationLevel.FULL_SERVICE:
            # Level 0: 直接返回结果
            return {
                "result": result["output"],
                "degradation_level": "full_service",
                "confidence": confidence,
            }
        
        elif degradation_level == DegradationLevel.OUTPUT_DEGRADATION:
            # Level 1: 输出降级—标注不确定性
            return {
                "result": result["output"],
                "degradation_level": "output_degraded",
                "confidence": confidence,
                "warning": (
                    "此结果由 AI 自动生成但置信度较低 "
                    f"({confidence:.0%})，建议人工复核后再使用"
                ),
            }
        
        elif degradation_level == DegradationLevel.STEP_DEGRADATION:
            # Level 2: 步骤降级—跳过不可逆操作
            skipped_actions = self._filter_irreversible_actions(
                result.get("proposed_actions", [])
            )
            return {
                "result": {
                    "safe_actions": result.get("output"),
                    "skipped_actions": skipped_actions,
                    "skipped_reason": "置信度不足，跳过高风险操作",
                },
                "degradation_level": "step_degraded",
                "confidence": confidence,
            }
        
        elif degradation_level == DegradationLevel.HUMAN_IN_LOOP:
            # Level 3: 人工介入
            intervention = await self.hitl_handler.intervene(
                agent_step=task,
                proposed_action=result.get("proposed_action", {}),
                confidence=confidence,
                context=context,
            )
            
            if intervention["action"] is None:
                # 人类拒绝了操作→进一步降级
                return await self._escalate_degradation(
                    task, agent_fn, context, operation_type
                )
            
            return {
                "result": intervention["action"],
                "degradation_level": "human_in_loop",
                "human_intervened": intervention["human_intervened"],
                "confidence": confidence,
            }
        
        elif degradation_level == DegradationLevel.RULE_ENGINE:
            # Level 4: 规则引擎
            rule_result = self.rule_engine.execute(task, context)
            if rule_result["matched"]:
                return {
                    "result": rule_result["result"],
                    "degradation_level": "rule_engine",
                    "rule_id": rule_result["rule_id"],
                    "confidence": 0.95,  # 规则引擎的确定性置信度
                }
            else:
                # 规则引擎也无法处理→安全终止
                return await self._safe_abort(task)
        
        else:  # SAFE_ABORT
            # Level 5: 安全终止
            return await self._safe_abort(task)
    
    async def _escalate_degradation(self, task, agent_fn, context, operation_type):
        """进一步升级降级（当人类拒绝时）"""
        # 直接跳到规则引擎
        rule_result = self.rule_engine.execute(task, context)
        if rule_result["matched"]:
            return {
                "result": rule_result["result"],
                "degradation_level": "rule_engine_after_human_reject",
                "confidence": 0.95,
            }
        return await self._safe_abort(task)
    
    async def _safe_abort(self, task: str) -> Dict:
        """安全终止"""
        return {
            "result": None,
            "degradation_level": "safe_abort",
            "message": (
                "我目前无法处理这个请求。当前的置信度不足以给出可靠的回答，"
                "并且备选方案也无法处理。请尝试重新表述您的问题，"
                "或联系管理员获取帮助。"
            ),
            "confidence": 0.0,
        }
    
    def _filter_irreversible_actions(self, actions: List[Dict]) -> List[Dict]:
        """过滤掉不可逆操作"""
        irreversible_types = {"delete", "update", "write", "transfer", "send"}
        skipped = []
        for action in actions:
            if action.get("type") in irreversible_types:
                skipped.append(action)
        return skipped
```

### 5.2 降级通知模板

不同的降级级别应该有不同的用户通知策略：

| 降级级别 | 是否通知用户 | 通知方式 |
|---------|------------|---------|
| Level 0: 全自动 | 否 | 不通知 |
| Level 1: 输出降级 | 是 | 在结果中附带警告标注 |
| Level 2: 步骤降级 | 是 | 告知哪些操作被跳过了 |
| Level 3: 人工介入 | 是 | 全量告知，等待用户输入 |
| Level 4: 规则引擎 | 透明 | 不主动告知（体验一致即可） |
| Level 5: 安全终止 | 是 | 清晰说明无法处理 |

## 关键概念速查

| 术语 | 解释 |
|------|------|
| 降级策略（Degradation Strategy） | 当系统无法完整服务时，主动降低服务质量换取安全性的方案 |
| Human-in-the-loop（HITL） | 在 Agent 决策链中引入人类判断机制 |
| 规则引擎回退 | 放弃 LLM 方案，使用确定性规则作为最后的保障 |
| 安全终止（Safe Abort） | Agent 主动告知无法完成任务并安全退出，不产生副作用 |
| 置信度阈值 | 区分不同降级级别的置信度分数边界（参见 14.5 节） |
| 操作类型加权 | 不可逆操作需要更高的置信度阈值 |
| 审批超时 | 人类在限定时间内未响应时的自动处理策略 |
| 输出降级 | Agent 完成推理但标注不确定性和风险警告 |
| 步骤降级 | Agent 跳过高风险步骤，只执行安全性可保证的操作 |
