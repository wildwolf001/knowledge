# 6.5 环境感知注入

> 同一份 System Prompt 在不同环境中运行的效果可能天差地别：Windows 上的路径分隔符是 `\` 而 Unix 是 `/`，PowerShell 的语法与 Bash 不同，小模型的推理能力远不及大模型。环境感知注入的目标是让提示词自动适应运行环境的差异，保持行为的一致性和正确性。

---

## 一、环境感知的定义与维度

### 1.1 什么是环境感知注入

环境感知注入（Environment-Aware Injection）是指 System Prompt 在渲染时自动检测当前运行环境的状态，并将这些状态信息以结构化的方式注入提示词中，使得 Agent 的行为能够自动适配环境差异。

### 1.2 需要感知的环境维度

| 维度 | 检测项 | 对 Agent 行为的直接影响 |
|------|--------|----------------------|
| **操作系统** | Windows / macOS / Linux | 路径格式、换行符、文件权限模型、进程管理方式 |
| **Shell 类型** | Bash / PowerShell / Zsh / Cmd | 命令语法、管道操作符、变量引用方式 |
| **模型能力** | 模型名称、上下文窗口大小、知识截止日期 | 推理深度、输出长度限制、知识范围 |
| **可用工具** | 已注册工具列表、工具版本 | 哪些操作 Agent 可以执行 |
| **语言环境** | 系统语言、用户偏好语言 | 回复语言、时间日期格式、数字格式 |
| **时区/地区** | 时区偏移量、地区代码 | 时间相关查询的精确性 |
| **权限级别** | admin/root、只读文件系统 | 文件操作的范围和安全约束 |
| **网络状态** | 是否在线、代理配置 | 是否需要联网工具、API 调用方式 |

## 二、环境检测的实现

### 2.1 操作系统检测

```python
import platform
import sys
from pathlib import Path

class OSDetector:
    """操作系统环境检测器"""

    @staticmethod
    def detect() -> dict:
        system = platform.system().lower()
        info = {
            "os_type": system,
            "os_version": platform.version(),
            "os_release": platform.release(),
            "is_windows": system == "windows",
            "is_macos": system == "darwin",
            "is_linux": system == "linux",
            "path_separator": "\\" if system == "windows" else "/",
            "line_ending": "\r\n" if system == "windows" else "\n",
            "home_dir": str(Path.home()),
            "encoding": sys.getfilesystemencoding(),
        }
        # 特定平台补充信息
        if info["is_linux"]:
            info["has_wsl"] = "microsoft" in platform.uname().release.lower()
        return info

    @staticmethod
    def get_path_guidance() -> str:
        """根据操作系统返回路径使用指导"""
        os_info = OSDetector.detect()
        if os_info["is_windows"]:
            return (
                "当前系统为 Windows。\n"
                "- 路径中使用反斜杠 \\ 或正斜杠 / 均可\n"
                "- 根目录表示为 C:\\ 或 /mnt/c/\n"
                "- 注意驱动器号（C:, D:）"
            )
        elif os_info["is_macos"]:
            return (
                "当前系统为 macOS。\n"
                "- 路径中使用正斜杠 /\n"
                "- 根目录为 /\n"
                "- 用户目录在 /Users/"
            )
        else:
            return (
                "当前系统为 Linux。\n"
                "- 路径中使用正斜杠 /\n"
                "- 根目录为 /\n"
                "- 用户目录在 /home/"
            )
```

### 2.2 Shell 类型检测

```python
import os

class ShellDetector:
    """Shell 环境检测器"""

    @staticmethod
    def detect() -> dict:
        """检测当前 Shell 类型和相关属性"""
        shell_raw = os.environ.get("SHELL", "") or os.environ.get("ComSpec", "")
        shell_name = Path(shell_raw).stem.lower() if shell_raw else "unknown"

        # Windows 下的特殊检测
        is_powershell = bool(os.environ.get("PSModulePath")) or "pwsh" in shell_name
        is_cmd = "cmd" in shell_name or "comspec" in [k.lower() for k in os.environ]

        info = {
            "shell_type": shell_name,
            "shell_path": shell_raw,
            "is_bash": "bash" in shell_name,
            "is_zsh": "zsh" in shell_name,
            "is_powershell": is_powershell,
            "is_cmd": is_cmd,
            "is_posix": not (is_powershell or is_cmd),
        }
        return info

    @staticmethod
    def get_shell_syntax_guide(shell_type: str) -> str:
        """根据 Shell 类型返回命令语法指导"""
        guides = {
            "bash": (
                "- 变量引用: $VAR 或 ${VAR}\n"
                "- 管道: cmd1 | cmd2\n"
                "- 重定向: >(输出) <(输入)\n"
                "- 后台运行: cmd &\n"
                "- 条件执行: cmd1 && cmd2"
            ),
            "zsh": (
                "- 变量引用: $VAR 或 ${VAR}\n"
                "- 管道: cmd1 | cmd2\n"
                "- 支持更高级的 glob 模式\n"
                "- 与 bash 高度兼容"
            ),
            "powershell": (
                "- 变量引用: $VAR\n"
                "- 管道: cmd1 | cmd2（传递对象而非文本）\n"
                "- 属性访问: $object.Property\n"
                "- 命令: Get-Content（替代 cat）\n"
                "- 注意: cmd.exe 的 .bat 脚本可能不兼容"
            ),
            "cmd": (
                "- 变量引用: %VAR%\n"
                "- 管道: cmd1 | cmd2\n"
                "- 命令: type（替代 cat）\n"
                "- 注意: 部分 Unix 命令不可用"
            ),
        }
        return guides.get(shell_type, "- 标准 POSIX Shell 语法")

    @staticmethod
    def get_command_equivalents(shell_type: str) -> dict:
        """返回不同 Shell 下的命令等价表"""
        equivalents = {
            "bash": {"ls": "ls", "cat": "cat", "grep": "grep", "find": "find",
                     "ps": "ps", "echo": "echo"},
            "zsh": {"ls": "ls", "cat": "cat", "grep": "grep", "find": "find",
                    "ps": "ps", "echo": "echo"},
            "powershell": {"ls": "Get-ChildItem", "cat": "Get-Content",
                           "grep": "Select-String", "find": "Get-ChildItem -Recurse",
                           "ps": "Get-Process", "echo": "Write-Output"},
            "cmd": {"ls": "dir", "cat": "type", "find": "dir /s",
                    "echo": "echo"},
        }
        return equivalents.get(shell_type, equivalents["bash"])
```

```python
class ModelCapabilityDetector:
    """模型能力检测器 —— 基于模型名称推断能力边界"""

    # 已知模型的能力参数表

            "supports_tool_use": True,
            "reasoning_level": "high",
            "knowledge_cutoff": "2024-04",
        },
        "claude-3-sonnet": {
            "context_window": 200000,
            "supports_vision": True,
            "supports_tool_use": True,
            "reasoning_level": "medium",
            "knowledge_cutoff": "2024-04",
        },
        "claude-3-haiku": {
            "context_window": 200000,
            "supports_vision": True,
            "supports_tool_use": True,
            "reasoning_level": "medium",
            "knowledge_cutoff": "2024-04",
        },
        "gpt-4": {
            "context_window": 8192,
            "supports_vision": False,
            "supports_tool_use": True,
            "reasoning_level": "high",
            "knowledge_cutoff": "2023-09",
        },
        "gpt-4-turbo": {
            "context_window": 128000,
            "supports_vision": True,
            "supports_tool_use": True,
            "reasoning_level": "high",
            "knowledge_cutoff": "2023-12",
        },
        "gpt-3.5-turbo": {
            "context_window": 16385,
            "supports_vision": False,
            "supports_tool_use": False,
            "reasoning_level": "low",
            "knowledge_cutoff": "2023-09",
        },
    }

    # 模型未知时的默认值
    DEFAULT_LARGE = {"reasoning_level": "high", "context_window": 128000}
    DEFAULT_SMALL = {"reasoning_level": "low", "context_window": 8192}

    @staticmethod
    def detect(model_name: str) -> dict:
        """检测模型能力"""
        # 精确匹配
        if model_name in ModelCapabilityDetector.MODEL_CAPABILITIES:
            return ModelCapabilityDetector.MODEL_CAPABILITIES[model_name].copy()

        # 前缀匹配
        for known, caps in ModelCapabilityDetector.MODEL_CAPABILITIES.items():
            if model_name.startswith(known):
                return caps.copy()

        # 基于名称的启发式推断
        name_lower = model_name.lower()
        if any(kw in name_lower for kw in ["large", "xl", "max", "opus", "4"]):
            return ModelCapabilityDetector.DEFAULT_LARGE.copy()
        if any(kw in name_lower for kw in ["small", "mini", "micro", "nano",
                                            "haiku", "3.5"]):
            return ModelCapabilityDetector.DEFAULT_SMALL.copy()

        return ModelCapabilityDetector.DEFAULT_LARGE.copy()

    @staticmethod
    def get_capability_guidance(capabilities: dict) -> str:
        """根据模型能力生成提示词指导"""
        guidance = []
        if capabilities["reasoning_level"] == "low":
            guidance.append(
                "注意: 当前模型推理能力有限。\n"
                "- 复杂任务请拆解为小步骤\n"
                "- 避免多步逻辑链\n"
                "- 提供更明确的中间结果检查点"
            )
        if capabilities["context_window"] < 16000:
            guidance.append(
                "注意: 当前模型上下文窗口较小。\n"
                "- 尽量压缩回答长度\n"
                "- 避免在对话中保留过多历史\n"
                "- 优先使用摘要而非完整内容"
            )
        if not capabilities["supports_tool_use"]:
            guidance.append(
                "注意: 当前模型不支持工具调用。\n"
                "- 只能提供建议，无法执行操作\n"
                "- 输出格式为文本，非结构化"
            )
        if not capabilities["supports_vision"]:
            guidance.append(
                "注意: 当前模型不支持图像理解。\n"
                "- 无法处理截图或图片内容\n"
                "- 请用户描述图片内容"
            )
        return "\n".join(guidance) if guidance else ""
```

## 三、环境感知注入的实现逻辑

### 3.1 完整注入管线

```
┌──────────────────────────────────────────────────────┐
│              环境感知注入管线                          │
│                                                       │
│  1. 环境检测阶段                                       │
│     ├─ OSDetector.detect()        → {os_type, ...}    │
│     ├─ ShellDetector.detect()     → {shell_type, ...}  │
│     ├─ ModelDetector.detect()     → {context_window}   │
│     └─ ToolRegistry.scan()        → {tools, ...}       │
│                                                       │
│  2. 规则适配阶段                                       │
│     ├─ 路径规则: Windows用\ vs Unix用/                 │
│     ├─ 命令语法: PowerShell用Get-Content vs cat        │
│     ├─ 安全规则: 只读FS禁止写操作                       │
│     └─ 输出规则: 小模型减少推理深度                     │
│                                                       │
│  3. 模板注入阶段                                       │
│     ├─ 填充 Jinja2 Context → base_layer.j2            │

│                                                       │
│  4. 验证阶段                                           │
│     ├─ 检查关键字段完整性                               │

│     └─ Token 预算检查                                  │
└──────────────────────────────────────────────────────┘
```

### 3.2 环境感知注入器的完整实现

```python
import os
from dataclasses import dataclass, field
from typing import Optional


@dataclass
class EnvironmentSnapshot:
    """环境状态快照 —— 包含所有检测到的环境信息"""
    os: dict = field(default_factory=dict)
    shell: dict = field(default_factory=dict)
    model: dict = field(default_factory=dict)
    tools: list = field(default_factory=list)
    locale: dict = field(default_factory=dict)
    permissions: dict = field(default_factory=dict)
    network: dict = field(default_factory=dict)


class EnvironmentAwareInjector:
    """环境感知注入器 —— 核心类"""

    def __init__(self, renderer, model_name: str = "unknown"):
        self.renderer = renderer
        self.model_name = model_name
        self.os_detector = OSDetector()
        self.shell_detector = ShellDetector()
        self.model_detector = ModelCapabilityDetector()

    def gather_environment(self) -> EnvironmentSnapshot:
        """收集所有环境信息"""
        return EnvironmentSnapshot(
            os=self.os_detector.detect(),
            shell=self.shell_detector.detect(),
            model=self.model_detector.detect(self.model_name),
            tools=self._scan_available_tools(),
            locale=self._detect_locale(),
            permissions=self._detect_permissions(),
            network=self._detect_network(),
        )

    def _scan_available_tools(self) -> list:
        """扫描当前环境可用的工具和命令"""
        tools = []
        # 检查常用工具是否存在
        common_tools = {
            "git": ["git", "--version"],
            "node": ["node", "--version"],
            "npm": ["npm", "--version"],
            "python": ["python", "--version"],
            "pip": ["pip", "--version"],
            "docker": ["docker", "--version"],
            "curl": ["curl", "--version"],
            "wget": ["wget", "--version"],
            "gcc": ["gcc", "--version"],
            "rustc": ["rustc", "--version"],
            "go": ["go", "version"],
        }
        for tool_name, cmd in common_tools.items():
            try:
                result = subprocess.run(
                    cmd, capture_output=True, text=True, timeout=2
                )
                if result.returncode == 0:
                    version = result.stdout.strip().split("\n")[0][:60]
                    tools.append({"name": tool_name, "available": True,
                                  "version": version})
                else:
                    tools.append({"name": tool_name, "available": False})
            except (FileNotFoundError, subprocess.TimeoutExpired):
                tools.append({"name": tool_name, "available": False})
        return tools

    def _detect_locale(self) -> dict:
        """检测语言和区域设置"""
        import locale
        try:
            sys_locale = locale.getdefaultlocale()
        except Exception:
            sys_locale = (None, None)
        return {
            "system_language": os.environ.get("LANG", sys_locale[0] or "en_US"),
            "preferred_language": os.environ.get("LC_ALL", ""),
            "encoding": sys.getfilesystemencoding(),
            "timezone": self._detect_timezone(),
        }

    def _detect_timezone(self) -> str:
        """检测时区"""
        try:
            import subprocess
            result = subprocess.run(
                ["powershell", "-Command", "(Get-TimeZone).Id"],
                capture_output=True, text=True, timeout=3
            )
            if result.returncode == 0:
                return result.stdout.strip()
        except Exception:
            pass
        # Linux/macOS 回退
        try:
            return os.path.realpath("/etc/localtime").split("/zoneinfo/")[1]
        except Exception:
            pass
        return "UTC"

    def _detect_permissions(self) -> dict:
        """检测当前进程的权限级别"""
        import os
        is_admin = False
        try:
            if platform.system() == "Windows":
                import ctypes
                is_admin = ctypes.windll.shell32.IsUserAnAdmin() != 0
            else:
                is_admin = os.geteuid() == 0
        except Exception:
            pass
        return {
            "is_admin": is_admin,
            "cwd_writable": os.access(os.getcwd(), os.W_OK),
        }

    def _detect_network(self) -> dict:
        """检测网络状态（简化版）"""
        import socket
        online = False
        try:
            socket.create_connection(("8.8.8.8", 53), timeout=2)
            online = True
        except OSError:
            pass
        return {
            "online": online,
            "has_proxy": bool(os.environ.get("HTTP_PROXY") or
                              os.environ.get("HTTPS_PROXY")),
        }

    def build_adapted_context(self, env: EnvironmentSnapshot) -> dict:
        """
        根据环境信息构建适配后的 Jinja2 上下文。
        这是核心适配逻辑 —— 根据环境差异调整注入内容。
        """
        # 基础上下文（始终注入）
        context = {
            "os_type": env.os["os_type"],
            "shell_type": env.shell["shell_type"],
            "path_separator": env.os["path_separator"],
            "line_ending": env.os["line_ending"],
            "home_dir": env.os["home_dir"],
            "cwd": os.getcwd(),
            "timezone": env.locale.get("timezone", "UTC"),
        }

        # 操作系统适配规则
        if env.os["is_windows"]:
            context["path_guidance"] = "路径使用 \\, 支持 C:/ 和 /mnt/c/"
            context["env_var_syntax"] = "%VAR%"  # cmd 语法
            if env.shell["is_powershell"]:
                context["env_var_syntax"] = "$env:VAR"
                context["default_ls"] = "Get-ChildItem"
                context["default_cat"] = "Get-Content"
            else:
                context["default_ls"] = "dir"
                context["default_cat"] = "type"
        else:
            context["path_guidance"] = "路径使用 /"
            context["env_var_syntax"] = "$VAR"
            context["default_ls"] = "ls"
            context["default_cat"] = "cat"

        # 模型能力适配
        if env.model["reasoning_level"] == "low":
            # 对推理能力弱的模型：拆解复杂指令
            context["complexity_mode"] = "simple"
            context["max_steps_without_check"] = 3  # 每3步需要一次检查
        else:
            context["complexity_mode"] = "normal"
            context["max_steps_without_check"] = 8

        # 工具集适配
        available_tools = [t["name"] for t in env.tools if t["available"]]
        context["available_tools_str"] = ", ".join(available_tools)
        # 关键工具缺失时添加警告
        missing_essential = []
        for essential in ["git", "python"]:
            if essential not in available_tools:
                missing_essential.append(essential)
        if missing_essential:
            context["tool_warning"] = (
                f"注意: 当前环境缺少 {', '.join(missing_essential)}。"
                "涉及这些工具的操作将不可用。"
            )

        # 权限适配
        if not env.permissions["cwd_writable"]:
            context["read_only_mode"] = True
            context["permission_guidance"] = "当前目录只读，无法创建或修改文件"
        if env.permissions["is_admin"]:
            context["admin_warning"] = "警告：当前以管理员权限运行，谨慎执行破坏性操作"

        # 网络适配
        if not env.network["online"]:
            context["offline_mode"] = True
            context["network_guidance"] = "当前无网络连接，所有联网操作不可用"

        # 语言适配
        lang = env.locale.get("system_language", "en_US")
        if lang.startswith("zh"):
            context["language"] = "zh-CN"
        elif lang.startswith("ja"):
            context["language"] = "ja-JP"
        else:
            context["language"] = "en-US"

        return context

    def inject(self) -> str:
        """
        执行完整的环境感知注入流程。
        返回适配后的完整 System Prompt。
        """
        # Step 1: 收集环境信息
        env = self.gather_environment()
        # Step 2: 构建适配上下文
        adapted_ctx = self.build_adapted_context(env)
        # Step 3: 注入渲染
        full_prompt = self.renderer.render_full_prompt(**adapted_ctx)
        return full_prompt
```

## 四、环境差异导致的典型失败模式

### 4.1 Windows vs Unix 的路径陷阱

```
场景: Agent 在 Windows 上运行，System Prompt 中硬编码了 Unix 路径格式

System Prompt: "在 /tmp 目录下创建临时文件"
Agent 行为: 尝试执行 mkdir /tmp，在 Windows 上失败
正确做法: 注入 os_type → "在临时目录 %TEMP% 下创建临时文件"
```

### 4.2 Shell 差异导致的命令错误

```
场景: Agent 在 Windows 上使用 Cmd 但提示词假设 Bash

System Prompt: "使用 cat 查看文件内容"
Agent 行为: 执行 cat，Cmd 不识别该命令
正确做法: 注入 shell_type → "使用 type 查看文件内容"

不同 Shell 的命令等价表:
| Unix 命令 | PowerShell    | Cmd    |
|-----------|---------------|--------|
| ls        | Get-ChildItem  | dir    |
| cat       | Get-Content    | type   |
| grep      | Select-String  | findstr|
| rm        | Remove-Item    | del    |
| mv        | Move-Item      | move   |
| cp        | Copy-Item      | copy   |
```

### 4.3 模型能力不足时的推理失败

```
场景: 使用 GPT-3.5 但 System Prompt 是基于 GPT-4 设计的

System Prompt: "请逐步推理，完成这个多步骤分析任务：..."
GPT-3.5 行为: 在前两步就开始偏离，且没有能力自行纠正
正确做法: 检测 reasoning_level=low → 将任务拆解为独立的小步骤，
          每步增加验证点，而非只写一个长流程
```

## 五、环境感知注入的提示词效果对比

### 5.1 是否为环境感知的对比

| 场景 | 无环境感知 | 有环境感知 |
|------|-----------|-----------|
| **Windows 路径操作** | Agent 尝试 `mkdir -p /tmp/test` → 失败 | Agent 执行 `mkdir C:\Users\...\test` → 成功 |
| **PowerShell 命令** | Agent 执行 `cat file.txt | grep pattern` → 失败 | Agent 执行 `Get-Content file.txt | Select-String pattern` → 成功 |
| **小模型推理** | Agent 尝试单步完成复杂推理 → 出现幻觉 | Agent 将任务拆解为小步骤，每步验证 → 准确率提升 |
| **离线环境** | Agent 尝试联网获取信息 → 超时 | Agent 提示无网络，仅使用本地信息 |
| **只读目录** | Agent 尝试写入文件 → 权限错误 | Agent 提示用户选择可写目录 |
| **无 Git 环境** | Agent 执行 git 操作 → "命令未找到" | Agent 提示"Git 不可用，建议手动操作" |

### 5.2 不同模型能力的提示词策略调整

```python
# 根据模型推理能力调整提示词策略
def get_reasoning_strategy(capabilities: dict) -> dict:
    """返回适配模型能力的提示词策略配置"""
    level = capabilities.get("reasoning_level", "medium")

    strategies = {
        "high": {
            "rule_density": "high",           # 可以处理高密度规则
            "chain_of_thought": "implicit",   # 不需要显式要求逐步推理
            "max_steps": 10,                  # 可处理多步推理
            "validation_frequency": "sparse", # 不需要频繁验证
            "abstraction_level": "high",      # 能理解抽象指令
        },
        "medium": {
            "rule_density": "medium",
            "chain_of_thought": "explicit",   # 需要显式要求逐步推理
            "max_steps": 6,
            "validation_frequency": "moderate",
            "abstraction_level": "medium",
        },
        "low": {
            "rule_density": "low",            # 规则少而明确
            "chain_of_thought": "forced",     # 必须分步执行
            "max_steps": 3,                   # 每 3 步需要 checkpoint
            "validation_frequency": "high",   # 每步都验证
            "abstraction_level": "low",       # 需要具体示例
        },
    }
    return strategies.get(level, strategies["medium"])
```

## 六、环境变化的事件响应

环境并非一成不变，Agent 运行时环境可能发生变化。需要监听的事件：

| 事件 | 触发条件 | 响应动作 |
|------|----------|----------|
| **目录切换** | 用户执行 cd 或其他目录变更操作 | 刷新 Context Layer 中的 cwd 字段 |
| **环境变量变更** | 检测到 PATH 或关键变量变化 | 重新扫描可用工具，更新 Tools Layer |
| **Shell 切换** | 从 Bash 切换到 PowerShell | 切 Shell 命令语法表，刷新 Tools Layer |
| **权限变化** | 权限提升或降级 | 更新 Permission 相关规则 |
| **网络状态变化** | 从离线变为在线或反之 | 刷新 Network 相关规则 |

```python
class EnvironmentChangeHandler:
    """环境变化事件处理器"""

    def __init__(self, injector: EnvironmentAwareInjector):
        self.injector = injector
        self.last_snapshot = injector.gather_environment()

    def on_directory_change(self, new_cwd: str):
        """目录切换事件"""
        os.chdir(new_cwd)
        # 只需要刷新上下文层，无需重建整个 System Prompt
        context = {
            "cwd": new_cwd,
        }
        updated_context = self.injector.renderer.render_context_layer(**context)
        # 将更新后的上下文注入到下一轮对话
        return updated_context

    def check_environment_change(self) -> Optional[str]:
        """检测环境是否发生变化，返回需要刷新的层级"""
        current = self.injector.gather_environment()
        changes = []

        if current.shell["shell_type"] != self.last_snapshot.shell["shell_type"]:
            changes.append("tools_layer")
            changes.append("rules_layer")
        if current.os["os_type"] != self.last_snapshot.os["os_type"]:
            changes.append("base_layer")  # OS 变化影响根本规则
            changes.append("rules_layer")

        self.last_snapshot = current
        return changes if changes else None
```

## 关键概念速查

| 术语 | 解释 |
|------|------|
| 环境感知注入 | System Prompt 自动检测并适配当前运行环境差异的机制 |
| OSDetector | 检测操作系统类型及特性的模块 |
| ShellDetector | 检测当前 Shell 类型并生成对应命令语法表的模块 |
| ModelCapabilityDetector | 基于模型名称推断其能力边界（上下文窗口、推理能力等） |
| 命令等价表 | 不同 Shell/系统下功能相同但语法不同的命令映射表 |
| 推理策略分级 | 根据模型推理能力强弱调整提示词密度和验证频率的策略 |
| 环境变化事件 | 运行时环境状态变化（目录切换、Shell 切换等）的响应机制 |
| 权限感知 | 检测当前进程权限级别并调整 Agent 操作范围的机制 |
