## 核心思想

前四节分别介绍了 Agent 的几种执行模式，但它们都共享一个底层架构：**LLM（大脑）+ Planning（规划）+ Memory（记忆）+ Tools（工具）**。这四大组件构成了任何 LLM Agent 的通用抽象层。

## 组件一：LLM（大脑）

LLM 是所有 Agent 的**中央处理器**，其他三个组件都由 LLM 驱动或与 LLM 交互。

### LLM 在 Agent 中的六项核心能力

| 能力 | 描述 | 在章节中的应用 |
|------|------|---------------|
| **推理 (Reasoning)** | 分析信息、推导结论 | ReAct 的 Thought 步骤（[2.1](./2.1-ReAct模式.md)） |
| **规划 (Planning)** | 将目标分解为可执行步骤 | Planner 生成执行计划（[2.2](./2.2-Plan-and-Execute.md)） |
| **工具选择 (Tool Selection)** | 决定何时调用哪个工具 | Action 步骤中的函数调用（[2.1](./2.1-ReAct模式.md)） |
| **工具参数生成** | 为工具调用生成正确的参数 | JSON 格式的 Action 输出（[2.1](./2.1-ReAct模式.md)） |
| **结果理解** | 解释工具返回的 Observation | Observation 到 Thought 的转换（[2.1](./2.1-ReAct模式.md)） |
| **自我评估** | 判断自身输出是否满足需求 | Evaluator 组件的核心（[2.4](./2.4-Reflexion模式.md)） |

### LLM 选型权衡

```python
class LLMConfig:
    """LLM 在 Agent 中的配置参数权衡"""
    
    def __init__(self, model_type: str):
        self.model_type = model_type
        
        if model_type == "frontier":  # 如 GPT-4, Claude 3.5 Sonnet
            self.reasoning_quality = 0.95  # 强推理
            self.latency_ms = 2000-5000    # 高延迟
            self.cost_per_1k_tokens = 0.015  # 高成本
            self.context_window = 128000    # 大上下文
            self.tool_use_reliability = 0.95  # 工具使用可靠
            
        elif model_type == "balanced":  # 如 GPT-4o-mini, Claude 3 Haiku
            self.reasoning_quality = 0.80
            self.latency_ms = 500-1500
            self.cost_per_1k_tokens = 0.002
            self.context_window = 128000
            self.tool_use_reliability = 0.85
            
        elif model_type == "fast":  # 如 Llama 3 8B, Gemma 2 9B
            self.reasoning_quality = 0.60
            self.latency_ms = 100-300
            self.cost_per_1k_tokens = 0.0002
            self.context_window = 32000
            self.tool_use_reliability = 0.60  # 小模型工具调用不稳定

# 常见策略：混合使用多个模型
class MultiLLMOrchestrator:
    """在 Agent 的不同环节使用不同能力的 LLM"""
    
    def __init__(self):
        self.planner_llm = LLMConfig("frontier")     # 规划需要强推理
        self.executor_llm = LLMConfig("balanced")    # 执行可以快一些
        self.evaluator_llm = LLMConfig("frontier")   # 评估需要高判断力
        self.critic_llm = LLMConfig("fast")          # 轻量检查用快速模型
```

**实践建议**：不要让单一 LLM 承担 Agent 中的所有角色。规划路径依赖强推理（用前沿模型），工具参数提取可以用平衡模型，关键字检查可以用快速模型。

## 组件二：Planning（规划）

Planning 决定了 Agent "做什么"和"按什么顺序做"。前几节介绍了三种规划模式，这里汇总对比。

### 三种规划模式的统一接口

```python
from abc import ABC, abstractmethod
from typing import Any

class PlanningStrategy(ABC):
    """规划策略的抽象接口"""
    
    @abstractmethod
    def create_plan(self, task: str, tools: list[str]) -> Any:
        """为任务创建执行计划"""
        pass
    
    @abstractmethod
    def update_plan(self, plan: Any, feedback: Any) -> Any:
        """根据执行反馈更新计划"""
        pass
    
    @abstractmethod
    def is_complete(self, plan: Any, state: Any) -> bool:
        """判断计划是否已全部完成"""
        pass


class ReActivePlanning(PlanningStrategy):
    """ReAct 的即兴规划——不做明确计划，每步动态决策"""
    # 对应 2.1 节
    def create_plan(self, task, tools):
        return {"strategy": "react", "task": task, "tools": tools}
    
    def update_plan(self, plan, feedback):
        # ReAct 不需要更新计划——每步从头生成
        return plan
    
    def is_complete(self, plan, state):
        return "Final Answer" in str(state)


class StaticPlanning(PlanningStrategy):
    """Plan-and-Execute 的静态规划——执行前固定"""
    # 对应 2.2 节
    def create_plan(self, task, tools):
        return planner_llm.generate(f"为 {task} 生成固定步骤计划")
    
    def update_plan(self, plan, feedback):
        # 静态规划不支持更新
        raise NotImplementedError("Static planning does not support updates")
    
    def is_complete(self, plan, state):
        return all(step["done"] for step in plan["steps"])


class HybridPlanning(PlanningStrategy):
    """Plan-then-ReAct 的分层规划——宏观计划 + 微观灵活"""
    # 对应 2.3 节
    def create_plan(self, task, tools):
        return {"macro_steps": self._generate_macro_steps(task, tools)}
    
    def update_plan(self, plan, feedback):
        # 支持轻量级重规划
        if self._should_replan(feedback):
            remaining = [s for s in plan["macro_steps"] if not s["done"]]
            plan["macro_steps"] = self._replan_remaining(remaining, feedback)
        return plan
    
    def is_complete(self, plan, state):
        return all(s.get("done", False) for s in plan["macro_steps"])
```

### 规划的四个关键设计维度

| 维度 | 选项 | 影响 |
|------|------|------|
| **粒度** | 粗粒度（5-10 步）vs 细粒度（20-50 步） | 粗粒度灵活但方向感弱；细粒度方向感强但僵化 |
| **修正策略** | 静态（不修正）vs 条件触发（异常时修正）vs 持续修正（每步后重规划） | 修正越频繁，适应越强但 Token 消耗越大 |
| **并行度** | 串行（顺序执行）vs DAG（可并行） | DAG 降低延迟但增加调度复杂度 |
| **反馈利用** | 无反馈 vs 结果反馈 vs 反思反馈 | 深度利用反馈可提升质量（如 Reflexion） |

## 组件三：Memory（记忆）

Memory 让 Agent 不再是"每次对话都失忆"的纯无状态系统。

### 三层记忆架构

```
┌────────────────────────────────────────────────┐
│               记忆系统架构                         │
│                                                    │
│  ┌──────────────────┐  容量: 大   持久性: 跨任务   │
│  │  长期记忆 (LTM)   │  存储: 经验、知识、模式     │
│  │  ┌────────────┐  │  检索: embedding + 权重排序  │
│  │  │ SQL/Vector │  │                             │
│  │  │  Database  │  │                             │
│  │  └────────────┘  │                             │
│  └────────┬─────────┘                             │
│           │ 转移（经验固化）                         │
│           ▼                                        │
│  ┌──────────────────┐  容量: 中   持久性: 单任务   │
│  │  短期记忆 (STM)   │  存储: 当前任务轨迹          │
│  │                   │  管理: 最近 N 步 + 摘要     │
│  │  (LLM 上下文窗口)  │  消耗: tokens（需成本控制）  │
│  └────────┬─────────┘                             │
│           │ 注入上下文                               │
│           ▼                                        │
│  ┌──────────────────┐  容量: 小   持久性: 单步     │
│  │  工作记忆 (WM)    │  存储: 当前 Thought/Action  │
│  │                   │  管理: 即时生成即时使用      │
│  └──────────────────┘                             │
│                                                    │
└────────────────────────────────────────────────┘
```

### 三种记忆的工程实现

```python
class MemorySystem:
    """统一的记忆系统，管理三层记忆的读写"""
    
    def __init__(self):
        self.working_memory = WorkingMemory()      # 工作记忆
        self.short_term_memory = ShortTermMemory()  # 短期记忆
        self.long_term_memory = LongTermMemory()    # 长期记忆
    
    def observe(self, observation: dict):
        """Agent 每步的执行结果都被记忆系统观察"""
        # 1. 写入工作记忆
        self.working_memory.current_step = observation
        
        # 2. 追加到短期记忆
        self.short_term_memory.append(observation)
        
        # 3. 触发长期记忆的联想学习
        self.long_term_memory.associative_learn(observation)
    
    def get_context(self, task: str, max_tokens: int = 4000) -> str:
        """为 LLM 构建包含记忆的上下文提示"""
        # 从长期记忆中检索相关经验
        ltm_context = self.long_term_memory.retrieve(
            query=task, top_k=3, max_tokens=1000
        )
        
        # 从短期记忆中获取最近轨迹摘要
        stm_context = self.short_term_memory.summarize(max_tokens=2000)
        
        # 合并
        return f"""
## 相关经验（长期记忆）
{ltm_context}

## 当前执行进度（短期记忆）
{stm_context}

## 当前步骤（工作记忆）
{self.working_memory.current_step}
"""


class ShortTermMemory:
    """短期记忆：LLM 上下文窗口内的执行历史"""
    
    def __init__(self, max_steps=20, summary_model=None):
        self.steps = []          # 存储最近的 Thought-Action-Obs 三元组
        self.max_steps = max_steps
        self.summary_model = summary_model  # 用于生成摘要的轻量 LLM
    
    def append(self, step: dict):
        self.steps.append(step)
        if len(self.steps) > self.max_steps:
            # 最早的步骤被移出，但生成摘要保留关键信息
            self._summarize_oldest()
    
    def summarize(self, max_tokens=2000) -> str:
        """生成短期记忆的摘要"""
        # 最近的步骤保留完整，早期的步骤用摘要代替
        recent = self.steps[-5:]  # 最近 5 步保留完整
        if len(self.steps) > 5:
            early_summary = self._get_summary()
            return f"[历史摘要]: {early_summary}\n[最近步骤]: {recent}"
        return str(self.steps)
    
    def _summarize_oldest(self):
        """将最早的步骤压缩为摘要"""
        # 实际实现可用 LLM 生成摘要
        oldest = self.steps.pop(0)
        self._accumulated_summary = f"{self._accumulated_summary}\n- {oldest['goal']}: {oldest['result'][:100]}"
    
    def clear(self):
        self.steps = []
        self._accumulated_summary = ""


class LongTermMemory:
    """长期记忆：向量数据库存储的跨任务经验"""
    
    def __init__(self, storage_backend="vector_db"):
        self.storage = []  # 实际应使用向量数据库
        self.embedding_model = None  # 用于生成检索 embedding
        
        # 不同类型的记忆
        self.experiences = []    # 经验教训（来自 Reflexion）
        self.knowledge = []      # 领域知识（用户提供或自动抽取）
        self.patterns = []       # 行为模式（自动发现的重复模式）
    
    def store(self, item: dict):
        """存储到长期记忆"""
        item["timestamp"] = time.now()
        item["access_count"] = 0
        item["embedding"] = self._embed(item["content"])
        self.storage.append(item)
    
    def retrieve(self, query: str, top_k: int = 3, 
                 max_tokens: int = 1000) -> str:
        """检索最相关的长期记忆"""
        query_emb = self._embed(query)
        scored = [
            (self._cosine_sim(query_emb, item["embedding"]), item)
            for item in self.storage
        ]
        scored.sort(reverse=True)
        results = scored[:top_k]
        
        # 更新访问计数
        for _, item in results:
            item["access_count"] += 1
        
        return "\n".join(
            f"- {r['content'][:max_tokens // top_k]}"
            for _, r in results
        )
    
    def forget(self, threshold_days=30, min_access=2):
        """遗忘策略：移除长期未访问且访问次数少的记忆"""
        now = time.now()
        self.storage = [
            item for item in self.storage
            if (now - item["timestamp"]).days < threshold_days
            or item["access_count"] >= min_access
        ]
```

### 记忆的四大关键操作

| 操作 | 方法 | 触发时机 | 实现 |
|------|------|----------|------|
| **写入** | `store()` | Agent 每步执行后、反思生成后 | 结构化存储（含 embedding、时间戳） |
| **检索** | `retrieve()` | 每步开始前、新任务开始时 | 向量相似度 + 权重排序 |
| **更新** | `update()` | 经验验证成功/失败后 | 调整权重、修正内容 |
| **遗忘** | `forget()` | 定时触发、容量超限时 | LRU / 时间衰减 / 重要性阈值 |

## 组件四：Tools（工具）

Tools 是 Agent 与外部世界交互的接口。没有工具，LLM 只是一个"大脑被关在黑箱里"的系统。

### 工具的类型体系

```python
from enum import Enum
from typing import Any
import json

class ToolCategory(Enum):
    PERCEPTION = "perception"     # 感知工具：读取外部信息
    ACTION = "action"             # 行动工具：对外部产生影响
    COMPUTATION = "computation"   # 计算工具：数据处理
    COMMUNICATION = "comm"        # 通信工具：与其他系统交互
    MEMORY = "memory"             # 记忆工具：读写 Agent 自身记忆

class BaseTool:
    """工具的基类定义"""
    
    def __init__(self, name: str, description: str, category: ToolCategory):
        self.name = name
        self.description = description
        self.category = category
        self.call_count = 0
        self.error_count = 0
    
    def execute(self, **kwargs) -> str:
        """执行工具并返回结果"""
        self.call_count += 1
        try:
            result = self._run(**kwargs)
            return self._format_result(result)
        except Exception as e:
            self.error_count += 1
            return f"Tool execution error: {str(e)}"
    
    def _run(self, **kwargs) -> Any:
        """子类实现具体的工具逻辑"""
        raise NotImplementedError
    
    def _format_result(self, result: Any) -> str:
        """格式化结果为 LLM 友好的文本"""
        if isinstance(result, str):
            return result[:2000]  # 截断过长结果
        return json.dumps(result, ensure_ascii=False)[:2000]
    
    def to_openai_schema(self) -> dict:
        """生成 OpenAI 函数调用格式的 schema"""
        return {
            "type": "function",
            "function": {
                "name": self.name,
                "description": self.description,
                "parameters": self.get_parameters_schema()
            }
        }
    
    def get_parameters_schema(self) -> dict:
        """返回工具参数的 JSON Schema"""
        raise NotImplementedError
```

## 四组件的完整协作循环

现在将四个组件集成到一个完整的 Agent 循环中：

```python
class CompleteAgent:
    """集成了四组件的完整 Agent"""
    
    def __init__(self, llm_config: dict, tool_list: list[BaseTool]):
        # 组件一：LLM（大脑）
        self.main_llm = self._init_llm(llm_config["main"])
        self.planner_llm = self._init_llm(llm_config.get("planner", llm_config["main"]))
        self.evaluator_llm = self._init_llm(llm_config.get("evaluator", llm_config["main"]))
        
        # 组件二：Planning（规划）
        self.planning = HybridPlanning()  # 使用混合规划策略
        
        # 组件三：Memory（记忆）
        self.memory = MemorySystem()
        
        # 组件四：Tools（工具）
        self.tools = {t.name: t for t in tool_list}
        # 注入记忆工具
        self.tools["memorize"] = MemorizeTool(self.memory)
        self.tools["recall"] = RecallTool(self.memory)
    
    def run(self, task: str, max_global_steps: int = 30) -> str:
        """Agent 主循环"""
        print(f"[Agent] 开始处理任务: {task}")
        
        # === 阶段一：规划 ===
        plan = self.planning.create_plan(
            task=task,
            tools=list(self.tools.keys())
        )
        print(f"[Planning] 计划生成: {len(plan['macro_steps'])} 个宏观步骤")
        
        # === 阶段二：执行循环 ===
        global_step = 0
        step_results = []
        
        while not self.planning.is_complete(plan, step_results):
            if global_step >= max_global_steps:
                return "[Agent] 达到最大全局步数，任务终止"
            
            # 获取当前要执行的步骤
            current_step = self._get_current_step(plan, step_results)
            
            # 构建带记忆的上下文
            context = self.memory.get_context(
                task=f"{task} - 当前步骤: {current_step['goal']}",
                max_tokens=4000
            )
            
            # === ReAct 子循环执行当前步骤 ===
            step_result = self._execute_step_with_react(
                step_goal=current_step["goal"],
                context=context,
                max_substeps=current_step.get("max_substeps", 5)
            )
            
            # 记录步骤结果
            step_results.append({
                "step_id": current_step["step_id"],
                "goal": current_step["goal"],
                "result": step_result,
                "status": "completed"
            })
            
            # === 记忆系统观察 ===
            self.memory.observe({
                "step": current_step["step_id"],
                "goal": current_step["goal"],
                "result": step_result
            })
            
            # === 反思（可选） ===
            if self._should_reflect(step_result):
                reflection = self._reflect_on_step(
                    current_step, step_result
                )
                self.memory.long_term_memory.store({
                    "content": reflection,
                    "importance": "high",
                    "source": "self_reflection"
                })
            
            # === 重规划检查 ===
            plan = self.planning.update_plan(
                plan=plan,
                feedback={"step_result": step_result, "step_results": step_results}
            )
            
            global_step += 1
        
        # === 阶段三：生成最终答案 ===
        final_answer = self.main_llm.generate(
            f"基于以下执行结果，回答用户的任务：{task}\n\n"
            f"各步骤结果：{json.dumps(step_results, ensure_ascii=False, indent=2)}"
        )
        
        print(f"[Agent] 任务完成，共 {global_step} 个全局步骤")
        return final_answer
    
    def _execute_step_with_react(self, step_goal: str, context: str, 
                                 max_substeps: int) -> str:
        """步骤内的 ReAct 子循环"""
        history = [
            {"role": "system", "content": f"当前目标: {step_goal}\n{context}"}
        ]
        
        for substep in range(max_substeps):
            # Thought 生成
            response = self.main_llm.generate(
                messages=history,
                tools=[t.to_openai_schema() for t in self.tools.values()]
            )
            
            content = response.content
            
            # 检查是否完成
            if self._is_step_complete(content, step_goal):
                return self._extract_result(content)
            
            history.append({"role": "assistant", "content": content})
            
            # 解析工具调用
            tool_calls = response.tool_calls if hasattr(response, 'tool_calls') else []
            
            if tool_calls:
                for tc in tool_calls:
                    tool_name = tc.function.name
                    tool_args = json.loads(tc.function.arguments)
                    
                    # 工具执行
                    if tool_name in self.tools:
                        observation = self.tools[tool_name].execute(**tool_args)
                    else:
                        observation = f"Error: unknown tool '{tool_name}'"
                    
                    history.append({
                        "role": "tool",
                        "tool_call_id": tc.id,
                        "content": observation
                    })
        
        # 子步骤超限
        return f"[Warning] 子步骤数超限，返回部分结果"
    
    def _should_reflect(self, step_result: str) -> bool:
        """判断是否需要对步骤结果进行反思"""
        # 触发条件：错误、警告、或 Agent 表现异常
        error_keywords = ["error", "fail", "warning", "exception", "timeout"]
        return any(kw in str(step_result).lower() for kw in error_keywords)
    
    def _reflect_on_step(self, step, result) -> str:
        """反思步骤并生成经验"""
        prompt = f"""步骤目标: {step['goal']}
步骤结果: {result}

请反思：
1. 这个步骤成功吗？如果不成功，原因是什么？
2. 从这次执行中能学到什么？
3. 下次遇到类似步骤时应该如何改进？"""
        
        return self.evaluator_llm.generate(prompt)
    
    def _get_current_step(self, plan, completed):
        """从计划中获取下一个要执行的步骤"""
        for step in plan["macro_steps"]:
            if not step.get("done"):
                deps = step.get("depends_on", [])
                if all(d in [c["step_id"] for c in completed] for d in deps):
                    return step
        return None
    
    def _is_step_complete(self, response, goal):
        """判断步骤目标是否达成"""
        # 简单实现：检查是否有明确的完成标记
        return "[DONE]" in response or "步骤完成" in response
```

|----------|-----|----------|--------|-------|------|

| [2.4 Reflexion](./2.4-Reflexion%E6%A8%A1%E5%BC%8F.md) | 评估用独立 LLM | 无显式规划（可结合 2.3） | 长期记忆 + 短期记忆 | 基础工具集 + 反思工具 | 反思驱动经验积累 |

## 关键概念速查表

| 概念 | 定义 | 要点 |
|------|------|------|
| **LLM（大脑）** | Agent 的推理和决策核心 | 承担推理、规划、工具选择、结果理解、自我评估六项能力；不同环节可用不同模型 |
| **Planning（规划）** | 将目标分解为可执行步骤的机制 | 支持 ReAct（隐式）、Static（一次性）、Hybrid（分层）三种策略 |
| **Memory（记忆）** | Agent 的状态持久化系统 | 工作记忆（当前步）、短期记忆（当前任务轨迹）、长期记忆（跨任务经验）；支持写入、检索、更新、遗忘 |
| **Tools（工具）** | Agent 与外部世界交互的接口 | 分为感知、行动、计算、通信、记忆五类；每个工具需提供名称、描述、参数 Schema |
| **分层规划** | 高层规划方向 + 低层 ReAct 执行 | 2.3 节的核心贡献；工业界最常用 |
| **反思循环** | 执行后评估并生成经验 | 2.4 节引入；填充了四组件中 Memory→Planning 的反馈回路 |
| **多 LLM 混合** | 不同环节使用不同能力的模型 | 规划用强模型（高推理）、执行用均衡模型（低成本）、检查用快速模型（低延迟） |
