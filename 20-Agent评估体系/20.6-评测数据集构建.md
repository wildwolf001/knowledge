# 20.6 评测数据集构建

> 评估 Agent 需要高质量的评测数据集。一个粗制滥造的 eval set 比没有 eval set 更糟糕——它会给你虚假的安全感，让你在错误的方向上"优化"Agent。**评估数据的质量直接决定了评估结果的可信度。**

---

## 一、为什么需要自建评测数据集？

### 1.1 公开基准的局限性

虽然 20.2 节介绍的四大基准（WebArena、OSWorld、SWE-Bench、GAIA）提供了通用评估框架，但它们无法覆盖每个团队的特定场景：

| 局限 | 说明 | 影响 |
|------|------|------|
| **领域不匹配** | 公开基准覆盖的是通用场景，不是你的业务领域 | 无法评估你的 Agent 在金融/医疗/法律等领域的表现 |
| **难度不匹配** | 公开基准的任务难度固定，可能远高于或低于你的实际场景 | 无法反映你的 Agent 在真实用户需求下的表现 |
| **时效性** | 基准数据集发布后就固定了，无法反映新出现的问题类型 | 评估可能过时 |
| **语言覆盖** | 主流基准以英文为主，中文或其他语言覆盖不足 | 中文 Agent 缺乏有效评估 |
| **任务类型缺失** | 公开基准不包含你的 Agent 特有的任务类型（如特定的工具调用链） | 核心能力缺乏评估 |

### 1.2 自建数据集的适用场景

| 场景 | 建议方案 |
|------|---------|
| **业务领域特定评估** | 自建领域专用 eval set（如保险理赔、技术支持） |
| **Agent 工具调用评估** | 自建工具调用场景测试集 |
| **中文或其他语言** | 自建特定语言的 eval set |
| **安全与边界测试** | 自建对抗性测试集（adversarial test set） |
| **回归测试** | 从生产数据中构建回归测试集（见 20.4 节） |

## 二、评测数据集构建方法论

### 2.1 数据集构建的完整流程

```
阶段 1：需求定义
├── 确定评估目标（评估什么能力？）
├── 定义任务类型（分类、生成、多步任务等）
├── 确定难度分布（简单:中等:困难 = 3:5:2）
└── 确定数量目标（最小统计有效样本量）

阶段 2：数据采集与生成
├── 真实数据采集（生产日志、用户反馈）
├── 人工编写（领域专家创作）
├── LLM 辅助生成（人工审核）
└── 数据增强（模板化变体、难度扩展）

阶段 3：标注与质量控制
├── 制定标注规范（Labeling Guideline）
├── 标注员培训与校准
├── 多重标注 + IAA 计算
└── 争议样本仲裁

阶段 4：验证与发布
├── 内部自洽性验证（标注一致性检查）
├── 外部有效性验证（样本与真实分布对比）
├── 训练/评估数据隔离
└── 版本管理与更新
```

### 2.2 数据采集策略

**策略一：从生产日志中采样**

从真实的 Agent 生产日志中提取有代表性的任务：

```python
def sample_from_production_logs(logs: list, target_distribution: dict) -> list:
    """
    从生产日志中采样构建 eval set
    
    Args:
        logs: 生产日志列表，每条包含 task、user_intent、difficulty 等字段
        target_distribution: 目标分布，如 {"easy": 0.3, "medium": 0.5, "hard": 0.2}
    
    Returns:
        sampled_eval_set: 采样后的评估数据集
    """
    from collections import defaultdict
    import random
    
    # 按难度分层
    stratified = defaultdict(list)
    for log in logs:
        difficulty = log.get("difficulty", "medium")
        stratified[difficulty].append(log)
    
    # 按目标分布采样
    sampled = []
    for difficulty, target_pct in target_distribution.items():
        available = stratified.get(difficulty, [])
        target_count = int(len(logs) * target_pct)
        
        if len(available) >= target_count:
            sampled.extend(random.sample(available, target_count))
        else:
            # 可用数据不足时全取
            sampled.extend(available)
            # 从其他难度补充
            shortage = target_count - len(available)
            supplement = [
                l for l in logs if l not in sampled
            ]
            if supplement:
                sampled.extend(random.sample(
                    supplement, min(shortage, len(supplement))
                ))
    
    return sampled
```

**策略二：LLM 辅助生成 + 人工审核**

结合 LLM 的生成能力和人类的判断力：

```python
class EvalSetGenerator:
    """
    LLM 辅助的评估数据集生成器
    
    使用 LLM 生成候选题目，人工审核后入库
    """
    
    def __init__(self, llm, domain_expertise: str):
        self.llm = llm
        self.domain = domain_expertise
    
    def generate_candidates(self, 
                           template: str, 
                           count: int,
                           difficulty: str = "medium") -> list:
        """
        基于模板批量生成候选题目
        
        Args:
            template: 生成模板
            count: 生成数量
            difficulty: 难度
        
        Returns:
            candidates: 候选题目列表
        """
        prompt = f"""你是 {self.domain} 领域的评测数据生成专家。
请根据以下模板生成 {count} 个 {difficulty} 难度的 Agent 评估任务。

模板：
{template}

要求：
1. 每个任务必须包含：task（任务描述）、expected_answer（参考答案）、
   evaluation_criteria（评估标准）
2. 任务难度为 {difficulty}
3. 任务应覆盖不同的子场景和边界情况
4. 确保任务有明确的可验证性（答案唯一或可判断）

请以 JSON 格式输出：
{{
    "tasks": [
        {{
            "task": "...",
            "expected_answer": "...",
            "evaluation_criteria": "...",
            "difficulty": "{difficulty}",
            "sub_scenario": "..."
        }}
    ]
}}
"""
        response = self.llm.generate(prompt)
        
        try:
            import re, json
            json_match = re.search(r'\{.*\}', response, re.DOTALL)
            if json_match:
                data = json.loads(json_match.group())
                candidates = data.get("tasks", [])
                
                # 为每个候选题目添加元信息
                for c in candidates:
                    c["source"] = "llm_generated"
                    c["status"] = "pending_review"
                
                return candidates
        except (json.JSONDecodeError, AttributeError):
            pass
        
        return []
    
    def difficulty_escalation(self, base_task: dict, target_difficulty: str) -> dict:
        """
        基于基础任务生成更高难度的变体
        """
        escalation_prompt = f"""
        将以下 {target_difficulty} 难度的 Agent 评估任务
        升级为更难的版本。

        原始任务：{base_task['task']}
        原始答案：{base_task['expected_answer']}
        当前难度：{base_task.get('difficulty', 'easy')}
        目标难度：{target_difficulty}

        升级策略：
        - 增加多步推理
        - 引入多个工具的组合使用
        - 增加干扰信息
        - 添加约束条件
        """
        
        response = self.llm.generate(escalation_prompt)
        return {"task": response, "base_task": base_task, "difficulty": target_difficulty}
```

## 三、数据标注质量控制

### 3.1 标注规范（Labeling Guideline）

标注规范是数据质量的基石。规范的标注指南应包括：

1. **任务边界定义**：什么算一个"任务"？什么情况下任务算"完成"？
2. **质量维度定义**：准确性、完整性、有用性、安全性分别怎么打分？
3. **边界案例处理**：哪些情况需要特殊处理？（如部分正确的回答）
4. **标注示例**：每个评分等级至少提供 2-3 个示例
5. **常见错误示例**：标注员容易犯错的地方

## 3.2 完整度评分标准（Completeness Scoring）

### 5 分（完全完整）
回答覆盖了用户问题的所有方面，并且没有遗漏任何必要信息。
示例：

### 3.2 标注员培训与校准

训练-校准循环：

```python
class AnnotatorTraining:
    """
    标注员培训与校准系统
    
    确保不同标注员对相同的标注标准有一致的理解
    """
    
    def __init__(self, gold_standard_set: list):
        """
        Args:
            gold_standard_set: 金标准数据集（由专家预先标注）
        """
        self.gold_set = gold_standard_set
        self.annotator_history = {}  # {annotator_id: [calibration_results]}
    
    def calibrate_annotator(self, annotator_id: str, annotation_fn) -> dict:
        """
        对标注员进行校准评估
        
        Args:
            annotator_id: 标注员 ID
            annotation_fn: 标注函数（输入 task 返回 label）
        
        Returns:
            calibration_result: 校准结果
        """
        correct = 0
        total = len(self.gold_set)
        
        for item in self.gold_set:
            predicted_label = annotation_fn(item["task"])
            true_label = item["label"]
            
            if predicted_label == true_label:
                correct += 1
        
        accuracy = correct / total
        
        result = {
            "annotator_id": annotator_id,
            "accuracy": accuracy,
            "correct": correct,
            "total": total,
            "qualified": accuracy >= 0.85  # 合格标准：85% 准确率
        }
        
        if annotator_id not in self.annotator_history:
            self.annotator_history[annotator_id] = []
        self.annotator_history[annotator_id].append(result)
        
        return result
    
    def training_feedback(self, annotator_id: str, errors: list) -> str:
        """
        基于错误生成个性化培训反馈
        """
        # 分析错误模式
        error_patterns = {}
        for err in errors:
            pattern = err.get("error_type", "unknown")
            error_patterns[pattern] = error_patterns.get(pattern, 0) + 1
        
        # 生成反馈
        feedback = f"标注员 {annotator_id} 的校准反馈：\n"
        feedback += f"错误总数：{len(errors)}\n"
        feedback += "错误模式：\n"
        
        for pattern, count in sorted(error_patterns.items(), key=lambda x: -x[1]):
            feedback += f"  - {pattern}：{count} 次\n"
        
        # 提供纠正指导
        feedback += "\n纠正建议：\n"
        # 从金标准中提取纠正示例
        for err in errors[:3]:
            feedback += f"  - 案例：{err.get('task', 'N/A')}\n"
            feedback += f"    你的标注：{err.get('your_label', 'N/A')}\n"
            feedback += f"    正确标注：{err.get('correct_label', 'N/A')}\n"
            feedback += f"    原因：{err.get('reason', 'N/A')}\n\n"
        
        return feedback
```

### 3.3 Inter-Annotator Agreement（IAA）计算

IAA（标注者间一致性）是衡量数据标注质量的核心指标。它量化了不同标注员对同一批数据的标注结果的一致程度。

#### 3.3.1 Percent Agreement（简单一致率）

最直观的 IAA 指标，但不考虑随机一致的可能性：

```python
def percent_agreement(annotations_a: list, annotations_b: list) -> float:
    """
    计算简单一致率
    
    公式：P_o = 一致的样本数 / 总样本数
    
    Args:
        annotations_a: 标注员 A 的标注结果
        annotations_b: 标注员 B 的标注结果
    
    Returns:
        agreement: 一致率 (0-1)
    """
    if len(annotations_a) != len(annotations_b):
        raise ValueError("两个标注员的标注数量必须一致")
    
    total = len(annotations_a)
    if total == 0:
        return 0.0
    
    agreements = sum(1 for a, b in zip(annotations_a, annotations_b) if a == b)
    return agreements / total
```

#### 3.3.2 Cohen's Kappa（两位标注员）

Cohen's Kappa 校正了随机一致的概率，是两位标注员场景下的标准 IAA 指标：

```
κ = (P_o - P_e) / (1 - P_e)

P_o = 观察一致率
P_e = 随机一致概率（边际分布的乘积之和）
```

```python
def cohens_kappa_detailed(annotations_a: list, annotations_b: list) -> dict:
    """
    计算 Cohen's Kappa 及其详细统计量
    
    适用场景：两位标注员，分类标注（包括有序分类）
    
    Args:
        annotations_a: 标注员 A 的评分列表
        annotations_b: 标注员 B 的评分列表
    
    Returns:
        kappa_result: 包含 Kappa 值和详细统计
    """
    from sklearn.metrics import cohen_kappa_score, confusion_matrix
    
    # 基本 Kappa
    kappa = cohen_kappa_score(annotations_a, annotations_b)
    
    # 混淆矩阵
    labels = sorted(set(annotations_a + annotations_b))
    cm = confusion_matrix(annotations_a, annotations_b, labels=labels)
    
    # 计算 P_o 和 P_e
    total = len(annotations_a)
    po = np.trace(cm) / total
    
    row_sums = cm.sum(axis=1)
    col_sums = cm.sum(axis=0)
    pe = sum(row_sums[i] * col_sums[i] for i in range(len(labels))) / (total ** 2)
    
    # 加权 Kappa（适用于有序分类，如 1-5 分）
    # 使用二次加权，更接近实际评分场景
    weighted_kappa = cohen_kappa_score(
        annotations_a, annotations_b, weights='quadratic'
    )
    
    # 逐个类别的条件 Kappa
    category_kappa = {}
    for i, label in enumerate(labels):
        # 二值化：将当前类别 vs 其他
        binary_a = [1 if a == label else 0 for a in annotations_a]
        binary_b = [1 if b == label else 0 for b in annotations_b]
        cat_kappa = cohen_kappa_score(binary_a, binary_b)
        category_kappa[label] = round(cat_kappa, 4)
    
    return {
        "kappa": round(kappa, 4),
        "weighted_kappa_quadratic": round(weighted_kappa, 4),
        "percent_agreement": round(po, 4),
        "expected_agreement": round(pe, 4),
        "confusion_matrix": cm.tolist(),
        "labels": labels,
        "category_kappa": category_kappa,
        "interpretation": _interpret_kappa(kappa),
        "sample_size": total,
        "n_annotators": 2
    }


def _interpret_kappa(kappa: float) -> str:
    """解释 Kappa 值"""
    if kappa < 0.0:
        return "一致性极差（低于随机水平）"
    elif kappa < 0.20:
        return "一致性较差（slight agreement）"
    elif kappa < 0.40:
        return "一致性一般（fair agreement）"
    elif kappa < 0.60:
        return "中度一致（moderate agreement）"
    elif kappa < 0.80:
        return "高度一致（substantial agreement）"
    else:
        return "几乎完全一致（almost perfect agreement）"
```

#### 3.3.3 Fleiss' Kappa（多位标注员）

当有超过两位标注员时，使用 Fleiss' Kappa：

```python
def fleiss_kappa(annotations_matrix: list) -> dict:
    """
    计算 Fleiss' Kappa
    
    适用场景：多位标注员（≥ 3 位），分类标注
    
    Args:
        annotations_matrix: N × K 矩阵
            N = 样本数, K = 标注员数
            每个元素是标注员对该样本的标注类别
    
    Returns:
        result: Fleiss' Kappa 值及统计量
    """
    import numpy as np
    
    n_samples = len(annotations_matrix)  # N
    n_annotators = len(annotations_matrix[0])  # K
    
    # 获取所有可能的类别
    all_labels = set()
    for row in annotations_matrix:
        all_labels.update(row)
    labels = sorted(all_labels)
    n_categories = len(labels)  # k
    
    # 构建 N × k 矩阵：每个样本被分到每个类别的标注员数
    label_to_idx = {l: i for i, l in enumerate(labels)}
    n_ij = np.zeros((n_samples, n_categories), dtype=int)
    
    for i, row in enumerate(annotations_matrix):
        for annotation in row:
            j = label_to_idx[annotation]
            n_ij[i, j] += 1
    
    # 步骤 1：计算每个样本的一致度 P_i
    # P_i = (Σ_j n_ij² - n_annotators) / (n_annotators × (n_annotators - 1))
    P_i = (np.sum(n_ij ** 2, axis=1) - n_annotators) / (
        n_annotators * (n_annotators - 1)
    )
    
    # 平均 P_bar
    P_bar = np.mean(P_i)
    
    # 步骤 2：计算每个类别的边际比例 p_j
    # p_j = (Σ_i n_ij) / (N × K)
    p_j = np.sum(n_ij, axis=0) / (n_samples * n_annotators)
    
    # 步骤 3：计算 P_e（随机一致的期望概率）
    P_e = np.sum(p_j ** 2)
    
    # 步骤 4：Fleiss' Kappa
    if P_e == 1:
        kappa = 1.0
    else:
        kappa = (P_bar - P_e) / (1 - P_e)
    
    # 方差计算（近似）
    var_terms = []
    for j in range(n_categories):
        for l in range(n_categories):
            if j != l:
                # 简化的方差近似
                var_terms.append(p_j[j] * p_j[l] / (1 - P_e) ** 2)
    
    variance = 2 * sum(var_terms) / (n_samples * n_annotators * (n_annotators - 1))
    std_error = np.sqrt(variance)
    
    # 置信区间
    z = 1.96  # 95% 置信水平
    ci_lower = kappa - z * std_error
    ci_upper = kappa + z * std_error
    
    return {
        "fleiss_kappa": round(kappa, 4),
        "P_bar": round(P_bar, 4),
        "P_e": round(P_e, 4),
        "std_error": round(std_error, 4),
        "ci_95": [round(ci_lower, 4), round(ci_upper, 4)],
        "interpretation": _interpret_kappa(kappa),
        "n_samples": n_samples,
        "n_annotators": n_annotators,
        "n_categories": n_categories,
        "categories": labels
    }
```

#### 3.3.4 Krippendorff's Alpha（通用 IAA 指标）

Krippendorff's Alpha 是最通用的 IAA 指标，支持任意数量的标注员、缺失值、以及不同的数据类型（名义、有序、间隔、比例）：

```python
def krippendorff_alpha_generalized(data_matrix, metric='interval'):
    """
    通用的 Krippendorff's Alpha 计算
    
    支持：多位标注员、缺失值、多种数据类型
    
    Args:
        data_matrix: n_annotators × n_samples 的矩阵，缺失值为 NaN
        metric: 距离度量方式
            - 'nominal': 名义数据
            - 'ordinal': 有序数据
            - 'interval': 间隔数据（默认）
            - 'ratio': 比例数据
    
    Returns:
        alpha: Krippendorff's Alpha 值
    """
    import numpy as np
    
    data = np.array(data_matrix, dtype=float)
    n_annotators, n_samples = data.shape
    
    # 计算距离函数
    def distance(a, b, metric_type):
        if np.isnan(a) or np.isnan(b):
            return np.nan
        if metric_type == 'nominal':
            return 0.0 if a == b else 1.0
        elif metric_type == 'ordinal':
            # 有序数据的距离
            return (a - b) ** 2  # 简化实现
        elif metric_type == 'interval':
            return (a - b) ** 2
        elif metric_type == 'ratio':
            return ((a - b) / (a + b)) ** 2 if (a + b) != 0 else 0.0
        return (a - b) ** 2
    
    # 计算观察到的分歧 D_o
    total_pairs = 0
    observed_sum = 0.0
    
    for s in range(n_samples):
        # 对该样本有标注的标注员
        valid_annotators = [a for a in range(n_annotators) if not np.isnan(data[a, s])]
        n_valid = len(valid_annotators)
        
        if n_valid < 2:
            continue
        
        for i in range(n_valid):
            for j in range(i + 1, n_valid):
                a_i, a_j = valid_annotators[i], valid_annotators[j]
                d = distance(data[a_i, s], data[a_j, s], metric)
                if not np.isnan(d):
                    observed_sum += d
                    total_pairs += 1
    
    if total_pairs == 0:
        return float('nan')
    
    D_o = observed_sum / total_pairs
    
    # 计算期望的分歧 D_e
    # 收集所有有效评分
    all_scores = []
    for s in range(n_samples):
        for a in range(n_annotators):
            if not np.isnan(data[a, s]):
                all_scores.append(data[a, s])
    
    expected_sum = 0.0
    expected_pairs = 0
    
    for i in range(len(all_scores)):
        for j in range(i + 1, len(all_scores)):
            d = distance(all_scores[i], all_scores[j], metric)
            if not np.isnan(d):
                expected_sum += d
                expected_pairs += 1
    
    if expected_pairs == 0:
        return float('nan')
    
    D_e = expected_sum / expected_pairs
    
    if D_e == 0:
        return 1.0
    
    alpha = 1 - (D_o / D_e)
    
    return alpha
```

#### 3.3.5 IAA 指标的选取指南

| 场景 | 推荐指标 | 原因 |
|------|---------|------|
| 两位标注员，二分类 | Cohen's Kappa | 标准选择，校正随机一致 |
| 两位标注员，有序评分（1-5） | 加权 Cohen's Kappa | 考虑评分差距（4分和5分比1分和5分更接近） |
| 三位以上标注员 | Fleiss' Kappa | 多标注员场景的标准扩展 |
| 标注员人数不等或有缺失值 | Krippendorff's Alpha | 最灵活，容忍缺失值 |
| 快速评估（仅内部参考） | Percent Agreement | 简单直观，但可能高估一致性 |

### 3.4 争议样本仲裁

当标注员之间存在分歧时，需要仲裁流程：

```python
class DisputeResolution:
    """
    争议样本仲裁系统
    
    当标注员之间的 IAA 低于阈值时，启动仲裁流程
    """
    
    def __init__(self, iaa_threshold: float = 0.7):
        self.iaa_threshold = iaa_threshold
        self.disputes = []  # 争议样本列表
    
    def detect_disputes(self, annotations: list, labels: list = None) -> list:
        """
        检测有争议的样本
        
        Args:
            annotations: 所有标注员对所有样本的标注
            labels: 可选的标签列表
        
        Returns:
            disputes: 有争议的样本列表
        """
        n_samples = len(annotations[0]) if annotations else 0
        disputes = []
        
        for s in range(n_samples):
            sample_annotations = [a[s] for a in annotations]
            
            # 计算该样本上的一致性
            # 简化：检查是否有超过 1 个不同标签
            unique_labels = set(sample_annotations)
            
            if len(unique_labels) > 1:
                # 计算该样本的 pairwise agreement
                agreements = 0
                pairs = 0
                for i in range(len(sample_annotations)):
                    for j in range(i + 1, len(sample_annotations)):
                        if sample_annotations[i] == sample_annotations[j]:
                            agreements += 1
                        pairs += 1
                
                sample_agreement = agreements / pairs if pairs > 0 else 0
                
                if sample_agreement < self.iaa_threshold:
                    disputes.append({
                        "sample_index": s,
                        "annotations": sample_annotations,
                        "agreement": sample_agreement,
                        "status": "pending"
                    })
        
        self.disputes = disputes
        return disputes
    
    def resolve_by_majority_vote(self, dispute: dict) -> dict:
        """
        多数投票仲裁（简单多数）
        """
        from collections import Counter
        annotations = dispute["annotations"]
        vote_count = Counter(annotations)
        winner = vote_count.most_common(1)[0]
        
        return {
            "sample_index": dispute["sample_index"],
            "method": "majority_vote",
            "final_label": winner[0],
            "votes": dict(vote_count),
            "resolved": True
        }
    
    def resolve_by_expert(self, dispute: dict, expert_annotation) -> dict:
        """
        专家仲裁（适用于关键样本）
        """
        return {
            "sample_index": dispute["sample_index"],
            "method": "expert_review",
            "final_label": expert_annotation,
            "original_annotations": dispute["annotations"],
            "resolved": True
        }
    
    def resolve_by_consensus_discussion(self, dispute: dict, annotators: list) -> dict:
        """
        标注员讨论达成共识
        """
        return {
            "sample_index": dispute["sample_index"],
            "method": "consensus_discussion",
            "final_label": None,  # 讨论后确定
            "resolved": True
        }
```

## 四、训练/评估数据隔离防泄露

### 4.1 数据泄露的危害

数据泄露（Data Leakage）是指评估集中的信息"不小心"出现在训练数据中，导致评估结果虚高：

```
数据泄露的后果：
- 基准准确率被高估 10-30%（根据多项研究）
- 模型改进方向被误导（"优化"了记忆能力而非泛化能力）
- 生产环境表现远低于评估表现（落差 20-50% 的案例不罕见）
```

**经典案例分析**：
```
某团队在 GAIA 基准上取得了 SOTA 结果（准确率 72%）：
  → 全量评估时发现实际准确率仅为 51%
  → 根因：训练数据包含了 GAIA 测试集中的部分任务
  → 模型实际学到的是"记忆答案"而非"解决问题"

教训：数据隔离不是"建议"而是"纪律"。
```

### 4.2 数据隔离策略

#### 策略一：时间戳隔离

以时间戳为界限，确保评估数据的时间晚于训练数据的截止时间：

```python
def temporal_split(production_logs: list, cutoff_date: str) -> dict:
    """
    基于时间戳的训练/评估数据分割
    
    使用 cutoff_date 之前的数据做训练，之后的数据做评估
    """
    from datetime import datetime
    
    cutoff = datetime.fromisoformat(cutoff_date)
    train_data = []
    eval_data = []
    
    for log in production_logs:
        log_date = datetime.fromisoformat(log["timestamp"])
        if log_date < cutoff:
            train_data.append(log)
        else:
            eval_data.append(log)
    
    return {
        "train": train_data,
        "eval": eval_data,
        "cutoff_date": cutoff_date,
        "train_size": len(train_data),
        "eval_size": len(eval_data)
    }
```

#### 策略二：基于内容的相似度去重

防止评估数据与训练数据在语义上重叠：

```python
def deduplicate_by_similarity(train_data: list, eval_data: list, 
                               threshold: float = 0.85) -> list:
    """
    基于语义相似度的去重
    
    使用 Embedding 计算评估数据与训练数据的相似度，
    移除与训练数据过于相似的评估样本
    
    Args:
        train_data: 训练数据集（文本列表）
        eval_data: 评估数据集（文本列表）
        threshold: 相似度阈值（超过此值认为重复）
    
    Returns:
        filtered_eval: 去重后的评估数据
    """
    from sentence_transformers import SentenceTransformer
    import numpy as np
    
    # 加载 Embedding 模型
    model = SentenceTransformer('all-MiniLM-L6-v2')
    
    # 编码训练数据
    train_embeddings = model.encode(train_data, show_progress_bar=False)
    
    filtered_eval = []
    removed_count = 0
    
    for item in eval_data:
        item_embedding = model.encode([item])[0]
        
        # 计算与所有训练数据的最大相似度
        similarities = np.dot(train_embeddings, item_embedding) / (
            np.linalg.norm(train_embeddings, axis=1) * np.linalg.norm(item_embedding)
        )
        max_similarity = np.max(similarities)
        
        if max_similarity < threshold:
            filtered_eval.append(item)
        else:
            removed_count += 1
    
    return {
        "filtered_eval": filtered_eval,
        "original_size": len(eval_data),
        "filtered_size": len(filtered_eval),
        "removed_count": removed_count,
        "removal_rate": round(removed_count / len(eval_data) * 100, 1) if eval_data else 0,
        "threshold": threshold
    }
```

#### 策略三：N-gram 重叠检测

轻量级的去重方法，不依赖 Embedding 模型：

```python
def deduplicate_by_ngram(train_data: list, eval_data: list, 
                          n: int = 8, threshold: float = 0.7) -> list:
    """
    基于 N-gram 重叠的去重
    
    计算评估样本与训练样本的 N-gram 重叠率
    
    Args:
        train_data: 训练数据集
        eval_data: 评估数据集
        n: N-gram 大小
        threshold: 重叠率阈值
    
    Returns:
        filtered_eval: 去重后的评估数据
    """
    def get_ngrams(text, n):
        """提取 N-gram 集合"""
        text = text.lower()
        return set(text[i:i+n] for i in range(len(text) - n + 1))
    
    # 构建训练数据的 N-gram 索引（用于高效查找）
    train_ngrams = set()
    for text in train_data:
        train_ngrams.update(get_ngrams(text, n))
    
    filtered_eval = []
    removed_count = 0
    
    for item in eval_data:
        item_ngrams = get_ngrams(item, n)
        if len(train_ngrams) == 0:
            filtered_eval.append(item)
            continue
        
        overlap = len(item_ngrams & train_ngrams) / len(item_ngrams) if item_ngrams else 0
        
        if overlap < threshold:
            filtered_eval.append(item)
        else:
            removed_count += 1
    
    return {
        "filtered_eval": filtered_eval,
        "original_size": len(eval_data),
        "filtered_size": len(filtered_eval),
        "removed_count": removed_count,
        "removal_rate": round(removed_count / len(eval_data) * 100, 1) if eval_data else 0,
        "ngram_size": n,
        "threshold": threshold
    }
```

### 4.3 数据集版本管理

```python
class EvalDatasetManager:
    """
    评估数据集版本管理器
    
    追踪数据集的版本变更、隔离状态、质量指标
    """
    
    def __init__(self, storage_path: str):
        self.storage_path = storage_path
        self.versions = {}
        self._load_manifest()
    
    def create_version(self, version: str, data: list, 
                       description: str = "",
                       isolation_checks: dict = None) -> dict:
        """
        创建新版本的数据集
        
        Args:
            version: 版本号（如 "1.0", "2.1"）
            data: 评估数据
            description: 版本描述
            isolation_checks: 隔离检查结果
        
        Returns:
            manifest: 版本清单
        """
        import datetime, uuid
        
        version_id = str(uuid.uuid4())[:8]
        
        # 数据隔离检查
        if isolation_checks is None:
            isolation_checks = {
                "temporal_isolation": True,
                "similarity_dedup": "not_applied",
                "ngram_dedup": "not_applied"
            }
        
        # 计算数据集统计
        tasks = [item.get("task", {}).get("instruction", "") for item in data]
        difficulties = [item.get("task", {}).get("difficulty", "unknown") for item in data]
        from collections import Counter
        difficulty_dist = Counter(difficulties)
        
        manifest = {
            "version": version,
            "version_id": version_id,
            "created_at": datetime.datetime.now().isoformat(),
            "description": description,
            "size": len(data),
            "difficulty_distribution": dict(difficulty_dist),
            "isolation_checks": isolation_checks,
            "status": "active",
            "change_log": self._get_change_log(version)
        }
        
        # 存储数据
        self._save_data(version, data)
        
        # 更新清单
        self.versions[version] = manifest
        self._save_manifest()
        
        return manifest
    
    def check_isolation(self, train_data: list, eval_data: list) -> dict:
        """
        检查评估数据与训练数据的隔离性
        
        返回隔离性报告
        """
        # 1. 时间隔离检查
        train_dates = [d.get("timestamp", "") for d in train_data 
                      if d.get("timestamp")]
        eval_dates = [d.get("timestamp", "") for d in eval_data 
                     if d.get("timestamp")]
        
        temporal_isolated = True
        if train_dates and eval_dates:
            max_train_date = max(train_dates)
            min_eval_date = min(eval_dates)
            temporal_isolated = max_train_date < min_eval_date
        
        # 2. 相似度检查
        train_texts = [str(d.get("task", "")) for d in train_data]
        eval_texts = [str(d.get("task", "")) for d in eval_data]
        
        # N-gram 检查
        ngram_overlap = self._check_ngram_overlap(train_texts, eval_texts)
        
        # 3. 生成报告
        isolation_report = {
            "temporal_isolation": {
                "isolated": temporal_isolated,
                "max_train_date": max(train_dates) if train_dates else "N/A",
                "min_eval_date": min(eval_dates) if eval_dates else "N/A"
            },
            "ngram_overlap": ngram_overlap,
            "overall_isolated": temporal_isolated and ngram_overlap["max_overlap"] < 0.5,
            "risk_level": "high" if not temporal_isolated else (
                "medium" if ngram_overlap["max_overlap"] > 0.3 else "low"
            )
        }
        
        return isolation_report
    
    def _check_ngram_overlap(self, train_texts: list, eval_texts: list, n: int = 10) -> dict:
        """检查 N-gram 重叠情况"""
        train_ngrams = set()
        for text in train_texts:
            for i in range(len(text) - n):
                train_ngrams.add(text[i:i+n].lower())
        
        overlaps = []
        for text in eval_texts:
            text_ngrams = set()
            for i in range(len(text) - n):
                text_ngrams.add(text[i:i+n].lower())
            
            if train_ngrams and text_ngrams:
                overlap_ratio = len(text_ngrams & train_ngrams) / len(text_ngrams)
                overlaps.append(overlap_ratio)
        
        return {
            "max_overlap": max(overlaps) if overlaps else 0,
            "mean_overlap": sum(overlaps) / len(overlaps) if overlaps else 0,
            "samples_above_50pct": sum(1 for o in overlaps if o > 0.5) if overlaps else 0
        }
    
    def _save_data(self, version: str, data: list):
        import os, json
        path = os.path.join(self.storage_path, f"eval_set_v{version}.json")
        with open(path, 'w', encoding='utf-8') as f:
            json.dump(data, f, ensure_ascii=False, indent=2)
    
    def _save_manifest(self):
        import os, json
        path = os.path.join(self.storage_path, "manifest.json")
        with open(path, 'w', encoding='utf-8') as f:
            json.dump(self.versions, f, ensure_ascii=False, indent=2)
    
    def _load_manifest(self):
        import os, json
        path = os.path.join(self.storage_path, "manifest.json")
        if os.path.exists(path):
            with open(path, 'r', encoding='utf-8') as f:
                self.versions = json.load(f)
    
    def _get_change_log(self, version: str) -> list:
        """获取从上一个版本到当前版本的变更"""
        version_nums = sorted(self.versions.keys())
        if not version_nums:
            return [{"version": version, "change": "initial_version"}]
        
        # 简单实现：返回空变更日志
        return []
```

### 4.4 数据隔离检查清单

每次发布新评估数据集前，检查以下项目：

```
□ 时间隔离：评估数据采集时间是否晚于训练数据截止时间？
   - [是]  √   - [否]  ✗  → 需要重新划定时间边界

□ 内容去重：评估数据与训练数据是否有显著的 N-gram 或语义重叠？
   - N-gram 最大重叠率：___%（警戒线：30%）
   - Embedding 最大相似度：___%（警戒线：85%）

□ 任务模板去重：评估数据的任务模板是否与训练数据不同？
   - 检查任务描述的词法和句法模式是否重复

□ 答案泄露检查：评估数据的参考答案是否可能在训练数据中出现过？
   - 对参考答案进行全文搜索确认

□ 作者独立：标注评估数据的人员是否独立于训练数据开发者？
   - 评估数据标注员未参与模型训练
```

## 五、数据集的质量保证与持续维护

### 5.1 数据集质量标准

| 质量维度 | 最低标准 | 推荐标准 | 检测方法 |
|---------|---------|---------|---------|
| **IAA (Cohen's Kappa)** | κ ≥ 0.6 | κ ≥ 0.8 | 标注过程中持续监控 |
| **标注准确率** | ≥ 80% | ≥ 90% | 与金标准对比 |
| **数据完整性** | 100% 必填字段 | 100% 所有字段 | schema 校验 |
| **难度分布合理性** | 任务难度有区分 | 符合目标分布比例 | 主客观联合验证 |
| **领域覆盖度** | 覆盖主要场景 | 覆盖全场景 | 场景分类统计 |
| **数据时效性** | 1 年内 | 6 个月内 | 时间戳检查 |

### 5.2 数据集的定期更新

```
更新频率建议：
- 高变化领域（金融、科技、时事）：每月更新 10-20%
- 中等变化领域（医疗、法律）：每季度更新 10%
- 低变化领域（数学、常识）：每半年更新 5%

更新策略：
1. 每期新增任务数量不少于总量的 10%
2. 移除过时的任务（依赖过期信息的）
3. 保持难度分布稳定
4. 更新参考答案（若标准答案发生变化）
5. 版本号递增，记录变更日志
```

## 关键概念速查

| 术语 | 解释 |
|------|------|
| **IAA（Inter-Annotator Agreement）** | 标注者间一致性，衡量不同标注员标注结果的一致程度 |
| **Cohen's Kappa** | 两位标注员间的 IAA 指标，校正了随机一致概率 |
| **Fleiss' Kappa** | 多位标注员间的 IAA 指标，Kappa 的多标注员推广 |
| **Krippendorff's Alpha** | 最通用的 IAA 指标，支持缺失值和多种数据类型 |
| **Percent Agreement** | 简单一致率，标注一致的样本比例 |
| **加权 Kappa** | 考虑有序评分差距的 Kappa（如 1-5 分制） |
| **数据泄露（Data Leakage）** | 评估数据信息出现在训练数据中导致评估结果虚高 |
| **时间戳隔离** | 以时间为界划分训练/评估数据 |
| **N-gram 去重** | 基于 N-gram 重叠检测的轻量级数据去重 |
| **Embedding 去重** | 基于语义相似度的深度数据去重 |
| **标注规范（Labeling Guideline）** | 标注员进行数据标注的标准和操作指南 |
| **争议仲裁** | 标注员意见不一致时的解决流程（多数投票/专家仲裁） |
| **金标准（Gold Standard）** | 由专家预标注的高质量数据集，用于标注员培训和校准 |
