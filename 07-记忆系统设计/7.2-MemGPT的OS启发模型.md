# 7.2 MemGPT 的 OS 启发模型

> MemGPT（现更名为 Letta）是首个将操作系统内存管理思想引入 LLM Agent 的系统。它将 LLM 的上下文窗口视为"主内存"（Main Memory），将外部存储视为"虚拟内存"（Virtual Memory），并通过**分页、换入换出、内存压力告警**等机制，让 Agent 突破上下文窗口的物理限制。

---

## 一、操作系统内存管理的启发

### 1.1 从 OS 到 Agent 的映射

操作系统（OS）的内存管理是现代计算机的基石——它让有限物理内存支持远超其容量的程序运行。MemGPT 的核心洞察是：**LLM 的上下文窗口本质上就是"物理内存"，而外部存储就是"磁盘"**。

| OS 内存管理概念 | MemGPT / Agent 记忆映射 | 说明 |
|----------------|------------------------|------|
| **物理内存（RAM）** | LLM 上下文窗口 | 容量有限，访问极快（直接推理） |
| **虚拟内存（磁盘）** | 外部存储（向量 DB + JSON 存储） | 容量大，访问慢（需检索） |
| **内存页（Page）** | 记忆片段（Memory Segment） | 固定大小的记忆单元 |
| **分页（Paging）** | 上下文窗口分段管理 | 将长记忆切分为可管理的片段 |
| **换入（Page In）** | 检索记忆 → 注入上下文 | 从外部存储加载到窗口 |
| **换出（Page Out）** | 记忆归档 → 移出上下文 | 从窗口移出到外部存储 |
| **缺页中断（Page Fault）** | 记忆缺失 → 触发检索 | 窗口无相关记忆时触发 |
| **MMU（内存管理单元）** | Memory Controller（记忆控制器） | 管理所有记忆操作的中央模块 |
| **内存压力** | Token 使用率 > 阈值 | 触发 Eviction / 压缩 |

### 1.2 为什么要用 OS 模型？

传统 Agent 的记忆管理是"平面"的：所有历史信息被无差别地塞入 Prompt。这与没有虚拟内存的计算机是一样的——只能运行比物理内存小的程序。

MemGPT 的革命性在于它为 Agent 引入了**层级化、可交换、有压力的**记忆系统：

```
                    ┌──────────────────────┐
                    │    Memory Pressure    │
                    │    (>70% 触发告警)    │
                    └────────┬─────────────┘
                             │ 触发
                             ▼
┌───────────────────────────────────────────────────────┐
│                 Memory Controller (MMU)               │
│  ┌──────────┐  ┌──────────┐  ┌───────────────────┐  │
│  │ Page In  │  │ Page Out │  │ Defragmentation   │  │
│  │ (检索)   │  │ (归档)   │  │ (碎片整理)        │  │
│  └──────────┘  └──────────┘  └───────────────────┘  │
└───────────────────────────────────────────────────────┘
                             │
        ┌────────────────────┼────────────────────┐
        ▼                    ▼                    ▼
┌───────────────┐   ┌──────────────┐   ┌──────────────┐
│  Main Memory  │   │Virtual Memory│   │  Swap Area   │
│ (上下文窗口)  │   │ (活跃外部)   │   │ (归档/休眠)  │
│ 4K-200K tok   │   │ 向量 DB      │   │ 文件系统     │
│ 当前可见      │   │ 最近活跃     │   │ 长期存档     │
└───────────────┘   └──────────────┘   └──────────────┘
```

## 二、MemGPT 的核心架构

### 2.1 记忆分页系统

MemGPT 将记忆分为若干固定大小的 **Memory Segment（记忆段，类比 OS 的内存页）**。每个段包含一段独立的记忆内容，并附带元数据。

```
记忆分页架构图：

┌────────────────────────────────────────────────────────┐
│                 Virtual Address Space                  │
│                    (虚拟地址空间)                       │
├────────────────────────────────────────────────────────┤
│  页号  │  偏移  │  段 ID  │  内容摘要  │  大小(Token) │
│────────┼────────┼─────────┼────────────┼──────────────┤
│  P#0   │  0000  │  core   │ system prompt & persona   │
│  P#1   │  1024  │  sess-0 │ 对话第 1-5 轮             │
│  P#2   │  2048  │  sess-0 │ 对话第 6-10 轮            │
│  P#3   │  3072  │  sess-1 │ 上一会话摘要              │
│  P#4   │  4096  │  user   │ 用户画像：偏好、习惯       │
│  ...   │  ...   │  ...    │ ...                       │
├────────────────────────────────────────────────────────┤
│  页面表 (Page Table):                                  │
│  虚拟页号 → 物理帧号 (Main Memory 中的位置)            │
│  P#0 → Frame#0 (常驻)                                 │
│  P#1 → Frame#1 (当前在窗口)                            │
│  P#3 → [SWAPPED] (在虚拟内存中)                        │
│  P#4 → Frame#2 (当前在窗口)                            │
└────────────────────────────────────────────────────────┘

┌───────────────── Main Memory (上下文窗口) ────────────┐
│  Frame#0: [System Prompt + Persona]  ← 常驻, 不换出   │
│  Frame#1: [对话第 1-5 轮]                              │
│  Frame#2: [用户画像]                                   │
│  Frame#3: [空] ← 预留空间                              │
│  Total: 4 frames × 1024 tokens = 4096 tokens          │
└────────────────────────────────────────────────────────┘
```

### 2.2 Memory Controller（记忆控制器）

记忆控制器是 MemGPT 架构的核心，负责所有记忆操作：

```python
class MemoryController:
    """
    记忆控制器：类比 OS 的 MMU（内存管理单元）
    管理主内存（上下文窗口）和虚拟内存（外部存储）之间的数据流动
    """
    def __init__(self, main_memory_size: int = 4096):
        self.main_memory = {}        # 主内存：当前 Prompt 中的帧
        self.page_table = {}         # 页表：虚拟地址 → 物理帧映射
        self.virtual_memory = {}     # 虚拟内存：外部存储
        self.page_size = 1024        # 每页 Token 数
        self.main_memory_size = main_memory_size
        self.pinned_pages = {"core"}  # 常驻页（永不换出）

    @property
    def memory_pressure(self) -> float:
        """当前内存压力 = 已用 Token / 总 Token"""
        used = sum(len(content) for content in self.main_memory.values())
        return used / self.main_memory_size

    def page_in(self, virtual_addr: str) -> bool:
        """换入：从虚拟内存加载到主内存"""
        if self.memory_pressure > 0.7:
            # 内存压力 > 70%，先换出
            self._evict_one_page()

        if virtual_addr not in self.virtual_memory:
            return False  # 缺页

        # 找到空帧
        free_frame = self._find_free_frame()
        if free_frame is None:
            self._evict_one_page()  # 强制换出一个
            free_frame = self._find_free_frame()

        # 换入
        page_data = self.virtual_memory.pop(virtual_addr)
        self.main_memory[free_frame] = page_data
        self.page_table[virtual_addr] = free_frame
        return True

    def page_out(self, virtual_addr: str):
        """换出：从主内存移至虚拟内存"""
        if virtual_addr in self.pinned_pages:
            return  # 常驻页不能换出

        frame = self.page_table.get(virtual_addr)
        if frame is not None:
            self.virtual_memory[virtual_addr] = self.main_memory[frame]
            del self.main_memory[frame]
            del self.page_table[virtual_addr]

    def _evict_one_page(self):
        """换出策略：选择最不常用的页换出（LRU 近似）"""
        # 排除常驻页
        candidates = [
            addr for addr in self.page_table
            if addr not in self.pinned_pages
        ]
        if not candidates:
            return
        # 选择访问时间最早的（LRU）
        victim = min(candidates, key=lambda addr: self._last_access(addr))
        self.page_out(victim)
```

### 2.3 内存压力与告警机制

MemGPT 的一个重要创新是**内存压力告警**——当上下文窗口使用率超过阈值时，Agent 会收到系统级通知，主动触发记忆管理操作：

```
┌─────────────────────────────────────────────────────┐
│  内存压力告警流程                                     │
│                                                      │
│  Token 使用率 > 70% ?                                 │
│      │                                               │
│      ├── YES → 注入 System Alert                       │
│      │         "Memory pressure is high               │
│      │          (current: 73%).                        │
│      │          Consider page-out or summarize."       │
│      │         → Agent 调用 memory_page_out()         │
│      │         → 或调用 summarize_and_compress()       │
│      │                                               │
│      └── NO  → 继续正常推理                            │
│                                                      │
│  Token 使用率 > 90% ?                                 │
│      │                                               │
│      └── YES → 强制 Eviction                          │
│                自动换出最低优先级的内容                  │
│                不再等待 Agent 主动操作                 │
└─────────────────────────────────────────────────────┘
```

**为什么是 70%？** 这是 MemGPT 的经验阈值。低于 70% 时，有足够空间换入新的记忆页；70%-90% 是"黄色警戒"，Agent 应主动管理；超过 90% 是"红色警戒"，系统强制介入。

## 三、MemGPT 的系统 Prompt 结构

MemGPT 通过精心设计的 System Prompt 让 LLM 自身具备"操作系统意识"。

### 3.1 内存结构声明

系统 Prompt 中会定义 Agent 的"内存结构"，告诉 LLM 它的"主内存"布局：

```
=== SYSTEM ===
You are an AI agent with an OS-like memory architecture.

Your working memory (context window) is organized as follows:

<main_memory>
  <core_persona>
    Name: Assistant
    Traits: helpful, thorough, memory-aware
  </core_persona>

  <dialogue_buffer>
    <!-- 最近对话滑动窗口 -->
  </dialogue_buffer>

  <retrieved_memories>
    <!-- 从 LTM 检索到的相关记忆 -->
  </retrieved_memories>
</main_memory>

Available functions:
- memory_page_in(page_id): Load a memory page into working memory
- memory_page_out(page_id): Unload a memory page to save space
- memory_search(query): Search across all memory tiers

Current memory pressure: 72%  ← 实时更新的告警
```

### 3.2 Agent 自主记忆管理

当模型收到"Memory pressure: 72%"这类系统消息时，可以在推理中自主决定调用记忆管理函数：

```python
# Agent 感知到内存压力后的自主操作
class MemGPTAgent:
    def process_turn(self, user_message: str):
        """处理用户消息——Agent 可能自主管理记忆"""
        # Step 1: 组装当前上下文
        prompt = self._build_prompt(user_message)

        # Step 2: LLM 推理（可能包含函数调用）
        response = self.llm.generate(prompt)

        # Step 3: 解析函数调用
        for func_call in response.function_calls:
            if func_call.name == "memory_page_out":
                self.memory_controller.page_out(func_call.args["page_id"])
            elif func_call.name == "memory_search":
                results = self.memory_controller.search(func_call.args["query"])
                # 将结果注入下一轮上下文
                self.context_buffer.append(results)
            elif func_call.name == "summarize_and_compress":
                summary = self.llm.summarize(
                    self.memory_controller.get_oldest_pages()
                )
                self.memory_controller.store_summary(summary)

        return response.text
```

## 四、MemGPT vs 传统 Agent 记忆

| 维度 | 传统 Agent | MemGPT 风格 |
|------|-----------|-------------|
| **窗口意识** | 不知道上下文被截断 | 通过 memory_pressure 感知窗口使用率 |
| **记忆管理** | 由外部系统强制截断 | Agent 自主决定换入/换出 |
| **常驻页** | 无区分，全部同等对待 | System Prompt + Persona 常驻 |
| **碎片处理** | 无 | 定期整理，合并相邻小页 |
| **换出策略** | FIFO（先入先出丢弃） | LRU + 优先级混合策略 |
| **扩展性** | 达到窗口上限后不可用 | 可扩展到任意大小的虚拟地址空间 |

## 五、实现一个精简版 MemGPT

### 5.1 核心实现

```python
class MemGPT:
    """
    精简版 MemGPT 实现
    """
    def __init__(self, llm, memory_controller, embedding_model):
        self.llm = llm
        self.mc = memory_controller  # Memory Controller
        self.embed = embedding_model
        self.pressure_threshold = 0.7

    def chat(self, user_message: str) -> str:
        # 1. 检查内存压力
        pressure = self.mc.memory_pressure
        system_alert = ""
        if pressure > self.pressure_threshold:
            system_alert = (
                f"[System] Memory pressure: {pressure:.0%}. "
                f"Consider page_out or compression."
            )

        # 2. 检索相关长期记忆
        query_embedding = self.embed.encode(user_message)
        relevant_memories = self.mc.search_vm(query_embedding, top_k=3)

        # 3. 组装主内存（上下文窗口）
        main_memory = self._assemble_main_memory(
            system_alert=system_alert,
            user_message=user_message,
            relevant_memories=relevant_memories
        )

        # 4. LLM 推理
        response = self.llm.generate(main_memory)

        # 5. 后处理：将新信息写入记忆
        self._consolidate(response)
        return response.text

    def _assemble_main_memory(self, system_alert, user_message, relevant_memories):
        """组装上下文窗口"""
        # 常驻页：System Prompt + Persona
        core = self.mc.main_memory.get("core", "")

        # 对话缓冲区：当前窗口中的对话历史
        dialogue = self.mc.main_memory.get("dialogue", "")

        # 检索结果：刚刚从虚拟内存换入的
        retrieved = "\n".join(
            f"[Memory {m['id']}]: {m['content']}"
            for m in relevant_memories
        )

        # 如果窗口不够，触发 page_in
        total_tokens = len(core) + len(dialogue) + len(retrieved) + len(user_message)
        if total_tokens > self.mc.main_memory_size:
            self.mc.page_out("dialogue")  # 换出一部分
            # 重建 dialogue
            dialogue = self.mc.main_memory.get("dialogue", "")

        return f"{core}\n{system_alert}\n{dialogue}\n{retrieved}\nUser: {user_message}"
```

### 5.2 运行流程

```
User: "你还记得我上周提到的项目计划吗？"

┌─ Memory Controller ─────────────────────────────────┐
│  1. memory_pressure = 65% (< 70%, OK)                │
│  2. Search VM for "上周 项目计划"                    │
│     → 找到相关页 P#7 (内容: "用户的项目计划...")     │
│  3. Page In: P#7 → Frame#3 (还剩 35% 空间)          │
│  4. 加载后的窗口:                                     │
│     [core][dialogue(最近5轮)][P#7(项目计划)]          │
│     memory_pressure → 82% (> 70%, 触发告警)          │
│  5. LLM 返回: "记得的，您上周提到..."               │
│  6. LLM 同时检测到告警, 自主调用 page_out(dialogue)   │
│     → memory_pressure → 68% (< 70%, OK)             │
└──────────────────────────────────────────────────────┘
```

## 关键概念速查

| 术语 | 解释 |
|------|------|
| **MemGPT (Letta)** | 将 OS 内存管理引入 LLM Agent 的系统 |
| **Main Memory** | LLM 上下文窗口，类比物理内存 |
| **Virtual Memory** | 外部存储，类比磁盘交换空间 |
| **Memory Page** | 固定大小的记忆单元 |
| **Page In / Page Out** | 记忆在窗口和存储之间的换入/换出 |
| **Memory Pressure** | Token 使用率，>70% 触发告警 |
| **Pinned Page** | 常驻页（如 System Prompt），永不换出 |
| **缺页中断 (Page Fault)** | 主内存未命中时触发的检索操作 |
| **MMU / Memory Controller** | 记忆操作的中央调度器 |
